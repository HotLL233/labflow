# LabFlow v2.3.81 更新说明

本版在v2.3.80上新增常见网盘类型和OneDrive原生通道，不改业务数据库结构、历史迁移、工作量计算或既有用户配置。

## 常见网盘

- 增加坚果云、OneDrive、Nextcloud、ownCloud、OpenList、百度/阿里/夸克经网关、通用HTTPS WebDAV的明确配置入口。
- OneDrive采用微软官方设备授权，需用户自己的公共客户端Client ID及对应权限。支持全球版个人和工作/学校账号，世纪互联版不在本版范围。
- 微软授权绑定发起人的程序账号和目标配置，遵守轮询间隔；访问/刷新令牌不返回前端，存于服务器私有目录，刷新和断开/重新授权互相复核，不使旧授权复活。
- OneDrive支持目录创建、列表、上传、取回和校验；大文件10MiB分片、私有会话落盘、查询服务端断点后续传。上传URL与下载CDN不接收Graph Bearer。
- 百度、阿里云盘、夸克明确标注“经OpenList网关”，要求先在网关完成授权，不宣传为原生账号直连。

## WebDAV 兼容修正

- 测试当前输入而非隐式使用旧配置，测试不自动保存密码；旧无请求体测试调用仍兼容，错误JSON不回退到旧凭据。
- 测试先只读鉴权，检查目标目录；父目录存在时可创建最后一级目录，再执行小文件上传、回读、删除。
- 坚果云专用类型默认使用具体备份子目录，不向 `/dav/` 根集合直接PUT。旧通用配置根目录仍可读，写入时明确说明原因。
- HTTP401/403/404/413/429/507分别解释鉴权、权限、目录、大小、频率和容量；不再把401混同配额。
- WebDAV大小核对采用目录属性，兼容网关下载跳转；文件读取可安全跟随HTTPS跳转，跨域后不再转发网关密码。
- 拒绝非WebDAV网页/分享页响应和Windows保留设备文件名。

## 保持的能力

保持本地全量/数据库包、原生浏览器下载与Range、短时文件授权、自动备份、同步目录、回收站、保留份数、后台任务重试、来源保护、SHA-256清单、取回后发布以及确认后覆盖恢复。

旧WebDAV目标指纹保持兼容；切换目标、原生账号、应用、租户或目录不会重定向旧任务。私有配置与任务不进入全量ZIP，服务器迁移后需重新配置或授权网盘。
