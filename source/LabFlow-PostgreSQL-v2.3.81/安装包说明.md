## 使用入口

1. 升级前保留数据库和附件的最终备份。安装到实际运行服务的那台电脑，不是在访问网页的客户端电脑安装。
2. “系统管理 → 数据备份 → 云端设置”选择网盘类型。
3. 坚果云填应用密码和具体目录；测试当前输入可创建最后一级目录，父目录需存在。测试不自动保存修改，成功后仍需保存。
4. OneDrive填写自己的公共客户端Client ID，再点“保存并授权”，在微软页面输入代码完成授权；无需把密码或令牌发给其他人。
5. 百度、阿里、夸克是已授权OpenList网关接入，填网关地址和网关凭据，不是网盘账号原生登录。
6. v80失败任务绑定旧地址；切换目的地后先取消旧失败任务，再在本地列表对原备份重新上传，取消不删除文件。

- All Integration：204项前端、336项后端通过；3项备份专用测试在默认套件中保留ignore，但在最终测试二进制上另行全部通过。类型检查、生产构建/gzip、Rust fmt/check/Release通过。
