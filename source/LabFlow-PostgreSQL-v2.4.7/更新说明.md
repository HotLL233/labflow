# labflow v2.4.7 更新说明

本版验证、安装包和正式发布状态见同目录《安装包说明.md》。

补齐旧方法辅助、已关联历史辅助与兼容主记录在人员记录、辅助统计和辅助录入列表中的编辑与删除入口；按明确原始来源调用原记录接口，保留原权限、历史快照、来源链、回收站和审计。独立辅助继续沿用既有编辑、删除和恢复流程。

删除后同步刷新人员记录及汇总，兼容镜像不得复活或重复统计；统计查看权限不授予删除权限，按服务端删除目标区分同数字 ID 的不同来源，保留回收站恢复。不新增数据库迁移，不操作现场数据。

历史辅助沿用原工作量记录维护权限，不要求原实验室存在，不按相似姓名补绑人员。可编辑数量、工作量时间和备注，原事项、人员、方法与系数显示为只读；原方法停用不阻止纯元数据编辑。原记录编辑与删除增加可选完整行指纹和事务锁内复核，兼容旧客户端并保留原源样累计数量约束；新入口删除原因必填，保留并发冲突提示。历史辅助不在当前列表更换事项、改写系数或批量迁移。

保留独立辅助的删除/恢复、原工作量回收站、历史系数、人员归属、自定义显示和其他业务功能。
