# v2.1.0 更新说明

## 新增与修复

- 工作量录入页新增“项目筛选”下拉框；同一实验室多个项目关联同一检测方法时，可按项目只显示对应的项目-方法录入行。
- 项目筛选与方法类型筛选联动，计数只统计当前项目范围；提交时继续校验方法属于所选项目。
- 通知中心字段候选自动读取录入表单配置（研发送样录入、样品信息录入、分析检测录入）和样品信息登记自定义列。
- 研发送样通知载荷补充 `extra_fields`，录入表单自定义字段可实际渲染到程序内通知和钉钉通知。
- 保留人员反馈字段同步、人员变动通知独立数据边界及 v2.0.0 其他功能。
- 通知中心新增“人员通知反馈驳回”独立通知事件；人员反馈被驳回后立即入队，默认通知反馈发起人，可配置程序内人员和钉钉渠道，并完整显示驳回原因。
- 新增 PostgreSQL 迁移 `2.1.0-personnel-feedback-rejection-notification`，兼容已有通知规则数据。

## 版本隔离

- 本版本基于 v2.0.0 源码复制到独立目录开发。
- 未修改 v2.0.0 源码目录；未改变用户、项目、样品、人员变动通知以外的既有数据库结构。
- 工作量录入项目筛选只改变页面展示条件，不改变录入接口、记录结构和权限校验。
