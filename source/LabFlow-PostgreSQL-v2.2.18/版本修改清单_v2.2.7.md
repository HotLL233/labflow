## 一、权限标签语义优化

### 1.1 后端权限定义扩展 (`src/models/role.rs`)

**优化目标**: 双标签系统 + 权限元数据增强

#### 结构变更
```rust
// 旧结构
pub struct PermissionDef {
    pub key: &'static str,
    pub label: &'static str,
    pub group: &'static str,
}

// 新结构
pub struct PermissionDef {
    pub key: &'static str,
    pub label: &'static str,           // 短标签（精简显示）
    pub full_label: &'static str,      // 完整标签（详细描述）
    pub group: &'static str,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub portal: Option<&'static str>,  // 门户归属
    #[serde(skip_serializing_if = "Option::is_none")]
    pub actor: Option<&'static str>,   // 角色归属
}
```

#### 典型示例
```rust
PermissionDef {
    key: "sample:collect",
    label: "取样（研发送样）",                    // 短标签
    full_label: "分析检测-对研发送样取样",        // 完整标签
    group: "门户入口",
    portal: Some("分析检测门户"),
    actor: Some("检测人员"),
}
```

#### 优化范围
- **权限总数**: 80+ 项
- **新增字段**: `full_label`、`portal`、`actor`
- **向后兼容**: 保留 `label` 字段，现有代码无需修改

### 1.2 前端权限接口对齐 (`frontend/src/constants/permissions.ts`)

## 二、版本号统一管理

### 2.1 单一数据源 (`VERSION` 文件)

**创建位置**: 项目根目录  
**文件内容**: `2.2.7`  
**设计原则**: 单一真实源（Single Source of Truth）

### 2.2 自动化脚本

#### Bash 版本 (`scripts/set-version.sh`)
```bash
#!/bin/bash
VERSION=$1

# 更新 5 个关键文件
sed -i "s/^version = .*/version = \"$VERSION\"/" Cargo.toml
sed -i "s/\"version\": \".*\"/\"version\": \"$VERSION\"/" frontend/package.json
sed -i "s/^#define MyAppVersion .*/#define MyAppVersion \"$VERSION\"/" build_server_installer.iss
sed -i "s/^#define MyAppNumericVersion .*/#define MyAppNumericVersion \"$VERSION.0\"/" build_server_installer.iss
sed -i "s/^#define MyAppVersion .*/#define MyAppVersion \"$VERSION\"/" build_hot_update_installer.iss
sed -i "s/^#define MyAppNumericVersion .*/#define MyAppNumericVersion \"$VERSION.0\"/" build_hot_update_installer.iss
echo "$VERSION" > VERSION
```

#### Windows 批处理版本 (`scripts/set-version.bat`)
```batch
@echo off
set VERSION=%1
powershell -Command "(gc Cargo.toml) -replace '^version = .*', 'version = \"%VERSION%\"' | Set-Content Cargo.toml"
powershell -Command "(gc frontend\package.json) -replace '\"version\": \".*\"', '\"version\": \"%VERSION%\"' | Set-Content frontend\package.json"
...
```

#### 版本一致性检查 (`scripts/check-version.sh`)
```bash
#!/bin/bash
# 验证 6 个文件中的版本号是否一致
# 不一致时退出并报错
```

## 三、前端变量命名标准化

### 3.1 命名原则

**优化前**: 过度简化的单字母/双字母变量  
**优化后**: 完整描述性命名

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| React Hooks | 完整动词+名词 | `useNavigate()` |
| 状态变量 | 描述性名词 | `groups`, `loading`, `error` |
| 函数 | 动词+名词 | `loadGroups`, `loadDivisions` |
| 计算值 | 描述性名词 | `filteredGroups`, `displayGroups` |
| 常量 | 大写+下划线 | `BORDER_RADIUS` |
