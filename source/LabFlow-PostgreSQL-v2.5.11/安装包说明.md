# labflow v2.5.11 安装包说明

本版基于 v2.5.10，新增工作量 API 接入永久删除。首次安装使用 `labflow-v2.5.11.exe`，已有完整服务器安装可使用 `labflow-v2.5.11-hotupdate.exe`。升级前备份数据库、附件和配置。

本版不新增数据库迁移，升级不会自动删除、停用或轮换现有接入。工作量 API 接入不随业务备份迁移，恢复后应重新生成接入令牌。详细用法见[接入文档](docs/工作量API接入.md)；本地验证包不是正式 Release。

## 本地验证

- 共享自动化与 Build/All 通过，前端 326 项、隔离 PostgreSQL 后端 427 项通过（另 4 项忽略）。删除回归覆盖非管理员及列表修订滞后被拒绝、旧令牌与续读失效、其他接入及业务数据保留、无凭据审计。全量测试结束后测试库关闭超过脚本等待时间，随后已核实正常关闭。
- 同一构建在隔离数据库上实测桌面及移动视口，覆盖取消、冲突提示、删除已启用/停用的接入及刷新后仍已删除。
- 本地完整包和热更新包均核对内嵌版本 `2.5.11.0` 和 SHA-256。详细证据及校验文件留在 `test-artifacts/v2.5.11/`；未执行安装/卸载、现网升级、容器运行或公司运营真实联调。
