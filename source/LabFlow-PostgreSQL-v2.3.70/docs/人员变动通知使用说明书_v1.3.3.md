# 人员变动通知使用说明书

适用版本：v1.3.3 及兼容的后续版本

## 1. 功能说明

“人员变动通知”用于向系统内相关人员发起人员、项目或检测方法变动反馈，并由有审批权限的人员确认。该功能的通知记录用于业务通知和审批留痕；实际人员变动以审批通过后的“项目及人员汇总表”为准。

本功能是独立功能：

- 发起、查看、审批、导入和导出操作不修改系统用户、项目、样品等业务数据库。
- 当前项目、人员和检测方法以独立的“项目及人员汇总表.xlsx”为准。
- 只有审批通过才会更新独立汇总表；审批通过前会自动备份原汇总表。
- 审批驳回不会调整汇总表。

## 2. 角色与权限

| 角色 | 可查看通知 | 可发起通知 | 可审批 | 可导入/导出汇总表 | 可编辑人员反馈配置 |
| --- | --- | --- | --- | --- | --- |
| 系统管理员 | 全部记录、全部实验室 | 是 | 是 | 导入、导出全部数据 | 是 |
| 分析检测组长 | 全部记录、全部实验室 | 否 | 是 | 导入、导出全部数据 | 否 |
| 研发送样组长 | 本账号关联实验室范围内记录 | 是 | 否 | 仅导出可见范围 | 否 |

注意：

- 审批人不能审批自己发起的通知。
- 一条通知只能审批一次，已通过或已驳回的通知不能重复处理。
- 研发送样组长只能选择用户数据库中与本人关联的有效实验室；系统管理员和分析检测组长可选择全部有效实验室。

## 3. 使用前准备

### 3.1 准备项目及人员汇总表

首次使用前，必须由系统管理员或分析检测组长导入项目及人员汇总表。模板建议使用系统提供的《项目及人员汇总表.xlsx》，工作表名称建议为“当前实验室人员统计表”。

表头必须包含以下五列，名称不能随意修改：

| 列名 | 填写要求 |
| --- | --- |
| 实验室 | 实验室名称，不能为空 |
| 实验室负责人 | 对应课题组长或实验室负责人 |
| 实验人员 | 该项目下的人员，可填写多人 |
| 实验室项目代号 | 项目唯一代号，不能为空 |
| 检测方法 | 该项目对应的检测方法 |

人员和检测方法可使用顿号、逗号、分号或换行分隔。系统导入时会自动去重；页面和导出的汇总表中，检测方法会按行自动换行显示。

### 3.2 导入汇总表

1. 进入“人员变动通知”页面。
2. 点击“更新汇总表”。
3. 选择 `.xlsx` 文件。
4. 系统校验表头和有效数据行，校验成功后替换当前独立汇总表。
5. 页面提示“项目及人员汇总表已更新，未写入程序数据库”后即可使用。

导入会替换当前独立汇总表。导入前请确认文件内容正确，并保留原文件备份。导入不会自动产生人员变动通知，也不会触发审批。

### 3.3 配置人员反馈字段（系统管理员）

进入“管理入口 → 系统配置 → 人员反馈字段”。可配置两类内容：

- **人员变动类型**：修改显示名称、启用/停用、删除或新增类型。
- **人员反馈字段**：新增、删除和调整字段。

自定义字段可设置：

- 字段键：用于系统识别，只允许英文字母、数字和下划线。
- 显示名称：表单中显示的名称。
- 字段类型：单行文本、多行文本、日期、是/否、下拉选项、多选。
- 适用类型：限定该字段在哪些变动类型中显示；留空表示适用于全部类型。
- 必填：勾选后提交时必须填写。
- 进入通知：勾选后字段值会加入通知内容。
- 启用：停用后不在发起表单中显示。

系统内置字段只能修改显示状态和配置，不能删除。修改后点击“保存配置”。

### 3.4 配置通知规则

如需在系统通知中心或钉钉群接收反馈：

1. 进入“管理入口 → 通知中心”。
2. 在“钉钉通知渠道”中新增机器人渠道，填写渠道名称、Webhook；使用加签机器人时填写加签密钥。
3. 点击“测试”确认机器人配置可用。
4. 在“通知规则”中新增规则。
5. 在“通知来源与类型”选择“人员变动反馈”。
6. 按需要选择钉钉渠道、实验室和程序内通知人员，启用规则并保存。

人员变动通知提交成功后会立即进入通知处理流程；后台定时任务仍会对失败通知进行重试。未配置匹配规则时，通知仍会保留在人员变动通知记录中，但不会发送到钉钉或程序内人员。

## 4. 发起人员变动通知

有发起权限的账号进入“人员变动通知”页面后，按以下顺序填写：

1. **实验室**：选择要反馈的实验室。
2. **变动类型**：选择系统管理员启用的类型。
3. **人员**：按变动类型填写或选择人员。
4. **关联项目**：选择受影响的项目，可多选。
5. **检测方法**：新增项目或新增方法时逐条填写。
6. **生效日期**：填写实际生效日期。
7. **备注及自定义字段**：按需要填写；标记为必填的字段必须填写。
8. 点击“发起通知”。

提交成功后会生成通知编号，状态为“待审批”，并显示在“近 7 天通知记录”中。提交人不能自行审批该通知。

### 4.1 人员和项目的默认规则

- **员工加入**：人员必填。输入已有人员时默认勾选其已关联项目；未匹配到人员时显示该实验室全部项目，可多选。
- **员工离职**：人员必填。已有人员默认勾选其已关联项目；取消勾选表示取消该项目关联。项目全部留空时，审批通过会取消该人员当前实验室的全部项目关联。
- **实验室内人员调动**：人员必填。项目下拉始终显示该课题组长关联实验室的全部项目。已有人员的已关联项目默认勾选；取消勾选表示取消关联，新增勾选表示建立关联。
- **跨实验室人员调动**：人员必须是当前实验室已有人员。页面不填写目标实验室和目标项目；选择项目表示取消该人员在当前实验室的这些项目关联，项目留空表示取消该人员在当前实验室的全部项目关联。
- **实验室新增项目**：人员可不填；必须填写新增项目代号和至少一个检测方法。
- **实验室新增方法**：人员可不填；必须选择项目并填写至少一个新增方法。

### 4.2 检测方法填写规则

在“实验室新增项目”和“实验室新增方法”中，检测方法必须一行一个、逐条填写。单个方法名称不能包含：

- 英文逗号 `,`
- 中文逗号 `，`
- 顿号 `、`
- 英文分号 `;`
- 中文分号 `；`
- 换行

如有多个方法，请点击“新增方法”逐项填写。输入内容不符合规则时，系统会阻止提交。

### 4.3 新增项目与高新项目

选择“实验室新增项目”后：

- 填写“新增项目代号”。项目代号不能与该实验室现有项目重复。
- 至少填写一个检测方法。
- 如勾选“高新项目”，必须填写“高新项目名称”。
- 项目名称不是本版本的独立表单字段，项目识别以项目代号为准；高新项目名称用于通知和记录说明。

### 4.4 自定义变动类型

管理员新增的变动类型会出现在发起表单中。自定义类型默认只产生记录和通知，不会自动修改汇总表。若该类型需要改变人员或项目关系，应由管理员或分析检测组长在汇总表中确认调整，或由管理员重新导入正确的汇总表。

## 5. 查看近 7 天通知记录

人员变动通知页面下方默认显示近 7 天记录，包含：

- 通知编号
- 变动类型
- 实验室
- 人员
- 项目/方法
- 生效日期
- 审批状态
- 审批操作

状态含义：

| 状态 | 含义 |
| --- | --- |
| 待审批 | 已提交，等待系统管理员或分析检测组长处理 |
| 已通过 | 审批通过，独立汇总表已更新 |
| 已驳回 | 审批驳回，汇总表未更新 |

驳回记录会显示驳回原因。点击“刷新”可重新加载最新记录。

## 6. 审批人员变动通知

系统管理员或分析检测组长在通知记录中找到“待审批”记录后：

### 6.1 通过

1. 点击“通过”。
2. 可填写审批说明。
3. 点击“确认”。
4. 系统先备份审批前的汇总表，再按变动类型更新独立汇总表。

### 6.2 驳回

1. 点击“驳回”。
2. 必须填写驳回原因。
3. 点击“确认”。
4. 通知状态变为“已驳回”，汇总表保持不变。

### 6.3 审批通过后的汇总表变化

| 变动类型 | 汇总表处理方式 |
| --- | --- |
| 员工加入 | 将人员加入所选项目 |
| 员工离职 | 移除所选项目中的人员；项目留空时移除全部关联项目 |
| 实验室内人员调动 | 所选项目成为人员在当前实验室的完整项目集合 |
| 跨实验室人员调动 | 移除所选项目中的人员；项目留空时移除全部关联项目 |
| 实验室新增项目 | 新增一行项目记录，沿用该实验室负责人并写入人员、项目代号和检测方法 |
| 实验室新增方法 | 将方法合并到所选项目，重复方法自动去重 |
| 自定义变动类型 | 只保留通知和审批记录，不自动更新汇总表 |

每次审批通过前，系统会在独立功能目录下保存一份汇总表备份。如需恢复历史数据，请由管理员根据通知编号和备份时间人工核对后处理。

## 7. 查看和导出汇总表

页面下方“项目及人员汇总表”显示以下内容：

- 实验室
- 实验室负责人
- 实验人员
- 项目代号
- 检测方法

系统管理员和分析检测组长看到全部实验室；研发送样组长只看到本人关联实验室。点击“导出汇总表”可导出当前账号可见范围的数据，导出的检测方法会自动换行。

导出的文件适合查看和备份。需要替换系统基线时，必须使用“更新汇总表”导入，并由系统管理员或分析检测组长执行。

## 8. 常见问题

### 8.1 页面提示尚未导入汇总表

请让系统管理员或分析检测组长先导入符合模板要求的 `.xlsx` 文件。没有有效汇总表时，不能发起或审批会影响项目人员关系的通知。

### 8.2 找不到实验室

研发送样组长只能看到用户数据库中与本人关联的有效实验室。请联系系统管理员检查用户的实验室关联；管理员和分析检测组长可看到全部有效实验室。

### 8.3 发起后没有钉钉消息

依次检查：

1. 通知中心是否存在“人员变动反馈”规则。
2. 规则是否启用，实验室范围是否匹配。
3. 钉钉 Webhook 和加签密钥是否正确。
4. 通知中心的“发送记录”是否显示失败原因。
5. 点击通知中心“处理待发送”进行一次人工重试。

没有配置外部通知渠道时，通知仍会保存在人员变动记录中，但不会发送钉钉消息。

### 8.4 审批通过后项目人员没有变化

请先刷新页面，确认通知状态为“已通过”。如果状态已通过但内容不正确，应核对审批前备份和通知中的实验室、人员、项目选择；不要直接修改程序数据库。

### 8.5 新增方法输入后自动退出

v1.3.3 已修复新增项目和新增方法输入框输入一个字符后失去编辑焦点的问题。若仍出现，请刷新前端页面并确认使用的是 v1.3.3 静态资源。

## 9. 推荐操作规范

- 导入汇总表前先导出并保存一份当前汇总表。
- 一次通知只描述一类明确变动，复杂变动建议拆分为多条通知。
- 项目和方法名称使用正式名称，避免使用简称造成重复。
- 审批人处理前核对实验室、人员、项目和生效日期。
- 驳回时写清原因，便于发起人重新提交。
- 不要通过直接编辑程序数据库来修正人员反馈数据；人员变动业务基线是独立汇总表。
