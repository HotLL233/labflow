## 本版本修复内容

### 核心问题修复

**问题**: 研发送样统计功能完全不可用

**原因**: 权限映射错误，使用了分析检测权限（`stats:workload:*`）而不是研发送样权限（`stats:rd:*`）

**修复内容**:
1. ✅ 修正前端权限映射（15 个权限）
2. ✅ 新增后端权限定义（15 个权限）
3. ✅ 同步前端权限常量（15 个常量）
4. ✅ 改进卡片过滤逻辑（参考分析检测统计模式）

**新增权限**:
- `stats:rd:week` - 按周统计卡片
- `stats:rd:month` - 按月统计卡片
- `stats:rd:user-log` - 送样人记录卡片
- `stats:rd:division` - 事业部统计卡片
- `stats:rd:sheet1` ~ `stats:rd:sheet11` - 11 个导出预览权限

## 升级后必须操作

### ⚠️ 重要：配置研发送样统计权限

升级完成后，需要为使用研发送样统计的角色添加权限：

**步骤**:
1. 以超级管理员登录系统
2. 进入"系统管理" → "角色管理"
3. 编辑需要使用统计功能的角色
4. 勾选以下权限：

**最小权限集**（进入统计门户）:
```
✅ stats:portal:rd          # 进入研发送样统计门户
✅ stats:rd:view-all        # 查看全部数据（或选择 stats:rd:view-lab 只看本实验室）
```

**完整权限集**（显示所有统计卡片）:
```
✅ stats:portal:rd          # 进入统计门户
✅ stats:rd:view-all        # 查看全部数据
✅ stats:rd:week            # 按周统计卡片
✅ stats:rd:month           # 按月统计卡片
✅ stats:rd:user-log        # 送样人记录卡片
✅ stats:rd:division        # 事业部统计卡片
✅ stats:rd:sheet1          # Sheet1 预览
✅ stats:rd:sheet2          # Sheet2 预览
✅ stats:rd:sheet3          # Sheet3 预览
✅ stats:rd:sheet4          # Sheet4 预览
✅ stats:rd:sheet5          # Sheet5 预览
✅ stats:rd:sheet6          # Sheet6 预览
✅ stats:rd:sheet7          # Sheet7 预览
✅ stats:rd:sheet8          # Sheet8 预览
✅ stats:rd:sheet9          # Sheet9 预览
✅ stats:rd:sheet10         # Sheet10 预览
✅ stats:rd:sheet11         # Sheet11 预览
```

**快捷方式**: 建议一次性勾选全部 17 个权限，让用户可以使用完整的统计功能。

## 验证功能是否正常

### 验证步骤

1. **以配置好权限的用户登录**
2. **进入研发送样统计门户**
3. **检查统计卡片**
   - 应该能看到配置的统计卡片
   - 超级管理员应该看到 15 个卡片
4. **点击卡片测试**
   - 卡片应该能正常加载数据
   - 筛选和导出功能应该正常

### 常见问题

**Q: 升级后看不到统计卡片？**
- 确认用户拥有 `stats:portal:rd` 权限
- 确认用户拥有至少 1 个 `stats:rd:*` 卡片权限
- 确认用户已重新登录（刷新权限缓存）

**Q: 点击卡片后无数据？**
- 确认用户拥有 `stats:rd:view-all` 或 `stats:rd:view-lab` 权限
- 确认选择的日期范围内有送样数据

**Q: 如何回滚到 v2.2.6？**
- 停止服务
- 从备份恢复 v2.2.6 的可执行文件
- 重启服务
