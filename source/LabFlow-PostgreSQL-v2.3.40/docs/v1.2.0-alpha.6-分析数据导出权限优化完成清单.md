## 已完成

### 1. 独立的统计导出权限

新增权限：

- 标识：`stats:workload:export`
- 中文名称：导出分析检测统计

分析检测统计页面仍需要原有的统计查看权限；执行导出时还必须具备新的导出权限。这样可以实现“能查看统计”和“能导出文件”分开授权。

数据库迁移会为以下内置模板和角色补充导出权限：

- 分析检测组长模板
- 部门统计查看员模板
- 分析检测组长
- 部门统计查看员

### 2. 统计数据按角色范围查看

统计角色配置了送样部门范围后，统计页面、统计明细和导出数据统一按该范围过滤，并显示范围内所有检测人员记录，不再默认只显示当前登录人员。

数据范围的主要口径为：

1. 优先按记录的送样部门 `sending_division_id` 过滤。
2. 兼容历史数据中的 `execution_division_id`、`division_id` 和项目组部门字段。
3. 系统管理员或具备“查看全部工作量”权限的账号可查看公司全部数据。
4. 没有配置部门范围的旧角色保留本人数据兼容逻辑。

### 3. 明细列表与汇总统计口径统一

分析检测统计页面的明细接口、聚合统计接口和导出接口采用同一套权限范围判断，避免页面显示数量与导出数量不一致。

检测人员筛选下拉也按当前角色可见范围生成。

### 4. 报表选择与全部导出

- 默认勾选“检测记录明细”和“检测部门-送样部门汇总”。
- 增加“全部报表”选项。
- 选择“全部报表”时不传 `sheet_ids`，后端生成全部 11 张报表。
- 选择指定报表时只生成用户勾选的报表。
- 没有 `stats:workload:export` 权限时，页面隐藏/禁用导出操作并提示无权限。
- 记录明细和检测人员下拉复用检测部门、送样部门及历史数据筛选条件，避免明细与统计卡片口径不一致。
- 导出模板中停用的报表不会被“全部报表”生成；显式选择已停用报表会被后端拒绝。

这里的“全部”是当前账号权限范围内的全部，不代表绕过权限导出全公司数据。
