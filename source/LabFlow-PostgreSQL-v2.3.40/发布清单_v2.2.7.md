## 三、升级指南

### 3.1 从 v2.2.6 升级（推荐）

**适用场景**: 已安装 v2.2.6 或更早版本

**升级步骤**:

1. **备份数据**（可选但推荐）
   ```bash
   # 使用系统内置备份功能
   管理工作区 > 数据备份 > 立即备份
   ```

2. **停止服务**
   - 关闭所有用户浏览器会话
   - 在系统托盘右键点击 "退出"

3. **运行热更新安装包**
   - 双击 `样品管理系统_v2.2.6_权限标签优化版_热更新升级包_Setup.exe`
   - 确认安装路径（默认覆盖原安装位置）
   - 等待安装完成（约 10-30 秒）

4. **启动服务**
   - 桌面双击 "样品管理系统" 图标
   - 或从开始菜单启动

5. **验证升级**
   - 登录系统
   - 检查版本号（右下角或关于页面）
   - 验证核心功能正常

**预计停机时间**: < 2 分钟

### 3.2 全新安装

**适用场景**: 首次部署或更换服务器

**安装步骤**:

1. **准备环境**
   - Windows Server 2016+ 或 Windows 10/11
   - .NET Framework 4.8+
   - 管理员权限

2. **运行服务器版安装包**
   - 双击 `样品管理系统_v2.2.6_权限标签优化版_PostgreSQL服务器版_Setup.exe`
   - 选择安装路径（推荐 C:\LabFlow）
   - 勾选 "安装 PostgreSQL 数据库服务"
   - 勾选 "创建桌面快捷方式"
   - 等待安装完成（约 3-5 分钟）

3. **初始化配置**
   - 首次启动会自动创建数据库
   - 默认管理员账号: `admin`
   - 默认密码: `admin123`（首次登录后强制修改）

4. **网络配置**（可选）
   - 默认端口: 8080
   - 修改配置文件: `C:\LabFlow\config\server.toml`
   - 重启服务生效

**预计安装时间**: 5-10 分钟

## 五、已知问题与限制

### 5.1 已知问题

**无**  
本版本为代码质量优化，未发现已知问题。

### 5.2 限制与注意事项

1. **安装包命名**  
   安装包文件名仍显示 `v2.2.6_权限标签优化版`，但内部版本号为 `v2.2.7`。这是为了保持历史命名约定。

2. **ManagePage 部分变量**  
   由于文件规模较大（1200+ 行），部分简写变量（如 `sm`、`lg`、`lp` 等）尚未完全重构。这不影响功能，但代码可读性仍有提升空间。

3. **Unicode 字符编码**  
   重构过程中修复了 WorkloadPortal.tsx 的 Unicode 字符编码问题，确保所有引号使用标准 ASCII。
