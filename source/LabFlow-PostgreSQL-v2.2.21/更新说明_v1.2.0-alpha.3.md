# v1.2.0-alpha.3 公司级权限第三测试版

## 本版完成

- 新增项目归属部门字段，默认沿用项目主实验室所属部门，也可以在项目管理中明确指定。
- 新增分析检测和研发送样记录的项目归属、执行部门、执行实验室快照。
- 对历史项目和历史记录执行一次性兼容回填。
- 记录列表、单条记录权限、统计、导出和导出预览优先按执行部门快照过滤。
- 新记录、记录编辑、数据治理导入、退回后待修改副本均写入归属快照。
- 保留旧 division_id、group_id 字段作为兼容回退，不改变原有取样、退回、公共账号选人和附件流程。
- PostgreSQL 集成测试配置使用 WORKLOAD_TEST_DATABASE_URL，全量测试通过。
