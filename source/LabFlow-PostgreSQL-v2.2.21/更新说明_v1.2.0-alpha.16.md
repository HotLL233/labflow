# v1.2.0-alpha.16 实际场景阻断修复版

## 本版修复

- 实验室新建时明确初始化所属部门，选择部门后可持久化；选择“未分配”可显式清空所属部门。
- 用户管理仅在后端创建成功后显示成功提示；重复用户名等业务失败保留弹窗并显示原因。
- 样品信息登记将部门、实验室、项目初始化请求分别保留结果；页面可区分组织数据加载失败与当前账号无可用部门。
- PostgreSQL 连接池默认下调为 12 个连接、1 个空闲连接，并支持通过 `db_pool_max_size`、`db_pool_min_idle` 配置部署预算。
- 恢复并完成自助注册路由与后端注册入口；注册账号默认不授予业务角色。

## 验收结果

- 隔离 PostgreSQL `max_connections=20` 下，真实页面连续刷新和跨页面操作无“连接数过多”。
- 已完成注册、部门/实验室、用户创建成功与失败、样品登记、附件上传删除、实验室取消部门归属等页面场景回归。
- `cargo test --lib -- --test-threads=1`：116 通过，0 失败，2 忽略。
