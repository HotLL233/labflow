# LabFlow v2.3.30 更新说明

发布日期：2026-09-30

## 一、本次修复：记录表样式改造的遗留问题

v2.3.29 引入记录表 Excel 化样式后，实际使用中暴露出若干问题，本次一并修复。

### 1. 无法设置列宽

- 原因：v2.3.28 起记录表改用右键列菜单，表头的拖动改宽手柄被移除，`ColumnResizeHandle` 只剩定义、页面里没人用。
- 修复：研发送样记录、样品信息登记记录恢复表头拖动改宽；「表格样式 → 列宽」新增按像素输入与「恢复自动」。
- 拖动与输入框共用同一份数据：拖动结果写入个人视图的列宽，输入框会同步显示，反过来也一样。

### 2. 表头下滑无法冻结

- 原因：页面为了让表头放右键菜单/拖动手柄，给表头单元格单独设了 `position: relative`。它与 MUI `stickyHeader` 的 `position: sticky` 选择器优先级相同，谁后注入谁生效，于是吸顶时有时无。
- 修复：样式引擎用「表头单元格 + stickyHeader 类」两级选择器强制吸顶，优先级更高，不再被页面的相对定位覆盖；同时补上不透明底色，滚动时行内容不会透到表头后面。
- 「表格样式 → 表格」提供「冻结表头」开关，默认开启。

### 3. 配置常驻占用页面，改为收进一个按钮

- 「表格样式」按钮 → 右侧抽屉，平时只占一个按钮位置。
- 抽屉内按「列显示 / 表格 / 样式范围 / 列宽 / 日期格式 / 文字与对齐 / 条件格式 / 保存方式」分区。

### 4. 发布全局仅系统管理员

- 发布条件由「管理员或有页面与录入表单配置权限」收紧为**仅系统管理员**（`user.is_admin`）。
- 非管理员的修改只保存在本机个人视图，抽屉内会明确提示。

### 5. 日期时间显示格式可配置

- 新增按列配置的日期格式：`2026-09-30`、`2026/09/30`、`2026年09月30日`、`09-30`、`2026-09-30 14:30`、`2026/09/30 14:30`、`14:30`，以及「默认格式」。
- 生效列：研发送样的录入时间 / 取样时间，样品信息登记的送样日期 / 检测日期 / 取样日期，分析检测的录入时间。
- 未配置时完全沿用原来的显示方式，不影响历史观感。

### 6. 恢复列显示 / 隐藏入口

- v2.3.28 起「列设置」按钮被移除，普通用户失去隐藏列的入口。
- 修复：抽屉「列显示」分区提供全部列的勾选列表，含「全部显示」，已显示数量实时显示。
- 三套记录页都生效（分析检测今日记录表同时改为按列定义驱动渲染，才能支持隐藏列）。

### 7. 选择框列可显示 / 隐藏

- 抽屉内新增「选择框列」开关（研发送样记录），关闭后表头与表体的复选框列一并隐藏，列宽不再被占用。
- 同时提供「序号列」开关。

### 8. 样品信息登记记录页上下滑动发卡

- 原因一：桌面端与移动端两套列表同时渲染，移动端卡片用 `display: none` 隐藏但仍会创建整份记录 DOM 与样式（每页 20 条 × 十余个字段）。
- 原因二：每个单元格每帧都会新建样式对象（内层容器的换行样式对象、日期格式分支的展开对象）。
- 修复：
  - 窄屏才渲染卡片列表（`useMediaQuery`），桌面端不再创建重复 DOM。
  - 单元格文本流样式改为按「列 + 行」缓存的解析器输出，未配置换行时直接复用模块级常量对象，不再逐格新建。
  - 每行的字段值只计算一次，列筛选与条件格式共用，避免重复测量。
