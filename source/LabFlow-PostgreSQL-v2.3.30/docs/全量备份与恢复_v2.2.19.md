# v2.2.19 全量备份与恢复

## 备份内容

`full` 模式包含 PostgreSQL 数据库、附件、附件预览、帮助文档和人员变动文件。备份 ZIP 内的 `backup_manifest.json` 会校验每个文件的大小和 SHA-256。

备份目录和临时恢复文件不会被递归打包。配置以快照形式保存，恢复时不会自动覆盖当前部署配置。

## Docker 路径

Compose 为以下目录设置了持久化路径：

```text
/app/data/attachments
/app/data/attachment_previews
/app/data/help_docs
/app/data/personnel-change-data
/app/data/backups
```

## 旧版本兼容

v2.2.18 的 ZIP 可以直接导入。旧 ZIP 没有预览和人员变动目录时，新版本会保留当前对应目录；新版本 ZIP 则会完整替换其中声明的目录。
