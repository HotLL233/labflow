# LabFlow v2.3.45 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.45.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.45-HotUpdate.exe`，仅用于已安装完整服务器版的升级。
- Windows 产品和文件版本：`2.3.45.0`。本地产物 SHA-256 见同目录 `installer/local-packages-sha256.json`；仓库根 `installers/` 为 CI 正式发布包，校验值以 GitHub Release 资产 digest 为准。
- 默认程序端口为 8000；实际端口、数据位置与初始管理员密码以安装向导和已有配置为准。升级保留已有账号密码与业务数据。
- Docker 镜像由 GitHub 工作流发布 `ghcr.io/hotll233/labflow:2.3.45`，部署配置位于仓库根 `docker-compose.deploy.yml`。

## 本次变化

研发送样记录新增送样时间筛选，默认全部时间；支持本周、上周、近7天、自定义日期区间及前后周切换。结束日期包含当天全部时间，服务端筛选与计数先于分页。

分析实验室卡片新增送样记录入口；实验室顶部增加“工作量录入 / 本实验室送样记录”。默认仍为原工作量页面，同实验室切换保留数量、倍率、录入日期及记录筛选；有未提交数量或倍率时返回门户、切换账号和关闭页面会提示。

新查看权限为 `records:rd:view-work-lab`，固定当前实验室并叠加检测部门范围；一次性为分析系统角色及分析模板来源角色补齐，撤权后不会在每次启动重新授予。取样、退回、撤回、工作量、编辑和确认退回继续使用原权限；新查看权限本身不授予操作能力。保留手机网格、内外边框、摘要/列/按钮配置与桌面一页显示全部列。长实验室名称不再撑宽手机分析门户。

## 升级与恢复

升级前按既有流程保存数据库及附件备份，再运行完整包或热更新包。备份恢复的数据库清空、导入、关键表校验处于同一事务；附件保留暂存内容供重试。数据库和文件不是整体事务，恢复失败会停止启动，排除错误后重启完成同一恢复任务，不能删除待恢复标记强行继续业务。
