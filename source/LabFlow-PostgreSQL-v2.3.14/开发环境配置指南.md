# LabFlow v2.2.5 开发环境配置指南

## 系统要求

### 必需软件
- **Rust**: 1.75+ (推荐使用 rustup 安装)
- **Node.js**: 18+ (推荐 20 LTS)
- **PostgreSQL**: 18 (仅开发测试需要，构建不需要)
- **Inno Setup**: 6.7.3 (仅打包安装程序需要)

### 可选软件
- **Git**: 版本管理
- **VS Code**: 推荐 IDE，配合 rust-analyzer 和 ESLint 插件

---

## 快速开始

### 1. 安装 Rust
```bash
# Windows (PowerShell)
winget install Rustlang.Rustup

# 或访问 https://rustup.rs/ 下载安装
```

验证安装：
```bash
rustc --version
cargo --version
```

### 2. 安装 Node.js
```bash
# Windows (PowerShell)
winget install OpenJS.NodeJS.LTS

# 或访问 https://nodejs.org/ 下载安装
```

验证安装：
```bash
node --version
npm --version
```

### 3. 安装前端依赖
```bash
cd frontend
npm install
```

### 4. 验证环境
```bash
# 后端类型检查
cargo check

# 前端类型检查
cd frontend
npm run typecheck
```

## 开发流程

### 前端开发
```bash
cd frontend

# 开发模式（热重载）
npm run dev

# 类型检查
npm run typecheck

# 生产构建
npm run build
```

构建产物位于 `backend/static/`

### 后端开发
```bash
# 开发模式编译
cargo build

# 运行程序
./target/debug/workload-tool.exe

# Release 构建
cargo build --release

# 可执行文件位于 target/release/workload-tool.exe
```

### 完整构建流程
```bash
# 1. 构建前端
cd frontend
npm run build

# 2. 构建后端
cd ..
cargo build --release

# 3. 测试运行
./target/release/workload-tool.exe
```

## 打包安装程序

### 前置准备
1. 完成上述完整构建流程
2. 安装 Inno Setup 6.7.3: https://jrsoftware.org/isdl.php
3. 确保以下运行时依赖就位：
   - `pdf-runtime/` - PDF 预览组件（poppler 库）
   - `postgres-runtime/` - PostgreSQL 18 运行时
   - `icon.ico` - 应用图标
   - `config.example.toml` - 配置模板
   - `installer-languages/ChineseSimplified.isl` - 中文语言包

### 构建安装包
```bash
# 完整安装包（含 PostgreSQL）
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build_server_installer.iss

# 热更新包（不含 PostgreSQL）
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build_hot_update_installer.iss
```

生成的安装包位于 `installer/` 目录

### 计算校验和
```bash
cd installer
sha256sum *.exe
```

## 常见问题

### Rust 编译失败
1. 检查 Rust 版本：`rustc --version`（需要 1.75+）
2. 更新 Rust：`rustup update`
3. 清理缓存：`cargo clean`

### 前端构建失败
1. 检查 Node.js 版本：`node --version`（需要 18+）
2. 删除 `node_modules` 和 `package-lock.json`，重新 `npm install`
3. 检查 TypeScript 错误：`npm run typecheck`

### 运行时错误
1. 确保 PostgreSQL 服务正在运行
2. 检查配置文件 `config.toml` 中的数据库连接信息
3. 查看日志输出排查问题

### 打包失败
1. 确认 `target/release/workload-tool.exe` 存在
2. 确认 `backend/static/` 目录包含前端构建产物
3. 确认 `pdf-runtime/` 和 `postgres-runtime/` 依赖完整
4. 检查 Inno Setup 编译器输出的错误信息

## 版本管理

### 更新版本号
同时修改以下文件：
1. `Cargo.toml` - `version = "x.x.x"`
2. `frontend/package.json` - `"version": "x.x.x"`
3. `build_server_installer.iss` - `#define MyAppVersion "x.x.x"`
4. `build_hot_update_installer.iss` - `#define MyAppVersion "x.x.x"`

### 发布流程
1. 更新版本号
2. 完整构建前端和后端
3. 生成两个安装包
4. 计算 SHA-256 校验和
5. 更新 `发布清单_vx.x.x.md`
6. 测试安装包功能

## 开发建议

### 代码风格
- **Rust**: 使用 `cargo fmt` 格式化代码
- **TypeScript**: ESLint + Prettier（配置已包含在项目中）

### 提交前检查
```bash
# 后端
cargo check
cargo fmt --check

# 前端
cd frontend
npm run typecheck
npm run build
```

### 数据库迁移
修改数据库结构后：
1. 更新 `src/repo/` 中的 SQL 创建语句
2. 添加迁移逻辑到 `src/repo/migration.rs`（如有）
3. 测试升级兼容性
