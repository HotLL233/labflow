# LabFlow v2.3.31 更新说明

发布日期：2026-09-30

## 一、本次修复：窄屏 / 手机端同步记录表样式

v2.3.30 的样式改造只覆盖了桌面表格：窄屏走卡片列表，既没有配置入口，也没有应用样式。本次把两端补齐。

### 修复前的问题

- 研发送样记录、样品信息登记记录两页的「表格样式」按钮与桌面表格一起被 `display: none` 隐藏，手机上无法进入配置。
- 窄屏卡片列表是另一套渲染分支，只跟随了「列显示 / 隐藏」和「日期格式」，列级颜色、加粗、填充、对齐与条件格式都不生效。
- 卡片列表的选择框没有跟随「选择框列」开关。
- 分析检测登记页因为窄屏仍用同一张表，所以那页本来就是生效的。

### 本次完成

- 两页的「表格样式」入口移出桌面专用容器，手机与窄屏同样可见；抽屉宽度自适应（窄屏占 92% 屏宽）。
- 样式引擎新增两组输出：
  - `visualSx`：只取字体、字号、颜色、底色、对齐等“看得见”的属性，供卡片里的字段容器复用（不搬边框与内边距，避免卡片出现双边框）。
  - `rowSx`：整行容器样式，含行级手工样式与命中的「整行」条件格式（底色 + 左侧色条）。
- 卡片列表接入：
  - 每张卡片的容器应用整行底色与左侧色条（研发送样、样品信息登记）。
  - 卡片内每个字段块应用该列的字体 / 颜色 / 填充 / 对齐 / 换行。
  - 日期格式在卡片上同样生效（本来就走同一渲染函数）。
  - 研发送样的卡片选择框跟随「选择框列」开关。
- 窄屏下抽屉里不适用的项置灰并给出说明：行高、表头行高、列宽、斑马纹、冻结表头——卡片布局没有这些结构。

### 生效范围对照

| 项目 | 桌面 ≥1200px | 窄屏 / 手机 |
|---|---|---|
| 「表格样式」配置入口 | 有 | 有（本次补齐） |
| 列显示 / 隐藏 | 生效 | 生效 |
| 日期显示格式 | 生效 | 生效 |
| 列级字体 / 颜色 / 填充 / 对齐 | 生效 | 生效（本次补齐） |
| 条件格式整行高亮 / 左侧色条 | 生效 | 生效（本次补齐） |
| 选择框列开关 | 生效 | 生效（本次补齐） |
| 行高 / 表头行高 / 列宽 / 斑马纹 / 冻结表头 | 生效 | 不适用，抽屉内已置灰说明 |
