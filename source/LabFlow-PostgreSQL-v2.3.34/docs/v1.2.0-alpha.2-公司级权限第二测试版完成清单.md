# v1.2.0-alpha.2 公司级权限第二测试版完成清单

## 本测试版已完成

1. 用户主归属部门字段。
2. 用户可承担业务部门多选字段。
3. 主归属部门必须属于可承担业务部门。
4. 用户管理页面展示和编辑两个部门关系。
5. 部门筛选按可承担业务部门执行，并兼容旧用户字段。
6. 创建和更新用户接口支持新字段。
7. 用户仓储保存 `user_divisions.is_primary` 的明确主部门标记。
8. 旧用户部门数据迁移和兼容。
9. 批量导入模板改为主部门与业务部门分列。
10. 批量导入兼容旧模板表头。
11. 修复非分析公共账号部门字段可能被重新写回的问题。
12. alpha.2 版本号、热更新备份目录和安装包名称隔离。

## 本测试版尚未完成

1. 部门角色独立模型和用户与部门角色的正式绑定重构。
2. 项目、送样、执行部门和执行实验室的归属字段补齐。
3. 业务记录归属快照，避免后续用户部门变化影响历史口径。
4. 历史数据归属确认和修正页面。
5. 跨部门协作、转交和审批规则。
6. 统计口径在“主归属部门/业务部门/执行部门”之间的切换。
7. 所有导出接口统一使用公司级部门口径。
8. 权限审计总览和部门管理员边界控制。
9. 全量历史数据治理和正式上线前的组织权限验收。
