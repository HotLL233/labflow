# LabFlow v2.3.34 更新说明

发布日期：2026-10-01

## 一、本次优化：记录页布局判定改为按设备，并支持手动切换

### 背景

此前卡片 / 表格的判定用的是**视口宽度**（`max-width: 1199.95px`）。手机浏览器开启
「桌面网站」后，浏览器会忽略页面的 viewport 声明、改用约 980px 的布局视口，
仍然小于 1200，于是**手机开 PC 标识依然只能看到卡片**。要让这种情况显示 PC 布局，
判定必须以设备类型为准。

### 本次完成

1. 新增布局规格 `layout.mode`，取值：
   - `auto`（默认）：**移动设备用卡片、桌面设备用表格**。
   - `card`：强制卡片。
   - `table`：强制表格。
2. 新增 `useCardLayout`（`components/recordTable/useCardLayout.ts`）与判定函数
   `resolveCardLayout` / `detectMobileDevice`（`utils/recordTableStyle.ts`）：
   - 设备识别只认真正的移动 UA（Android / iPhone / iPad / HarmonyOS / Mobile 等）；
     iPadOS 13+ 上报桌面 UA，用触点数兜底。
   - 手机开启「桌面网站」后上报的是桌面 UA，因此按桌面处理 → **显示与 PC 一致的表格**。
   - 仅当视口极窄（< 768px）时才兜底回落到卡片，避免桌面端把窗口拖得很窄时
     把十几列硬塞进不可读的宽度。
3. 「表格样式」抽屉新增「布局」分区（自动 / 卡片 / 表格），可手动覆盖自动判定。
   该设置同样走「个人视图 / 全局样式」体系：普通用户改的是本机自己的视图，
   管理员可以发布为全局默认。
4. 分析检测登记页（`EntryPage`）只有表格一种布局，抽屉里不显示布局开关，
   避免出现「切了没反应」的困惑。

### 生效效果

| 使用场景 | 改动前 | 改动后 |
|---|---|---|
| 手机正常浏览 | 卡片 | 卡片 |
| 手机开「桌面网站」 | 卡片 | **表格（与 PC 一致）** |
| 电脑 ≥1200px | 表格 | 表格 |
| 电脑 768～1200px 窗口 | 卡片 | 表格（窗口更窄时可在抽屉里手动切卡片） |
| 电脑 < 768px 窗口 | 卡片 | 卡片 |

> 提示：手机上看表格需要横向滚动，字号也会比卡片小，这是「与 PC 一致」必然的代价。
