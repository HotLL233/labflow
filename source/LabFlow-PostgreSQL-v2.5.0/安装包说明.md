v2.5.0 已发布至 [GitHub Release](https://github.com/HotLL233/labflow/releases/tag/v2.5.0)，Release ID 为 `444203920`。提供完整安装包和热更新包，数字版本 `2.5.0.0`，发布者 HotLL；软件内名称及管理员品牌配置保留。镜像仅发布至 GHCR。

## 下载与启用

1. 升级前使用原备份入口保存业务数据。Windows 首次安装使用 [labflow-v2.5.0.exe](https://github.com/HotLL233/labflow/releases/download/v2.5.0/labflow-v2.5.0.exe)；已有完整运行环境升级使用 [labflow-v2.5.0-hotupdate.exe](https://github.com/HotLL233/labflow/releases/download/v2.5.0/labflow-v2.5.0-hotupdate.exe)，先从托盘完全退出程序，再按原安装流程升级，保留原数据与配置。
2. Docker 使用 `ghcr.io/hotll233/labflow:2.5.0`，在现有部署配置中更新镜像并保留原数据库、附件及持久卷；本次不发布 Docker 离线镜像包。复现本次镜像可固定为 `ghcr.io/hotll233/labflow@sha256:0b8ef81e2185b5b8a094721c4accddff3effed9863cd0576c019072b66db7bcb`。
3. AI **默认关闭**。系统管理员进入“系统管理 → AI 助手”，配置上游、获取或手填模型，保存后分别完成 hi、流式及工具测试，再启用需要的能力。地址可达不代表模型可用；业务工具需要工具测试通过。
4. 在“角色权限管理”中为需要的角色授予“使用 AI 助手”（`ai:use`）。旧角色业务权限与范围保留，不自动授予 AI 资格；业务查询和草稿继续取原权限交集。语音服务在“语音输入”页单独配置与测试。

助手入口在头像旁。默认不附带整页业务数据；查询需使用者允许发送到所选模型服务并确认日期。四类草稿仍需带入原表单复核，再按原按钮提交。辅助工作不分摊实验室或项目、不计算金额。

密钥保存在服务端独立私密目录，不放通用设置或浏览器持久存储，常规升级保留。**AI 私密配置不纳入业务数据库备份或标准全量业务备份**，换部署主机恢复后需管理员重新配置并测试。远程电脑或手机录音需要受信任 HTTPS；局域网 HTTP 无法录音时可打字或选择本地短音频。录音每段最多 60 秒、10MB，具体格式及转写能力取决于浏览器与语音服务。
