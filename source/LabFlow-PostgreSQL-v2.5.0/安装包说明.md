# labflow v2.5.0 安装包说明

本地开发验证及两份安装包构建已完成，正在正式发布。正式 Release/GHCR 状态将在实际取回核验后补充；上一版本验收不沿用为本版证据。

计划提供 labflow-v2.5.0.exe 完整包和 labflow-v2.5.0-hotupdate.exe 热更新包，数字版本 2.5.0.0，发布者 HotLL。软件内名称及管理员品牌配置保留。

AI 默认关闭。启用后，系统管理员配置模型服务并测试，再为需要使用的角色授权“使用 AI 助手”。语音服务单独配置。局域网 HTTP 无法申请浏览器麦克风时，可使用音频文件转写；录音需 HTTPS 或浏览器认可的本机安全环境。

业务查询按原权限执行，草稿交由原表单确认。普通问答不默认附带整页业务数据。密钥保存在服务端独立私密目录，不放通用系统设置或浏览器持久存储，升级保留；该凭据目录和云备份授权一样不纳入业务全量备份，换部署主机后由管理员重新配置。

实际模型服务、音频识别、麦克风权限及现场升级效果需结合部署环境验收。自动化验证的模拟上游不代表真实供应商验收。

本地最终 All Build 通过：前端313项、后端最终隔离库427项通过（3项备份恢复忽略），AI HTTP 52项、原方法/送样人36项、权限及真实v2.4.14→v2.5.0升级96项通过。生产静态配合合成API浏览器11组通过；AI协议与转写上游均为本机模拟服务。四类原表单转填已纳入313项前端测试，不重复累计。

本地输入、程序及静态摘要见[实施与验收对照](../../docs/ui-ai-assistant/v2.5.0-实施与验收对照.md)。现场升级、安装/卸载生命周期、实机麦克风、真实供应商、完整Excel报表和全量备份恢复未执行；本次不连接生产数据库或8000。
