# labflow v2.5.0 更新说明

本版按 AI Agent 与语音业务助手方案实施，正式交付状态与验证范围见根 README.md 和本版安装包说明。

- 管理员集中维护多个模型上游、可用模型和默认模型，分别执行地址、hi、流式和工具测试。支持获取模型及手工填写模型 ID。
- 头像旁增加实验瓶形象的 AI 助手入口；桌面侧栏、手机全屏，不改变原业务页面布局。
- 业务工具遵循现有权限和范围，查询与工作量汇总复用原接口；辅助工作保持独立区域、事项和统计口径，不计实验室、项目或金额。
- 对话整理填报草稿后带入原表单，用户检查后按原按钮提交；公共账号实际送样人仍需确认，AI 不直接创建记录或发送业务通知。
- 语音服务独立配置，支持短录音或音频文件转写，识别文字可修改后使用。
- 新增 ai:use 使用资格，不自动修改旧角色授权。配置仅系统管理员可维护，密钥使用服务端私密文件，浏览器只显示是否已配置。

既有权限、人员归属、来源链、历史快照、自定义配置及程序内品牌保持兼容。AI 默认关闭，不升级或安装生产服务，不重算历史业务记录。
