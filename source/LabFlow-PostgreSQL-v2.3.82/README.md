# LabFlow v2.3.82：备份文件名简化

本版承接 v2.3.81，移除新备份文件名末尾的32位随机标识。例如全量备份由 `workload_full_20261101_103637_2a55814b0e9c4a6fa4021aed962b1c23.zip` 简化为 `workload_full_20261101_103637.zip`。名称已被备份文件或未完成的临时文件占用时，自动追加 `_2`、`_3`，不覆盖已有文件。

手动、自动、全量、数据库及维护安全备份共用此命名规则。旧备份不改名；包格式、清单校验、下载、云端传输、保留策略和恢复入口保持兼容。本地验证、安装包和发布情况见本版《安装包说明.md》及根 PROJECT_MEMORY.md。

## 接入类型

| 类型 | 连接方式 | 前置条件 |
| --- | --- | --- |
| 坚果云 | 官方 WebDAV、账号与应用密码 | 使用具体备份子目录；默认 `/dav/LabFlowBackups/` |
| OneDrive 全球版个人/工作或学校账号 | 微软 Graph 与官方设备授权 | 注册公共客户端应用，填写 Client ID，账号已有 OneDrive |
| Nextcloud / ownCloud | 服务器提供的 HTTPS WebDAV | 完整用户目录地址和应用密码 |
| OpenList | 已授权网关的 WebDAV | 网关先挂载网盘，使用网关账号密码及可写目录 |
| 百度 / 阿里云盘 / 夸克 | 经 OpenList 网关的 WebDAV | 不是原生账号登录；网关和服务商必须支持所需读写 |
| 其他 HTTPS WebDAV | 通用协议 | 服务提供标准目录、上传、下载及删除能力 |

所有类型共用现有任务、备份包、SHA-256清单、取回校验、下载和恢复流程。一次配置一个当前目标，切换不会把旧任务静默转发到新账号或目录。

## WebDAV 设置

入口：“系统管理 → 数据备份 → 云端设置”。选择类型，填写目标目录、账号、应用密码。坚果云类型会将 `/dav/` 根入口规范为默认备份子目录；通用类型误填坚果云根入口时测试会明确提示，仍可只读查看根目录。

“测试当前配置 / 创建目录”使用本次输入，不先保存账号密码；可验证鉴权并创建最后一级备份目录，父目录需已存在且可读取。成功后仍需“保存”才会应用到后台任务。测试会上传、回读、删除一个小文件，不能证明大文件配额足够。更换目标仍须重新输入密码。

Nextcloud常见格式为 `https://服务器/remote.php/dav/files/用户名/LabFlowBackups/`；OpenList常见格式为 `https://网关/dav/挂载名/LabFlowBackups/`，具体地址以实际服务器为准。不能填网盘网页或分享链接。

程序按HTTP状态分别提示401鉴权、403权限、404路径、413大小、429限流、507空间，不再混合描述。支持WebDAV文件下载跳转，跨域后不会转发网关Basic凭据，不允许跳转降级为明文HTTP。

## OneDrive 授权

1. 在 Microsoft Entra 应用注册中创建自己的应用，按需允许个人/组织账号，复制“应用程序(客户端) ID”。
2. 应用须允许公共客户端/设备授权流程；配置 Microsoft Graph 委托权限 `User.Read`、`Files.ReadWrite`，授权时包含 `offline_access`。不需要在 LabFlow 输入客户端密钥。
3. 选择“OneDrive（微软官方授权）”，填写 Client ID、租户（默认 `common`）和相对备份目录（默认 `LabFlowBackups`）。
4. 点击“保存并授权 OneDrive”，在微软页面输入显示的授权码并确认账号。保持本窗口开启，等待程序显示授权成功，再测试或上传。
5. 租户策略禁止用户同意或未开通应用时需管理员允许；未配置或授权失败不会绕过组织策略。世纪互联版暂未适配。

令牌只保存在服务器私有目录，前端仅显示账号和授权状态；临近过期时使用刷新授权。刷新不会覆盖较新的登录或恢复已断开的授权。切换账号、应用、租户或目标目录后，旧任务按原目标校验，不会自动换目的地。

大文件使用10MiB分片，记录私有上传会话，重试或程序重启后查询微软实际断点续传；会话到期后重新上传。云端取回不携带Graph Bearer访问下载CDN。断开授权只清除本部署令牌，不删除云端数据，也不替用户撤销微软账号中的应用同意。

## 安全与兼容

沿用 `manage:backup`、备份回收站、覆盖恢复前安全快照、业务权限、统计与历史数据。未新增业务数据库迁移。v80配置缺少新字段时按WebDAV兼容，原目标指纹保留。

私有配置、微软设备码、访问/刷新令牌和分片会话位于数据目录 `cloud-backup/`，不加入全量ZIP，也不随旧数据库恢复回退。Windows使用私有目录ACL，Unix文件权限0600；接口和审计不返回令牌或应用密码。

实际服务商的单文件、容量、流量、速率及网关能力需独立验证。云端大小核对不等于完整回读校验；取回后才按SHA-256和包清单验证。最终迁移备份仍应暂停业务写入；云端协议不会把数据库和附件变为同一事务快照。
