# LabFlow v2.3.82 更新说明

本版承接 v2.3.81，针对备份名称过长做局部调整，不增加依赖、配置项或数据库迁移。

## 备份文件名

- 新全量备份名称为 `workload_full_20261101_103637.zip`，移除末尾的32位随机标识。
- 手动数据库、自动数据库、自动全量以及维护安全备份同步采用“原类型前缀 + 日期时间 + 扩展名”。
- 同一秒名称已被已有备份或 `.part` 临时文件占用时，依次追加 `_2`、`_3`；沿用原有备份与维护互斥锁。
- 旧备份不重命名、不删除；新旧名称均可通过现有备份文件名校验。

## 兼容范围

不改变全量ZIP内部结构、数据库快照、SHA-256清单、浏览器下载、云端上传取回、自动备份周期、保留份数、回收站或恢复流程。保留v81已有网盘入口、OneDrive授权、业务功能和自定义配置。

## 验证

新增文件名回归覆盖短名称、已有文件、未完成写入、四种类型前缀及旧文件保留；扩展现有云端名称校验用例。实际构建、专项测试和安装包结果见本版《安装包说明.md》。
