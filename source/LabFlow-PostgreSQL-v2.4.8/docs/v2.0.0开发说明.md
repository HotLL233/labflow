# v2.0.0 正式版开发说明

## 变更范围

本版本仅处理登录页注册入口显示问题：移除登录页底部“还没有账号？注册”可见区域，并移除该页面不再使用的前端路由链接依赖。

## 保持不变的功能

- 注册页面路由、用户注册 API、管理员用户管理和现有权限逻辑未修改。
- 登录、保持登录、记住密码、会话管理及所有业务页面未修改。
- 数据库结构、数据迁移、人员变动通知和样品信息登记未修改。

## 版本隔离

源码、Cargo 包、前端包、锁文件、安装脚本和安装包命名统一使用 v2.0.0。完整服务器安装包继续包含 PostgreSQL、PDF 运行时和 VC++ 运行库；热更新包仅更新程序和静态资源。
