# labflow v2.4.8 更新说明

本版验证、安装包与正式发布状态见同目录《安装包说明.md》。

按已确认的后台布局方案整理管理总览、主数据、方法、辅助配置、角色权限、通知、字段与备份页面。

- 统一管理外壳、页头和带边框的返回按钮，通知、角色、辅助配置、业务数据管理及公告沿用同一导航。保留四组菜单、权限过滤与侧栏收起设置。
- 管理栏目直接由当前路由决定，避免只拥有部分管理权限的账号直达页面时被默认项目栏目误拦截；原栏目权限条件不变。
- 管理总览桌面两列分组；主数据页消除重复标题，桌面使用工作表目录，手机保留滑动页签与局部表格滚动。
- 方法工具栏自然换行；手机补齐类型、系数、倍率和单价。辅助事项新增本地关键词／区域筛选与手机紧凑列表，稳定事项 ID 继续仅供程序及 Excel 识别。
- 角色页将标题和操作分层，手机使用紧凑记录，保留模板、权限、数据范围、内置角色保护及原编辑删除操作。
- 通知页补齐管理导航与页内定位；五项状态概览桌面同排。完整模板编辑器通过窗口维护，关闭后保留当前页面草稿，刷新、隐藏字段恢复和示例预览均沿用原流程。
- 字段配置宽屏并排显示预览、窄屏上下布局；字段顺序、类型、列宽、范围及必填仍使用原编辑流程。切换表单前提示未保存修改。
- 备份文件与云端任务优先展示，自动备份设置可定位；原下载、恢复、确认、云端授权及删除保护继续保留。

不新增数据库迁移，不修改业务接口、权限规则、统计口径或历史数据。现有品牌、主色、圆角、字号、列配置及操作按钮配色继续继承。

本版实际验证、安装包和发布状态见《安装包说明.md》。
