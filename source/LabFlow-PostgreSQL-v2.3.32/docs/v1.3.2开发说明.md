# v1.3.2 开发说明

## 修复范围

本版本只修复人员变动通知功能的三个问题：方法输入框焦点、通知目标数据库约束、人员反馈字段自定义配置。所有改动均在 v1.3.1 隔离目录内完成。

## 数据库兼容

新增幂等迁移 `1.3.2-personnel-feedback-notification-target`，删除旧通知目标检查约束并重建为包含 `personnel_change_feedback` 的约束。不会新增人员反馈业务表，也不修改现有业务数据。

## 配置能力

管理员可在“管理入口 → 系统配置 → 人员反馈字段”中维护变动类型和字段，字段支持显示名称、类型、适用变动类型、必填、进入通知、启停和自定义字段新增/删除。自定义启用且进入通知的字段自动出现在通知模板字段候选中。
