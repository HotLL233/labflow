# LabFlow v2.3.32 更新说明

发布日期：2026-09-30

## 一、本次新增：卡片内外框配色与每页行数配置

### 1. 手机卡片内外框颜色分开配置

- 「表格样式 → 手机卡片」新增一组独立配置：
  - 卡片外框：颜色 + 线宽
  - 卡片底色
  - 字段块外框：颜色 + 线宽
  - 字段块底色
- 外框与内框各自独立，可做成「外深内浅」的层次；线宽设为 0 即为无边框。
- 沿用原有优先级：整行条件格式命中的底色与左侧色条仍优先于卡片默认色，状态色条（待取样红 / 待检测黄 / 已检测绿）在没有规则命中时保留。
- 桌面表格的边框配色不受影响，「表格 → 边框颜色」与「手机卡片」两组配置各自作用于自己的布局。

### 2. 每页行数可配置

- 「表格样式 → 分页」新增「每页行数」：页面默认 / 20 / 50 / 100 / 200。
- 三套记录页都已接通：
  - 研发送样记录（`RdRecordsPage`）
  - 样品信息登记记录（`SampleInfoEntry` + `SampleInfoRecordList`，取数由父页面发出，已按新条数重新请求）
  - 分析检测登记今日记录（`EntryPage`）
- 切换后自动回到第一页重新取数，不会停在已不存在的页码上。
- 默认值为「页面默认」，即沿用改造前各页面自己的每页条数，升级后请求量不会变化。
- 该设置同样遵循「个人视图 / 全局样式」体系：普通用户改的是本机自己的视图，管理员可以发布为全局默认。

## 二、安装包

- 完整安装包：`installer/LabFlow-v2.3.32.exe`
- 热更新包：`installer/LabFlow-v2.3.32-HotUpdate.exe`

已有环境使用热更新包，全新安装使用完整安装包。
