# LabFlow v2.3.80：备份下载与 WebDAV 云端备份

正式发布和本地交付状态见根 README、PROJECT_MEMORY.md 和本版《安装包说明.md》。

## 使用入口

有 `manage:backup` 权限的账号进入“系统管理 → 数据备份”。

1. 保留原有数据库/全量模式、自动间隔、保留份数、同步目录、恢复与回收站。
2. “下载最新全量备份”仅下载最近的全量 ZIP；单个数据库/全量包在“本地备份”列表下载。
3. “云端设置”填写已创建的 HTTPS WebDAV 备份目录 URL、账号和应用密码，保存后测试已保存配置的读写。
4. 建议首次关闭自动上传，使用一份测试备份完成上传、取回和校验，再开启“新备份完成后自动上传”。
5. “传输任务”显示尝试次数与失败原因，失败任务可重试或取消。取消不删除文件；关联任务未完成时，本地备份不会被清理。
6. “云端备份 → 读取云端目录”直接读取专用目录。取回经完整校验后，才可在本地列表下载或选择恢复。
7. 恢复仍须用户确认并重启，属于覆盖恢复。Windows和Docker的配置、数据路径继续按当前部署保留。

## 范围和限制

- 首期仅 HTTPS WebDAV；不依赖桌面网盘客户端，Windows与Linux使用同一服务实现。
- 服务商可能限制单文件大小、流量或调用次数。读写测试只验证小文件；大包须用实际网盘账号测试。
- 上传成功先核对远端大小，SHA-256及包内容在取回时校验。校验清单用于完整性检测，不是签名，不能防止有网盘写权限的人同时篡改文件及清单。
- 原有“同步目录”只确认复制成功，云端状态以本轮新增的传输任务为准。
- 新云端凭据与任务保存在 `WORKLOAD_DATA_DIR/cloud-backup/`，不纳入全量 ZIP；迁移时重新授权。全量包仍包含业务数据和既有通知等配置，应保存在受控目录。
- 下载授权有效10分钟；已开始的传输继续完成，失效后需要重新点击下载。浏览器上传恢复仍限制2GiB，超出可使用服务器云端取回入口。
- 停用网盘只阻止后续任务，已经开始的传输不会强制中断。远端数据不会自动删除。
- 最终迁移备份应暂停新增、修改、删除及附件上传，避免数据库和文件在不同时间点生成快照。

## 开发与部署

沿用根共享 `scripts/prepare-local-build.ps1`、`scripts/verify.ps1` 和 `scripts/build-installers.ps1`，使用 PowerShell 7、隔离测试 PostgreSQL及共享构建缓存。生产静态文件在 `backend/static`，Docker使用同版本镜像，禁止复制旧版可执行文件充当本版产物。
