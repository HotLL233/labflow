# LabFlow v2.3.80 更新说明

本版承接 v2.3.79，升级数据备份，不改动业务数据库结构、工作量计算、权限定义、历史快照和既有自定义配置。

## 备份下载

- 数据备份页增加“下载最新全量备份”和逐文件下载，数据库包仍为 `.dump`，全量包仍为 `.zip`。
- 原生浏览器流式下载，服务端支持 Range；使用限定文件、10分钟有效的随机下载授权，不在 URL 中暴露登录 JWT。
- 下载请求重新核查当前账号、会话和 `manage:backup` 权限，记录发起下载的审计。

## WebDAV 云端副本

- 数据备份页增加本地备份、云端备份、传输任务和云端设置；保留原有自动备份、份数、同步目录、恢复和回收站。
- 首期支持 HTTPS WebDAV；仅本机回环地址允许 HTTP，供隔离测试使用。使用已创建的专用备份目录及服务商的应用密码。
- 保存配置后可测试小文件上传、回读、删除；测试不保证实际备份满足套餐大小、配额及速率限制。
- 新备份可自动排队上传；也可单独上传已有备份。任务落盘、上传下载独立后台执行，最多自动尝试3次，失败后可人工重试或取消。
- 同一个目标、文件和方向的未完成任务去重。修改网盘地址或账号不会将旧任务静默转发到新目标。
- 上传核对远端大小，最后发布 SHA-256 校验清单；“已上传”不表示已回读完成全量校验。
- 云端存在同名包时核对原清单；同内容复用，不同内容或异常清单拒绝覆盖。
- 可从网盘直接读取目录，即使本地任务记录不存在，也能发现已发布校验清单的备份。
- 取回采用服务器流式下载，校验大小、SHA-256和备份内容后才进入本地列表，不覆盖同名但内容不同的本地文件。取回不自动恢复数据库。
- 上传中、排队中或失败待处理的任务保护对应本地备份，自动清理和手动删除均不能提前移除。取消任务只解除保护，不删除备份。
- 首期不自动删除远端数据，不支持其他网盘的专有 API，也不承诺任意 WebDAV 服务器支持断点上传；失败时重新上传该文件。

## 安全与兼容

- 云端凭据位于数据目录的 `cloud-backup/settings.json`，Windows 目录仅服务账号、SYSTEM和管理员访问，Unix 文件权限0600。响应和审计不返回应用密码。
- 更换网盘地址、目录或账号必须重新输入应用密码，原凭据不会被静默带到新目标。
- 云端凭据、传输任务不加入全量包，也不随旧数据库恢复回退；迁移服务器时重新配置网盘授权。
- 备份使用唯一文件名，先写临时文件，完成校验后才发布；全量包校验和浏览器上传恢复改为流式处理。
- 恢复拒绝重复、清单未声明或摘要不符的文件，并补充 Windows 盘符、父目录等越界路径校验。
- 继续沿用 `manage:backup` 权限及原恢复前安全备份、重启恢复机制；浏览器上传恢复上限仍为2GiB，大包可通过云端取回后从本地列表恢复。
- 全量备份的数据库和磁盘文件仍不是同一事务快照，迁移/灾备的最终备份应暂停业务写入。
