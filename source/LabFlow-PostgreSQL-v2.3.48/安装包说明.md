# LabFlow v2.3.48 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.48.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.48-HotUpdate.exe`，仅用于已有完整服务器安装的升级。
- Windows 产品和文件版本：`2.3.48.0`。本地产物校验文件位于版本 `installer/`；仓库根 `installers/` 由 CI 留存正式发布包。
- Docker 镜像：`ghcr.io/hotll233/labflow:2.3.48`；部署文件继续使用仓库根 `docker-compose.deploy.yml`。
- 默认端口8000；账号密码、数据位置按安装向导和现有配置，升级保留原密码与业务数据。

## 本次变化

人员工作量汇总新增“类型汇总”，可按检测类型继续查看方法、仪器及对应明细；辅助工作支持子类型及方法 / 事项汇总。管理员在类型汇总中的“辅助子类型配置”维护分类关系，普通用户仍仅能查看本人或角色授权范围。

新增视图保留日期、人员、多部门筛选和同源导出。桌面保持一页显示全部列，手机使用紧凑摘要；字号、显隐、摘要内容和内外边框可继续配置。原有取样、编辑、退回、工作量录入及原报表入口保持，工作量仍按数量×系数快照累计。

## 升级与验证

升级前按原流程备份数据库和附件，再运行完整包或热更新包。备份恢复的事务与待恢复任务规则不变。不得删除待恢复标记绕过失败；不包含生产配置、凭据或业务数据。

首次启动自动执行一次分类快照迁移，旧记录保留空快照并按现有配置兼容分类，不重算历史工作量。新记录及主动修改方法的记录保存分类快照。辅助分类缺失时显示“未分类”，恢复损坏配置不会阻断辅助录入，管理员可重新保存修复。

前后端回归、隔离数据库升级、真实接口、安装包校验与CI / 镜像发布结果见仓库根PROJECT_MEMORY.md本版记录。本轮浏览器工具不可用，未做真实手机浏览器验收，也未在生产环境覆盖安装。

既有取样工作量弹窗方法系数预估与实际项目系数统计差异仍待统一，本版未修改统计规则或重算历史数据。
