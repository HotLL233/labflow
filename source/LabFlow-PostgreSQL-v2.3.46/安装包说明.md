# LabFlow v2.3.46 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.46.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.46-HotUpdate.exe`，仅用于已有完整服务器安装的升级。
- Windows 产品和文件版本：`2.3.46.0`。本地产物校验文件位于版本 `installer/`；仓库根 `installers/` 由 CI 留存正式发布包。
- Docker 镜像：`ghcr.io/hotll233/labflow:2.3.46`；部署文件继续使用仓库根 `docker-compose.deploy.yml`。
- 默认端口8000；账号密码、数据位置按安装向导和现有配置，升级保留原密码与业务数据。

## 本次变化

实验室卡片只进入工作量内页，送样记录在内页切换，固定实验室且受原数据范围授权。研发记录新增全量列筛选、具体送样时刻范围和操作状态/录入账号筛选；已录入展示实际工作量提交人，分批明细按原工作量权限查看，历史缺失不推测为取样人。

桌面保持一页显示全部列，手机保持自定义摘要和内外边框；辅助文字与按钮字号/宽度可独立设置，操作采用文字，取样按钮加入排序。编辑或恢复关联工作量复用来源累计量事务校验，错误不会部分写入或静默修改数量。

## 升级与验证

升级前按原流程备份数据库和附件，再运行完整包或热更新包。备份恢复的事务与待恢复任务规则不变。不得删除待恢复标记绕过失败；不包含生产配置、凭据或业务数据。

本轮175项后端测试（含隔离备份恢复）、18项前端回归，以及真实Release接口152项和旧测试库升级21项检查通过。浏览器与最终完整/热更新包的校验、CI及镜像发布结果见仓库根PROJECT_MEMORY.md本版记录。测试不使用生产数据库或现有安装。
