# LabFlow v2.3.42 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.42.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.42-HotUpdate.exe`，仅用于已安装完整服务器版的升级。
- Windows 产品和文件版本：`2.3.42.0`。本地产物 SHA-256 见同目录 `installer/checksums.sha256`。
- 默认程序端口为 8000；实际端口、数据位置与初始管理员密码以安装向导和已有配置为准。升级保留已有账号密码与业务数据。
- Docker 镜像由 GitHub 工作流发布 `ghcr.io/hotll233/labflow:2.3.42`，部署配置位于仓库根 `docker-compose.deploy.yml`。

## 本次变化

优化研发送样与样品信息登记手机卡片，默认四组核心字段，可选三行紧凑模式。管理员在“表格样式 → 手机卡片 → 摘要内容”配置字段和顺序后发布为全局。保留完整详情、原有自定义列与操作按钮配置。

## 升级与恢复

升级前按既有流程保存数据库及附件备份，再运行完整包或热更新包。备份恢复的数据库清空、导入、关键表校验处于同一事务；附件保留暂存内容供重试。数据库和文件不是整体事务，恢复失败会停止启动，排除错误后重启完成同一恢复任务，不能删除待恢复标记强行继续业务。

## 验证范围

本版完成前端类型检查和生产构建、9项布局/摘要/工作量相关测试、后端设置权限测试。浏览器使用真实组件和模拟接口验证320/390/768像素手机及1280像素桌面、自定义列宽和操作列位置；未在生产数据库或现场覆盖安装测试。数据库业务逻辑及历史迁移沿用v2.3.41。

未在生产数据库上运行测试，未在真实业务服务器执行覆盖安装。现场升级仍需核对原角色配置、历史报表及附件。
