# v1.3.0 人员变动通知与项目人员汇总实施方案

## 1. 边界

人员变动通知为独立功能。提交、查看、导入、导出、审批均不修改程序 PostgreSQL；只有审批通过才修改功能目录中的外部 `项目及人员汇总表.xlsx`。旧 `personnel_change_feedbacks` 与旧人员反馈路由不参与本功能。

## 2. 数据文件

- `项目及人员汇总表.xlsx`：当前项目、人员、方法的唯一业务基线。
- `change-types.json`：可启用、停用、调整通知类型；默认将早期“新员工加入”兼容显示为“员工加入”。
- `notices-YYYY-MM.jsonl`：通知与审批状态台账。
- `summary-history/<时间>-<通知号>.xlsx`：每次审批通过前的汇总表备份。

汇总表列为实验室、实验室负责人、实验人员、实验室项目代号、检测方法。人员、方法支持顿号、逗号、分号、换行分隔并在读写时去重。

## 3. 权限

- 系统管理员：发起、查看全部记录、导入导出汇总表、审批。
- 分析检测组长：查看全部记录、导入导出汇总表、审批；不能发起。
- 研发送样组长：发起、查看本人近 7 天记录、查看导出汇总表；不能导入或审批。
- 审批禁止自审；待审批记录只能处理一次。

系统管理员可从全部有效实验室选择；研发送样组长仅从用户数据库中关联的有效实验室选择。

## 4. 审批动作

| 通知类型 | 审批通过后对外部汇总表的动作 |
| --- | --- |
| 员工加入 | 将人员加入所选项目 |
| 员工离职 | 移除所选项目的人员；未选项目时移除该人员当前所有项目 |
| 实验室内人员调动 | 所选项目成为该人员在当前实验室的完整项目集合 |
| 跨实验室人员调动 | 移除所选项目的人员；项目留空时移除当前实验室全部关联项目 |
| 实验室新增项目 | 按新项目代号、新增检测方法增加项目行，负责人沿用该实验室现有负责人 |
| 实验室新增方法 | 合并新增方法至所选项目并去重 |
| 自定义类型 | 仅记录和通知，不自动变更汇总表 |

审批驳回必须填写原因，且不会更新汇总表。通过或驳回都会将新状态作为独立 JSONL 事件追加保存，不覆盖历史通知内容。

## 5. 表单细节

- 实验室内人员调动的项目下拉直接读取该实验室全部项目，已存在人员也不得缩小候选范围。
- 跨实验室人员调动无目标实验室、无目标项目字段。
- “实验室新增项目”无“新增项目名称”字段；高新项目为“是”时仍需填写高新项目名称。
- 员工加入、离职、实验室内人员调动、跨实验室人员调动必须填写人员；其他类型可不填写。
- 发起后先外部投递并显示待审批，不更新汇总表。

## 6. 文件与安装

完整服务器安装包包含 PostgreSQL、PDF 预览工具及 VC++ x64 运行库。安装器会验证运行时完整性；若检测到已安装运行时缺少 `vcredist_x64.exe` 或关键 PostgreSQL 文件，会重新补齐运行时。热更新包仅用于已完整安装的服务器升级。
