# labflow v2.4.5 更新说明

本版修复 Windows 卸载后重装时的安装状态识别与重新安装流程。

- 修复卸载后重装只凭配置和完成标记判为覆盖安装、复制文件后才报告数据库缺失的问题。
- 在替换程序前识别有效数据库、丢失或损坏的路径标记及残留配置，默认保护已有记录。
- 完成标记缺失但原库仍在时继续保留安装，不归档、替换原库或重置管理员密码。
- 原库确实缺失时，完整包显示“安装数据处理”：默认保留并定位原目录；明确选择新建后，使用空目录并先归档旧配置与标记、核对 SHA-256。取消或复制失败时原配置指针仍在。
- 标记使用 UTF-8，读取兼容旧编码；完整包、热更新包和卸载共用同一定位逻辑。多个数据库或另一份配置会影响后续普通启动时，提前停止并提示核对，不自动切换到错误配置。
- 热更新遇到配置或数据库不完整时提前停止，并提示使用完整包处理。

原附件、备份和数据文件不删除；新建空系统不会自动恢复旧记录。静默新建需显式传入 `/REINSTALL=NEW` 并选择空数据目录。
不重算历史系数，不修改程序内名称、业务页面或既有权限，没有新增数据库迁移。
实际验证范围、安装包与发布结果见本版《安装包说明.md》。
