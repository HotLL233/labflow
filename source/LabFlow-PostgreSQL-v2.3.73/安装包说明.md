## 本版行为

辅助事项有自动生成的只读“事项ID”（A-编号），已有事项含软删除事项一次性回填。修改名称、系数、区域、分类、启停或备注不改变 ID；删除、恢复和 Excel 回导保持身份，历史记录不合并、不重算。

主数据“辅助工作”表改为9列：事项名称、系数、辅助分类、启用、排序、备注、区域名称、序号、事项ID。移除“范围、所属实验室”；按 ID 回导可修改配置，新建留空自动编号。旧模板无 ID 时仍按唯一名称兼容，未知或重复 ID、同名歧义会阻止写入。

辅助工作只按数量×保存系数计入人员工作量，不分配实验室、项目或仪器，不参与金额计算。新录入及主动更换事项不保存实验室，旧客户端附带实验室也不能分配；旧字段仅留作历史兼容。金额和实验室汇总继续排除新旧辅助来源，人员原始导出的辅助行不再展示实验室及项目分配。

人员与常规工作量共用账号和实际工作人员的主归属部门。保留本人、公共账号实际人员及授权代录权限；独立区域、事项配置、每事项系数、导入导出、自定义显示配置全部保留。历史数量、日期和备注编辑继续使用原人员、部门及系数快照。
