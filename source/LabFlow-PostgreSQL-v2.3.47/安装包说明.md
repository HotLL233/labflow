# LabFlow v2.3.47 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.47.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.47-HotUpdate.exe`，仅用于已有完整服务器安装的升级。
- Windows 产品和文件版本：`2.3.47.0`。本地产物校验文件位于版本 `installer/`；仓库根 `installers/` 由 CI 留存正式发布包。
- Docker 镜像：`ghcr.io/hotll233/labflow:2.3.47`；部署文件继续使用仓库根 `docker-compose.deploy.yml`。
- 默认端口8000；账号密码、数据位置按安装向导和现有配置，升级保留原密码与业务数据。

## 本次变化

按用户确认，研发送样的取样按钮继续放在取样人列，已取样后显示姓名。记录表头排序标题与箭头保持同一行，避免排序控件继承纵向布局后独占一行、挤压筛选按钮空间。

桌面保持一页显示全部列，手机保持自定义摘要和内外边框；辅助文字与按钮字号/宽度和既有操作按钮排序配置保留。取样授权、实际操作人记录、工作量归属、全量列筛选及统计规则不变，其他功能沿用上一版。

## 升级与验证

升级前按原流程备份数据库和附件，再运行完整包或热更新包。备份恢复的事务与待恢复任务规则不变。不得删除待恢复标记绕过失败；不包含生产配置、凭据或业务数据。

18项前端回归、类型与生产构建、Rust fmt/check/Release通过；Mock API配真实Chrome验证源码14项和最终生产静态包6项通过。后端及迁移代码未变，本轮未重新执行全库数据库回归或生产安装。完整/热更新安装包校验、CI及镜像发布结果见仓库根PROJECT_MEMORY.md本版记录。

既有取样工作量弹窗方法系数预估与实际项目系数统计差异仍待统一，本版未修改统计规则或重算历史数据。
