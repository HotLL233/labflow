# LabFlow v2.3.41 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.41.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.41-HotUpdate.exe`，仅用于已安装完整服务器版的升级。
- Windows 产品和文件版本：`2.3.41.0`。本地产物 SHA-256 见同目录 `installer/checksums.sha256`。
- 默认程序端口为 8000；实际端口、数据位置与初始管理员密码以安装向导和已有配置为准。升级保留已有账号密码与业务数据。
- Docker 镜像由 GitHub 工作流发布 `ghcr.io/hotll233/labflow:2.3.41`，部署配置位于仓库根 `docker-compose.deploy.yml`。

## 本次变化

修复角色分配与数据范围授权、人员统计与实验室筛选、工作量累计状态和方法系数预估。手机记录默认紧凑摘要，可展开完整字段和原有操作。改密后所有旧会话失效，需要重新登录。

## 升级与恢复

升级前按既有流程保存数据库及附件备份，再运行完整包或热更新包。备份恢复的数据库清空、导入、关键表校验处于同一事务；附件保留暂存内容供重试。数据库和文件不是整体事务，恢复失败会停止启动，排除错误后重启完成同一恢复任务，不能删除待恢复标记强行继续业务。

## 验证范围

独立 PostgreSQL 环境完成后端回归和恢复故障测试；前端完成类型检查、布局/工作量测试、320/390/768 像素实际组件浏览器检查和生产构建。Release 程序在全新测试库完成初始化、登录、记录和统计接口冒烟验证。

未在生产数据库上运行测试，未在真实业务服务器执行覆盖安装。现场升级仍需核对原角色配置、历史报表及附件。
