# labflow v2.4.2

本版统一工作量录入与编辑的时间精度，兼容历史分钟格式，完善日期查看范围和稳定账号ID归属；保留程序内原名称、自定义配置、历史系数和全部既有桌面/备份功能。

## Windows使用

现有安装使用 `labflow-v2.4.2-hotupdate.exe`，首次部署使用 `labflow-v2.4.2.exe`。快捷方式启动程序和本机控制窗口；从窗口或托盘打开网页。关闭设置窗口后仍在托盘运行，选择“退出labflow”结束桌面程序与所属后台进程。

端口保存前检查可用性，修改后重启服务，浏览器需使用新端口访问并重新登录。其他配置字段和数据库不因端口编辑而覆盖。受保护配置需要管理员授权。

“开机自启”指当前Windows用户登录后自动启动，不会自动打开浏览器。发布者元数据为HotLL，Windows已验证发布者需要另行配置有效代码签名证书。

升级识别旧workload程序并保留原数据位置、数据库账号和备份格式；历史文件不批量改名。卸载保留业务数据和配置。升级前仍应保留数据库、附件和配置的最终备份。

## 云端备份

保留坚果云、通用HTTPS WebDAV、Nextcloud、ownCloud、OneDrive全球版官方设备授权及OpenList网关。百度、阿里云盘和夸克仍经已授权OpenList接入。OneDrive需自己的公共客户端Client ID与对应权限；不是全部网盘原生授权。

入口为“系统管理→数据备份→云端设置”。网关填写可写WebDAV目录和网关账号密码，不能填写网盘网页或分享地址。测试当前输入成功后仍需保存。旧任务绑定原目的地，切换后应取消旧任务再重新上传，不自动改变去向。

本版构建、测试和发布的实际范围见《安装包说明.md》。
