# 研发送样统计功能修复完成报告 v2.2.7

**修复日期**: 2026-08-28  
**问题描述**: 研发送样门户的统计功能异常，用户无法看到统计卡片  
**根本原因**: 权限映射错误（使用了分析检测的权限名称）  
**修复状态**: ✅ 已完成

---

## 一、问题诊断

### 核心问题
`SampleStatsPage.tsx` 从 `StatsPage.tsx`（分析检测统计）复制代码时，未修改权限映射常量，导致：

```typescript
// ❌ 错误：使用了分析检测权限
const STAT_CARD_PERMISSIONS: Record<TabValue, string> = {
  week: "stats:workload:week",      // 应该是 stats:rd:week
  month: "stats:workload:month",    // 应该是 stats:rd:month
  // ... 其他 13 个权限全部错误
};
```

**影响**：即使用户拥有 `stats:portal:rd` 权限，也无法看到任何统计卡片。

const visibleStatCards = hasPermissionKey(user?.permissions || [], "stats:portal:rd") || user?.is_admin
  ? STAT_CARDS
  : [];
