# labflow v2.5.2

AI 授权代办版。头像旁打开助手；管理员在“系统管理 → AI 助手 → 助手与权限”启用本人通知已读、填报确认提交。普通账号仍需单独授权 ai:use 及原业务权限，新增能力默认关闭。

使用者分别允许本次通知已读与准备提交。通知已读不执行取样等业务操作；研发送样、样品登记及检测/辅助工作量先展示服务端预览，再由用户一次确认整批。来源、实际人员、系数、金额及数量限制沿原业务接口校验，原草稿与手工入口保留。当前模型仍需通过 hi 和流式工具测试。准确交付状态见根 README 与本版安装包说明。

当前正式版本以项目根 README.md 为准；使用说明、验证和发布结果见本目录《更新说明.md》《安装包说明.md》。现行开发规则见根 PROJECT_MEMORY.md。
