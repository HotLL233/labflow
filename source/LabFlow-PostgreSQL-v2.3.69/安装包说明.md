# LabFlow v2.3.69 安装包说明

- 完整服务器包：LabFlow-v2.3.69.exe，用于首次部署。
- 热更新包：LabFlow-v2.3.69-HotUpdate.exe，用于已有完整安装后的升级。
- Windows产品／文件版本：2.3.69.0。
- 本地留档：本版installer/；CI正式包：根installers/及GitHub Release。
- Docker：ghcr.io/hotll233/labflow:2.3.69与latest，使用根docker-compose.deploy.yml。只发布GitHub／GHCR，Gitee继续暂停。

本版修正辅助工作录入界面：主页不再新增独立入口，分析检测门户保留紧凑入口，录入与现有手动工作量页面样式一致。主数据管理提供辅助事项配置，模板／导出／导入支持辅助工作表，旧管理路由保留兼容。

辅助工作仍按数量乘保存系数统计，历史快照不重算。旧模板缺少辅助工作表时保留配置；有该表的覆盖更新会软删除表中未出现的辅助事项，空表会软删除全部辅助事项，正式导入前须核对预检。“跳过已有”仅增加不存在的事项。

本地构建使用根scripts/prepare-local-build.ps1 -SourceDir source/LabFlow-PostgreSQL-v2.3.69准备共享资源；依赖缺失时加-InstallDependencies。运行库、缓存和依赖位于根build-resources/，本版通过链接引用。frontend必须由本版源码重新构建到backend/static/，不复制旧版产物，不在共享node_modules上运行npm ci。

记录时间输入／显示使用北京时间，日期筛选沿用原系统数据库会话时区；Windows服务器建议使用北京时间，Docker默认TZ=Asia/Shanghai。部署在其他时区的既有日期边界差异本次不扩大重写。

升级前按既有流程备份数据库、附件与配置；包内不含生产数据、备份或凭据。验证与发布状态见根PROJECT_MEMORY.md；本地包和CI正式包可能因构建环境不同而具有不同哈希，分别核验。

未操作生产数据库、现场8000服务或实际安装配置；当前无可用浏览器，真实桌面／手机交互、现场覆盖安装、生产规模压测及容器实际启动尚未验收。

本地验证完成：前端146项测试、类型检查、生产构建和2份gzip逐字节核验通过；Rust格式／编译检查、277项库测试通过，3项既有备份恢复专项按原标记跳过，默认非console Release通过。独立PostgreSQL上原记录33项、辅助工作53项、主数据导入38项Release HTTP检查通过；Excel原流程5项及辅助工作197项核验通过。完整安装包／热更新包产品与文件版本均2.3.69.0，大小及SHA-256已核验。

CI正式包及GHCR发布结果见根PROJECT_MEMORY.md本版记录。
