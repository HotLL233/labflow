# v1.3.3 开发说明

## 问题原因

人员变动反馈只完成了通知入队，实际发送依赖主循环每 60 秒执行一次 `process_pending`；通知规则页面也遗漏了 `personnel_change_feedback` 的中文回显映射。

## 修复内容

人员变动通知入队成功后通过 `spawn_blocking` 立即调用通知处理服务，后台维护循环继续作为失败重试保障。前端规则编辑器增加中文映射，并将人员反馈与驳回、重新提交事件按独立规则处理，避免生成混合事件规则。

## 版本隔离与兼容

版本号迭代为 v1.3.3。变更仅涉及人员变动通知提交链路、通知规则显示及安装包版本元数据，不改变既有数据库表结构和其他业务功能。
