# labflow v2.5.1 更新说明

本版修复 AI 助手权限入口难找、业务辅助条件不清楚、送样草稿难以调用，以及工具测试与实际会话调用方式不一致的问题。正式发布与验证状态见根 README 和本版安装包说明。

- 角色权限管理独立展示“AI 助手”，关键词可搜索全部权限分组；AI 配置页提供“分配使用权限”快捷入口。仍需手动选择角色、勾选权限并保存，不自动更改旧角色。
- 助手常显业务辅助状态和“业务授权与范围”入口，明确授权同时影响记录查询、主数据核对和填报草稿。草稿无需查询日期；近7天、近30天快捷选择按北京时间展示，不自动允许数据外发。
- 修改业务同意或日期时保留未发送的问题，同时清除旧会话、结果、重试和草稿；切换账号、实际人员或模型仍完整清理。
- 新建会话撤销上次业务同意和日期；刷新发现能力或模型测试资格降低、权限读取失败时，终止旧请求并清理上下文，不接受迟到回包。
- 后端向模型说明本次可用工具和缺少条件，指引用户完成设置；数据结论须有真实查询依据，不能根据缺少本次授权宣称程序永久不支持分析。
- 工具测试复用实际流式调用与结果往返。旧非流式工具测试结果需管理员重新测试；服务、模型、密钥及其他配置保留。
- AI 配置页的测试结果可点 × 收起，不改变已保存的测试资格；再次测试会展示新结果。
- 填报工具按当前账号原表单权限提供可用目标；实验室、项目可按关键词检索完整授权候选，避免前100项截断后无法匹配。模型需先核对真实字段和主数据，再生成可带入原表单的草稿，不能只给文字说明。
- 草稿复核展示可填自定义字段；原生字段与自定义字段按当前配置校验，原表单的字段及实际人员选项加载完成后才能添加草稿。

升级不改变原业务权限、人员归属、日期边界、历史快照、统计口径和自定义配置。AI 默认关闭，不补授旧角色；辅助工作仍不分摊实验室、项目或金额。AI 不直接提交或修改业务记录。
