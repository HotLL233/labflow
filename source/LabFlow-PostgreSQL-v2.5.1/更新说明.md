# labflow v2.5.1 更新说明

本版修复 AI 助手权限入口难找、业务查询条件不清楚，以及工具测试与实际会话调用方式不一致的问题。正式发布与验证状态见根 README 和本版安装包说明。

- 角色权限管理独立展示“AI 助手”，关键词可搜索全部权限分组；AI 配置页提供“分配使用权限”快捷入口。仍需手动选择角色、勾选权限并保存，不自动更改旧角色。
- 助手常显本次业务查询状态和查询范围入口，区分模型未测试、未同意、未确认日期和无业务权限。近7天、近30天快捷选择按北京时间展示，不自动允许数据外发。
- 修改业务同意或日期时保留未发送的问题，同时清除旧会话、结果、重试和草稿；切换账号、实际人员或模型仍完整清理。
- 后端向模型说明本次可用工具和缺少条件，指引用户完成设置；数据结论须有真实查询依据，不能根据缺少本次授权宣称程序永久不支持分析。
- 工具测试复用实际流式调用与结果往返。旧非流式工具测试结果需管理员重新测试；服务、模型、密钥及其他配置保留。
- AI 配置页的测试结果可点 × 收起，不改变已保存的测试资格；再次测试会展示新结果。

升级不改变原业务权限、人员归属、日期边界、历史快照、统计口径和自定义配置。AI 默认关闭，不补授旧角色；辅助工作仍不分摊实验室、项目或金额。AI 不直接提交或修改业务记录。
