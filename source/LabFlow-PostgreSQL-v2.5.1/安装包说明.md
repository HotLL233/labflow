# labflow v2.5.1 安装包说明

本版本地验证完成，正式发布进行中。当前正式版仍以根 README 为准；不把源码文件或旧版验收计作本版交付。

预定提供完整安装包 labflow-v2.5.1.exe、热更新包 labflow-v2.5.1-hotupdate.exe，数字版本 2.5.1.0，发布者 HotLL；镜像仅发 GHCR，程序内品牌不变。正式来源、摘要与实测范围在完成后填入。

升级前按原入口备份业务数据，并从托盘完全退出程序。保留原数据库、附件、服务器及 AI 私密配置；AI 私密配置不在标准业务备份中，换主机需重新配置。

启用与授权：

1. 系统管理员进入“系统管理 → AI 助手 → 助手与权限”，点击“分配使用权限”。
2. 手动选择需要的角色，在“AI 助手”分组勾选“使用 AI 助手”，复核并保存。角色模板也可维护该权限，不自动授权旧角色。
3. 在“模型服务”对当前服务、模型完成 hi 和工具测试。v2.5.1 工具测试验证实际流式工具往返，旧版通过记录需重新测试；不清空原配置。
4. 使用者从头像旁打开助手，点击“业务授权与范围”，明确勾选允许本次业务辅助和必要信息发送。记录查询或工作量汇总再选择起止日期；填报草稿和所需主数据核对不需要日期。近7天含今天；日期以北京时间为准。
5. 填报时说明实验室、项目、方法和数量，例如“410-研究院，Q007 项目，理化水分，3 个样品”。助手检索实际可用选项；有歧义或缺必填项时继续补充。生成草稿后点击“复核并带入原表单”，在原页面核对并添加，再使用原提交按钮。
6. hi、工具等测试提示可点 × 收起；关闭只影响当前显示，不取消测试通过状态，再次测试会显示新结果。新建会话需重新允许业务辅助。

当前支持原权限内记录查询与工作量全量汇总，不等于任意检测结果分析。模型不能绕过原账号范围或日期限制；未查询的数据不得编造。草稿仍需带入原表单人工复核。

本地前端 334 项及完整 Build 通过；同一受控输入后端隔离库 434 项通过，0 失败、3 项既有备份恢复测试忽略。真实程序配合本机模拟上游 HTTP 77 项通过；生产静态配合合成 API 的助手浏览器 17 组、草稿浏览器 4 组分别通过，不累加重跑。完整证据及未验范围见 `docs/ui-ai-assistant/v2.5.1-修复与验收.md`。尚未验证真实上游模型、实机麦克风、现场安装升级或容器业务运行。
