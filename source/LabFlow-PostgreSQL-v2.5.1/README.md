# labflow v2.5.1

AI 助手使用入口修复版。头像旁打开助手；系统管理员在“系统管理 → AI 助手 → 助手与权限”点击“分配使用权限”，进入角色权限管理的“AI 助手”分组。普通账号需单独授权 ai:use，业务能力仍取原有权限与范围。

业务查询需当前模型通过 hi 和流式工具往返测试，并由使用者在助手内允许本次数据发送、确认查询日期。升级保留配置与原权限；旧工具测试结果需重测，不自动授权或外发数据。准确交付状态见根 README 与本版安装包说明。

当前正式版本以项目根 README.md 为准；使用说明、验证和发布结果见本目录《更新说明.md》《安装包说明.md》。现行开发规则见根 PROJECT_MEMORY.md。
