# LabFlow v2.3.44 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.44.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.44-HotUpdate.exe`，仅用于已安装完整服务器版的升级。
- Windows 产品和文件版本：`2.3.44.0`。本地产物 SHA-256 见同目录 `installer/local-packages-sha256.json`；仓库根 `installers/` 为 CI 正式发布包，校验值以 GitHub Release 资产 digest 为准。
- 默认程序端口为 8000；实际端口、数据位置与初始管理员密码以安装向导和已有配置为准。升级保留已有账号密码与业务数据。
- Docker 镜像由 GitHub 工作流发布 `ghcr.io/hotll233/labflow:2.3.44`，部署配置位于仓库根 `docker-compose.deploy.yml`。

## 本次变化

新增“工作量统一汇总”（`/stats/workload`），支持个人及授权范围汇总、人员×检测类型矩阵、分类钻取、时间趋势、分页来源明细与当前筛选 Excel。检测工作量、辅助工作量和总工作量分别展示；工作量仍为数量×系数快照，金额算法不变。

页面入口需 `stats:portal:workload`，Excel 另需 `stats:workload:export`；管理范围仍叠加角色部门授权。新增独立辅助表部门快照字段及读取授权，不推测回填历史归属。保留原手机字段网格、内外边框、三/四组摘要、按钮宽度/排序、桌面一页显示全部列和管理员全局配置。

## 升级与恢复

升级前按既有流程保存数据库及附件备份，再运行完整包或热更新包。备份恢复的数据库清空、导入、关键表校验处于同一事务；附件保留暂存内容供重试。数据库和文件不是整体事务，恢复失败会停止启动，排除错误后重启完成同一恢复任务，不能删除待恢复标记强行继续业务。

## 验证范围

本版通过166项后端测试（163项常规、3项隔离备份恢复）及11项前端测试，Rust格式检查、编译和Release构建、前端类型检查和生产构建通过。真实PostgreSQL验证部门隔离、空授权、同名/历史未绑定、分批录入、删除恢复、系数快照、日期边界及页面/Excel对账；浏览器验证320/390/768/1280汇总页面和原手机/桌面自定义布局，实际Release配生产前端验证新库启动与旧库迁移。

未在生产数据库上运行测试，未在真实业务服务器执行覆盖安装。现场升级仍需核对原角色配置、历史报表及附件。
