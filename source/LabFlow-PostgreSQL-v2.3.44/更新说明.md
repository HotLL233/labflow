## 一、本次修复：窄屏用表格时整页空白

### 现象

手机开启「桌面网站」（或把布局手动切成「表格」）后，记录页中间整块空白：
工具栏、筛选条、分页「1-20 / 1625」都在，但一条记录也不显示。

### 原因

v2.3.34 把卡片 / 表格的判定改成了**按设备**（`cardLayout`），但**表格容器本身仍用旧断点隐藏**：

```text
TableContainer sx={{ display: { xs: 'none', lg: 'block' } }}   ← 视口 < 1200px 时隐藏
```

于是出现判定与显隐不一致：

- 判定结果 = 用卡片 → 卡片挂载前提是 `cardLayout`，此时为 false，卡片不渲染；
- 判定结果 = 用表格 → 表格又被 `lg` 断点（≥1200px）隐藏。

两个布局都没渲染，页面就只剩工具栏和分页。手机桌面标识下的布局视口约 980px，
小于 1200px，所以必然踩中。

### 修复

1. 研发送样记录、样品信息登记记录两页的表格容器改为跟随判定：

   ```text
   display: cardLayout ? 'none' : 'block'
   ```

2. 同一页面上两处管理员提示文案（「右键对应列可编辑全局设置」/「点击字段设置图标…」）
   原本也按 `lg` 断点切换，会与实际布局不符，一并改为跟随 `cardLayout`。

3. 表格容器的横向溢出由 `overflowX: 'hidden'` 改为 `auto`。
   在窄视口下显示表格时，列宽总和可能超过可视宽度，原来会被直接裁掉、右侧列永远看不到；
   改成 `auto` 后表格区域内部可以横向滚动。桌面宽度下列宽本来就能装下，不会出现滚动条，观感不变。

### 布局判定规则（便于验证）

| 布局设置 | 设备 / 视口 | 结果 |
|---|---|---|
| 自动 | 手机 UA（未开桌面标识） | 卡片 |
| 自动 | 桌面 UA，视口 ≥768px（含手机开桌面标识的约 980px） | 表格 |
| 自动 | 任意 UA，视口 < 768px | 卡片（极窄兜底） |
| 卡片 | 任意 | 卡片 |
| 表格 | 任意（含视口 < 768px） | 表格 |

> 注意：在浏览器开发者工具里把视口模拟成 400px 时，即使 UA 是桌面，也会因
> 「极窄兜底」落到卡片。若要在这种小视口下强制看表格，请把「表格样式 → 布局」切成「表格」。

## 四、本次追加修复：列错位与操作列展示

### 列错位原因

表格样式中的「单行省略 / 最多两行 / 自动换行」会生成 `display: block`、`display: -webkit-box`、`overflow` 等文本流样式。此前这些样式同时传给了外层 `<td>/<th>` 和内层文本容器，导致被设置过换行方式的列不再保持正常 `table-cell` 布局，于是该列的行边框与相邻列出现错位。

现在外层单元格只保留网格、边框、背景、对齐和字体样式；换行、截断、滚动、最大高度只传给内层文本容器。既有个人 / 全局换行配置仍然有效。

### 操作列展示配置

在「表格样式 → 表格 → 操作列」新增三种模式：

- **自动（按宽度收纳）**：沿用原有响应式策略；
- **全部显示（自动换行）**：按钮全部直接显示，操作列内自动换行；
- **折叠到“更多”**：保留主按钮，其余收进「更多」。

配置跟随当前记录表样式保存，适用于研发送样记录和样品信息登记记录；不改变权限判断、按钮顺序或业务操作。手机卡片布局下也遵循显式选择的「全部显示 / 折叠到更多」模式。
