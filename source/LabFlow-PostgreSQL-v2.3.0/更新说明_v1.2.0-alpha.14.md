# 1.2.0-alpha.14 主数据序号与方法关联修复测试版

## 已完成

- 主数据导出/模板的部门、实验室、检测类型、仪器、检测方法、通用方法、研发项目、项目关联表增加“序号”列。
- 序号仅用于人工定位，不参与导入匹配、更新、删除；旧版没有序号列的文件仍可导入。
- 项目关联继续按数据库中的 `method_id` 建立项目与方法关系，仪器不会被项目再次绑定。
- 导出时项目关联的仪器编号从同一个方法实例生成，避免与检测方法表出现不一致。
- 兼容历史导出文件中“方法名称唯一但仪器编号过期”的情况，回导时自动采用本次方法表中的唯一方法实例。
- 保留 alpha.13 既有样品信息登记入口与 PDF 预览运行时修复。

## 版本隔离

- 本版本只复制源码和运行时依赖，不复制 alpha.13 的 `target`、`installer`、`.dev`、`backend/static`、`frontend/node_modules` 或旧安装包。
- 数据库迁移编号不重复执行历史迁移，升级不修改业务数据和附件原文件。

## 使用说明

- 项目关联中的“关联仪器编号”是同名方法实例的识别字段，不是第二次建立仪器关联。
- 新导出的表会自动填写序号；导入时可以不填写或修改序号。
- 热更新包适用于已有服务器安装，完整安装包适用于新电脑或重新安装运行环境。
