# v1.2.0-alpha.15 附件兼容与补传修复测试版

## 本版修复

- 兼容旧版本附件：旧 PDF/Word 的存储文件名没有扩展名或扩展名异常时，改为结合原始文件名和 MIME 类型识别，恢复网页预览。
- 对历史预览缓存中“类型暂不支持”的可恢复失败状态自动重新生成，避免旧失败状态永久阻塞预览。
- 样品信息登记记录提交后，在未取样且用户具有本人编辑权限时，允许继续补传和删除附件；分析检测人员和管理员保持原有附件处理权限。
- 前端附件上传、删除按钮与记录状态及当前权限保持一致，避免显示不可执行的操作。
- 修复 PostgreSQL 下送样通知的部门人员筛选参数类型错误；送样事件可再次完成规则匹配、站内通知和钉钉推送。
- 退回待修改记录固定继承原记录的所属部门、实验室和项目，页面显示部门名称；保存时只提交可修改的样品内容，避免组织校验报错和组织信息漂移。

## 本版未改变

- 未改变样品信息登记状态流转、取样、检测、退回和数据范围规则。
- 未改变附件下载、附件保存目录和数据库结构。
