# LabFlow v2.3.71 安装包说明

- 完整服务器包：LabFlow-v2.3.71.exe，用于首次部署。
- 热更新包：LabFlow-v2.3.71-HotUpdate.exe，用于已有完整安装后的升级。
- Windows产品与文件版本：2.3.71.0。
- 本地构建包在本版本installer/保留，交付清单记录大小、版本和SHA-256。远端发布状态见根PROJECT_MEMORY.md。

## 使用入口

管理员打开“分析检测 → 辅助工作 → 辅助配置”，或“管理后台 → 主数据 → 辅助工作”，点击“区域管理”即可独立维护区域。真实系统管理员且具备辅助管理权限才能配置，全部人员共用配置；普通录入人员不会显示管理员快捷入口。

## 数据兼容

辅助区域不再复用检测类型。升级只复制辅助事项及辅助记录实际引用的区域，保留ID和历史快照；检测类型和方法关联不变。区域停用禁止所属事项新录入，历史数量、时间和备注编辑保留原快照，各事项独立系数与统计口径不变。

主数据新增可选“辅助区域”表，名称只匹配独立字典或本次区域表。缺表保留；更新/新增保留未列区域，跳过已有不修改已有区域，覆盖更新停用遗漏区域，空表停用全部。先核对导入预检再执行。旧辅助工作表缺区域列保留原值，有列空白清空绑定。

升级前按原流程备份数据库、附件和配置。升级后辅助外键改为独立区域表，回退到v2.3.70需恢复升级前的数据库备份，不能只换回旧程序。运行中的旧页面遇到配置变更提示时，刷新后重新录入。本次不重算已保存工作量；程序包不含生产数据、附件、配置或凭据。

## 本地构建

使用PowerShell 7执行根scripts/prepare-local-build.ps1，明确SourceDir为source/LabFlow-PostgreSQL-v2.3.71；依赖、运行库和编译缓存引用根build-resources。验证入口为scripts/verify.ps1，打包入口为scripts/build-installers.ps1；生产前端会写入本版backend/static，不复制旧产物。
