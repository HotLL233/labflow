# LabFlow v2.3.77 更新说明

## 历史辅助关联迁移

- 在“系统管理 → 业务数据管理”提供管理员历史辅助关联入口，按日期、关键词在全部原工作记录中分页查询明确旧辅助；选择独立事项后先预览数量、原系数和工作量对账，再填写原因确认，每批最多100条，支持跨页勾选。
- 仅增加显式事项关联，不复制第二份工作量，不修改原工作记录、业务号、人员、部门、日期、数量、系数及取样来源链；同一送样分量逐条关联。普通检测、自定义推测和独立辅助镜像不自动转换，事项有歧义时由管理员明确选择。
- 新增批次记录、幂等提交、签名有效期、行锁、完整指纹、事务审计和预览撤销；原记录或事项配置变化使旧预览失效。撤销只解除本批事项关联，保留已确认的旧辅助证据及全部历史计量值，后续编辑过的原记录需先核对。
- 人员汇总、事项分类明细、Excel及辅助历史列表统一读取原事实；映射旧行与新事项按同一事项键合并，事项标题显示配置名称，来源明细保留原名称。区域/类别保存关联时归类，不回填或猜测历史归属。辅助历史列表只读，支持按原记录精确查看且继续遵守原权限。
- 新旧辅助不参与实验室、项目、仪器和金额分配；研发金额只排除明确辅助或全部有效工作分量均已确认且数量完整的辅助送样，混合或未完整情况保留原口径。修复旧分类缺失时多类型JOIN展开导致的重复。
- 原字典外键和关联审计继续保留，含撤销批次的源记录/事项也受永久清理保护；旧方法用停用、项目用归档，主数据修改使用“更新/新增（保留未列数据）”。完整覆盖删除遗漏的历史引用保护不变。

## 历史系数全量诊断与方法关联

- 分页扫描所选日期工作记录和独立辅助，显示一致、可修正差异、未关联、明确自定义、原方法删除/失联、辅助、记录删除和异常原因。无法归入日期的异常记录也保留核对，“0条差异”不再代表所有历史记录均正确。
- 管理员可选择真实标准方法，先预览关联变化和按当前方法单价预计的金额前后及差额，再填写原因确认。原单价缺失显示未知，不当作0；保留原名称、仪器、人员、部门、时间、数量和系数快照。方法维度及部分金额报表可能变化，确认时明确提示。
- 原/新方法、仪器及分类上下文参与指纹与锁定校验。方法关联与系数修正分开；关联后重新诊断，再单独选择所需历史系数差异。普通系数修正排除全部已确认旧辅助、明确自定义和无效日期，保留无效数值的原校验拒绝行为，不自动重算辅助。
- 诊断与原系数差异预览统一使用实际时间范围，兼容UTC和显式时区偏移，保留跨页全选、原有页大小和每批100条修正。金额倍率与工作量系数继续分离。
