# LabFlow v2.3.77：历史辅助关联与系数全量诊断

本版承接v2.3.76的事项编号隐藏与全部自定义配置，在“系统管理 → 业务数据管理”补齐历史辅助关联迁移、批次撤销、全量系数诊断和管理员方法关联确认。

历史辅助只增加关联，保留原记录、外键、人员、时间、数量、系数和取样链，不复制计量。页面/分类明细/Excel统一归类，原历史按原权限只读查看。关联与系数修正分开，方法关联预览同时提示方法维度及预计金额影响；不自动重算历史。

主数据更新继续使用“更新/新增（保留未列数据）”，旧方法停用、项目归档；完整覆盖删除遗漏的引用保护保留。事项ID在界面隐藏，程序及Excel系统字段保留。

行为及兼容说明见《更新说明.md》，操作步骤及对账边界见 `docs/历史辅助关联迁移与系数复核方案.md`。实际验证和本地安装包见《安装包说明.md》，远端发布以根PROJECT_MEMORY.md及实际GitHub结果为准。

新版本新增关联审计迁移，升级前备份数据库、附件及配置；不操作生产库或实际安装。开发命令统一PowerShell7，复用根共享运行库/缓存和验证打包脚本，不复制旧版构建缓存。
