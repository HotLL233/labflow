**SHA-256**: `FECFD7E75CD52C2A9F153345879125C1AA84A121847E4FEFC0879BBA094BF311`

- 全新安装
- 系统初次部署

- PostgreSQL 18 数据库运行时
- workload-tool.exe 主程序（29 MB）
- 前端静态资源（HTML/CSS/JS）
- PDF 预览组件（poppler 运行时库）

1. 检查是否已有旧版本安装
2. 安装 PostgreSQL 数据库服务
3. 初始化数据库和表结构
4. 部署应用程序文件
5. 创建 Windows 计划任务
6. 配置系统启动项

## 使用说明

### 全新安装步骤
1. 以管理员身份运行 `样品管理系统_v2.2.5_人员变动通知优化版_PostgreSQL服务器版_Setup.exe`
2. 选择安装目录（默认：`C:\Program Files\样品管理系统服务器版`）
3. 等待安装完成（约 2-3 分钟）
4. 安装完成后系统自动启动
5. 浏览器访问 `http://localhost:7878`

### 升级安装步骤
1. 以管理员身份运行 `样品管理系统_v2.2.5_人员变动通知优化版_热更新升级包_Setup.exe`
2. 安装程序自动检测现有安装位置
3. 等待升级完成（约 30 秒）
4. 系统自动重启服务
5. 验证新版本功能

### 回滚操作（如需）
1. 停止所有服务：
   ```powershell
   schtasks /End /TN "WorkloadToolServer"
   schtasks /End /TN "WorkloadToolServerTray"
   taskkill /F /IM workload-tool.exe
   ```

2. 从备份目录还原旧版本：
   ```powershell
   cd "C:\Program Files\样品管理系统服务器版"
   copy /Y backup\v2.2.5\workload-tool.exe .
   robocopy backup\v2.2.5\static static /E
   ```

3. 重启服务：
   ```powershell
   schtasks /Run /TN "WorkloadToolServer"
   schtasks /Run /TN "WorkloadToolServerTray"
   ```

## 系统要求

- **操作系统**: Windows 10/11 (x64)
- **权限要求**: 管理员权限
- **磁盘空间**: 
  - 完整安装：至少 500 MB
  - 热更新：至少 100 MB
- **内存**: 建议 2 GB 以上
- **端口占用**: 7878（HTTP）、5432（PostgreSQL）

## 注意事项

1. **安装前准备**
   - 关闭杀毒软件或将安装目录添加到白名单
   - 确保端口 7878 和 5432 未被占用
   - 建议在安装前备份现有数据库（如有）

2. **升级前注意**
   - 热更新包仅适用于 v2.2.4 → v2.2.5 升级
   - 升级前会自动备份，但建议手动导出数据库
   - 确保没有正在进行的业务操作

3. **数据兼容性**
   - v2.2.5 完全兼容 v2.2.4 数据库结构
   - 审计日志会自动添加新字段
   - 人员变动通知 JSONL 文件向后兼容

4. **防火墙设置**
   - 如需远程访问，需在防火墙中开放 7878 端口
   - PostgreSQL 端口 5432 默认仅本地访问

## 故障排查

### 安装失败
- 检查是否有管理员权限
- 查看日志文件：`C:\Users\<用户名>\AppData\Local\Temp\Setup Log *.txt`
- 确认端口未被占用

### 升级失败
- 确认已安装 v2.2.4 版本
- 检查旧程序是否已停止
- 查看备份目录是否创建成功

### 服务无法启动
- 检查 PostgreSQL 服务状态
- 查看应用程序日志
- 验证配置文件格式
