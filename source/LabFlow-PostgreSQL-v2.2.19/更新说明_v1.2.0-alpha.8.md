# 样品管理系统 v1.2.0-alpha.8

## 本测试版

- 正式角色的数据来源部门范围成为唯一业务授权来源。
- 旧部门角色不再授予分析检测、研发送样和样品信息登记数据权限。
- 角色管理统一使用“角色模板 + 数据来源部门范围”。
- 旧部门角色仅保留在权限审计和迁移核对中。
- 历史分析记录归属确认后的检测部门、送样部门和实验室快照继续保留。

## 安装包说明

- PostgreSQL 服务器完整安装包：首次安装使用，包含私有 PostgreSQL 运行时和数据库初始化流程。
- 热更新升级包：已有服务器版使用，只替换程序和前端静态资源，不覆盖数据库、配置和业务数据。
- 覆盖安装前建议先完成数据库备份。
