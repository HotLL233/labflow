# v1.3.0 人员变动通知独立版

## 人员变动通知

- 新增独立人员变动通知、近 7 天通知记录和项目及人员汇总表页面。
- 系统管理员可发起、导入导出、查看全部记录和审批；分析检测组长可导入导出、查看全部记录和审批；研发送样组长可发起、查看本人记录和导出，不能审批。
- 通知先进入待审批状态；管理员或分析检测组长通过后才更新独立 Excel 汇总表，并自动备份审批前版本。驳回不会调整汇总表。
- 人员变动模块不写程序 PostgreSQL、旧人员反馈表、站内通知或审计表；台账默认保存到既有应用数据目录下的独立 `personnel-change-data`。
- 实验室内人员调动可选择所选实验室全部项目；跨实验室人员调动已移除目标实验室和目标项目，项目留空即取消当前实验室全部项目关联。
- “新员工加入”更名为“员工加入”；新增项目不再填写项目名称。

## 安装完整性

- 完整服务器安装包会校验 PostgreSQL 关键程序及 Microsoft VC++ x64 运行库。
- 发现旧运行时目录不完整时，安装器会补齐 PostgreSQL 和 VC++ 运行库，避免因缺少 `vcredist_x64.exe` 导致安装退出代码 2。
- 首次安装或环境损坏请使用“PostgreSQL服务器版”完整安装包；热更新包仅用于已有完整服务器的升级。
