# LabFlow v2.2.19 更新说明

## 全量备份改进

- 全量 ZIP 备份新增附件预览目录 `attachment_previews/`。
- 新增人员变动数据目录 `personnel-change-data/`。
- 备份清单升级为 format version 3，记录来源目录、文件数量、总字节数和 SHA-256。
- 大文件改用流式写入 ZIP，降低备份过程的内存占用。
- 恢复流程支持上述新增目录，并继续兼容 v2.2.18 的旧 ZIP。
- 旧备份缺失的新目录时不会清空当前预览或人员变动数据。

## Docker 改进

- 预览和人员变动目录固定在 `/app/data` 持久化卷内。
- 应用镜像安装 PostgreSQL 18 客户端，支持页面执行数据库备份和恢复。
- Docker 发布工作流继续只构建 `linux/amd64`，避免 ARM 模拟构建超时。
- 恢复上传接口允许最大 2 GiB，避免大于 2 MiB 的备份被框架默认限制拒绝。

## 升级注意事项

从 Windows 迁移时，请将原 `ProgramData\\LabFlow\\pv` 目录内容导入备份的 `attachment_previews/`。
配置快照仅用于参考，恢复不会覆盖当前 Docker 的数据库连接、密码、端口和数据目录配置。
