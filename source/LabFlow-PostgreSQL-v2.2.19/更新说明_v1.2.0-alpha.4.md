# v1.2.0-alpha.4 公司级权限第四测试版

发布日期：2026-08-14

## 本测试版内容

1. 组织治理：部门编码、负责人、启用状态、项目归属部门和协作部门。
2. 权限治理：角色模板、部门角色、按业务域部门范围及部门管理员。
3. 业务归属：分析、研发送样和样品登记保存项目、执行、提交部门及实际业务人员快照；项目关联的实验室必须属于项目归属部门或明确配置的协作部门，编辑记录时同样重新校验。
4. 公共账号：公共账号保留操作审计，实际取样和检测归属到已选择人员。
5. 历史数据：无法可靠判断部门的历史记录标记为待确认，可由管理员确认归属。
6. 统计导出：分析检测、研发送样、样品信息登记支持按部门口径统计和导出；默认不混入历史待确认数据。项目归属统计口径只改变汇总维度，不会突破角色的执行部门数据范围。
7. 审计日志：增加操作账号、实际业务人员和业务部门展示。

## 升级说明

1. 先在测试环境安装或执行热更新，首次启动会自动执行组织治理迁移。
2. 升级后由系统管理员补齐部门编码、负责人、项目归属部门及部门角色。
3. 历史待确认归属记录请在“角色与权限 - 历史归属待确认”中完成确认。
4. 新增或编辑项目时，跨部门执行实验室必须同时完成“项目-实验室关联”和“项目协作部门”配置；仅关联实验室不会自动开放跨部门执行。
5. 本版本为测试版，正式上线前需完成跨部门权限、统计导出和公共账号回归验证。
