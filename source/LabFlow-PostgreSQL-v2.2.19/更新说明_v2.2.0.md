# v2.2.0

## 教程与反馈

- 教程页面以管理员上传的源文档为准，保留 PDF、Word、Excel、图片原文件。
- PDF 和 Office 文件复用样品附件的分页预览能力；转换失败时仍可下载源文件。
- 普通用户仅可查看启用教程和下载教程附件，管理员可上传、替换、显隐和删除。
- 新增 `help_attachments` 教程附件表及对应上传、下载、显隐、删除接口。
- 修复帮助文档和文章 `BIGINT is_visible` 被按布尔值读取导致显隐失效的问题。

## 用户管理

- 新增当前角色模型的用户 Excel 导出，包含角色名称和稳定标识。
- 导入继续兼容旧模板，仅使用功能角色，不再创建或展示部门角色治理映射。

## 移除范围

- 移除公司级权限与数据治理审计、旧角色待映射、历史归属待确认页面及 HTTP 接口。
- 保留业务记录自身的权限范围和历史 ownership 字段，确保现有业务查询不受影响。

## 版本隔离

- 本版本从 v2.1.0 独立复制构建，数据库迁移版本为 `2.2.0-help-tutorial`。
