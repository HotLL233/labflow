# v1.3.1 人员变动反馈优化

## 本版本

- 系统管理员和分析检测组长查看、导出全部实验室；研发送样组长仅查看、导出关联实验室。
- 人员离职、实验室内调动、跨实验室调动默认勾选已有项目，取消勾选即取消关联；员工加入默认不勾选。
- 新增通知中心“人员变动反馈”规则和可配置通知字段，业务明细仍只写独立外部台账及汇总表。
- 管理入口新增“人员反馈字段”，管理员可维护变动类型和字段启停、必填、通知属性。
- 检测方法改为逐条录入，禁止逗号、顿号、分号和换行；汇总表检测方法完整显示并自动换行。

## 隔离与兼容

- 本版本仅使用人员变动功能目录中的 JSON/JSONL 和 Excel 文件，不新增人员反馈业务数据库表。
- 未修改样品信息登记、送样、分析检测、统计、用户和角色等既有业务数据结构。
- 升级安装包保留原 PostgreSQL 数据目录，热更新包备份旧程序和静态资源后再替换。
