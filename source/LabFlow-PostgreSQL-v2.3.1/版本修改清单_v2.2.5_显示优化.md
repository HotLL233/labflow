# v2.2.5 显示优化清单

## 修改日期
2026-08-27

## 问题描述

### 问题 1: 通知记录列表显示不全
- **现象**: "项目/方法"列显示内容不完整，实验室新增项目时只显示 `new_project_code`，其他信息（项目名称、检测方法、人员）未显示
- **影响**: 用户无法在列表中快速了解通知的完整信息

### 问题 2: 通知详情显示为 JSON
- **现象**: 点击"详情"按钮后显示原始 JSON 格式数据
- **影响**: 普通用户难以阅读，不符合表单填写时的直观展示方式

## 解决方案

### 优化 1: 改进列表"项目/方法"列显示逻辑

**文件**: `frontend/src/pages/PersonnelChangePage.tsx:230-246`

**修改前**:
```tsx
<TableCell>
  {[notice.project_codes?.join('、'), notice.method_names?.join('、')]
    .filter(Boolean).join(' / ') || notice.new_project_code || '-'}
</TableCell>
```

**修改后**:
```tsx
<TableCell sx={{ whiteSpace: 'normal', wordBreak: 'break-word' }}>
  {notice.change_type === '实验室新增项目' ? (
    <>
      {notice.new_project_code && <div>项目代号: {notice.new_project_code}</div>}
      {notice.new_project_name && <div>项目名称: {notice.new_project_name}</div>}
      {notice.method_names && notice.method_names.length > 0 && (
        <div>检测方法: {notice.method_names.join('、')}</div>
      )}
      {notice.person_name && <div>人员: {notice.person_name}</div>}
    </>
  ) : notice.change_type === '实验室新增方法' ? (
    <>
      {notice.project_codes && notice.project_codes.length > 0 && (
        <div>项目: {notice.project_codes.join('、')}</div>
      )}
      {notice.method_names && notice.method_names.length > 0 && (
        <div>方法: {notice.method_names.join('、')}</div>
      )}
    </>
  ) : (
    [notice.project_codes?.join('、'), notice.method_names?.join('、')]
      .filter(Boolean).join(' / ') || '-'
  )}
</TableCell>
```

**改进点**:
- 根据 `change_type` 显示不同内容结构
- 实验室新增项目：显示项目代号、项目名称、检测方法、人员
- 实验室新增方法：显示项目、方法
- 其他类型：保持原有简洁显示
- 添加 `whiteSpace: 'normal'` 允许多行显示
- 添加 `wordBreak: 'break-word'` 防止长内容溢出

### 优化 3: 改进通知详情对话框显示

**文件**: `frontend/src/pages/PersonnelChangePage.tsx:267-301`

**修改前**:
```tsx
<Dialog open={Boolean(detailTarget)} onClose={() => setDetailTarget(null)} 
        fullWidth maxWidth="md">
  <DialogTitle>通知详情</DialogTitle>
  <DialogContent>
    <pre style={{ whiteSpace: 'pre-wrap', wordBreak: 'break-word', fontSize: '0.875rem' }}>
      {JSON.stringify(detailTarget, null, 2)}
    </pre>
  </DialogContent>
  <DialogActions><Button onClick={() => setDetailTarget(null)}>关闭</Button></DialogActions>
</Dialog>
```

**修改后**:
```tsx
<Dialog open={Boolean(detailTarget)} onClose={() => setDetailTarget(null)} 
        fullWidth maxWidth="md">
  <DialogTitle>通知详情</DialogTitle>
  <DialogContent>
    <Box sx={{ display: 'grid', gridTemplateColumns: { xs: '1fr', sm: 'auto 1fr' }, gap: 1.5, pt: 1 }}>
      <Typography variant="body2" fontWeight={600}>通知编号：</Typography>
      <Typography variant="body2">{detailTarget?.notice_no}</Typography>
      
      <Typography variant="body2" fontWeight={600}>创建时间：</Typography>
      <Typography variant="body2">{detailTarget?.created_at}</Typography>
      
      <Typography variant="body2" fontWeight={600}>提交人：</Typography>
      <Typography variant="body2">{detailTarget?.actor_username}</Typography>
      
      <Typography variant="body2" fontWeight={600}>变动类型：</Typography>
      <Typography variant="body2">{detailTarget?.change_type}</Typography>
      
      <Typography variant="body2" fontWeight={600}>实验室：</Typography>
      <Typography variant="body2">{detailTarget?.lab_name}</Typography>
      
      {/* 条件显示各字段 */}
      {detailTarget?.target_lab_name && (
        <>
          <Typography variant="body2" fontWeight={600}>目标实验室：</Typography>
          <Typography variant="body2">{detailTarget.target_lab_name}</Typography>
        </>
      )}
      
      {detailTarget?.person_name && (
        <>
          <Typography variant="body2" fontWeight={600}>人员名称：</Typography>
          <Typography variant="body2">{detailTarget.person_name}</Typography>
        </>
      )}
      
      {/* 项目代号、检测方法、新增项目等字段 */}
      
      <Typography variant="body2" fontWeight={600}>生效日期：</Typography>
      <Typography variant="body2">{detailTarget?.effective_at}</Typography>
      
      <Typography variant="body2" fontWeight={600}>审批状态：</Typography>
      <Typography variant="body2">{detailTarget?.review_status || '待审批'}</Typography>
      
      {/* 审批信息、更新时间、额外字段 */}
    </Box>
  </DialogContent>
  <DialogActions><Button onClick={() => setDetailTarget(null)}>关闭</Button></DialogActions>
</Dialog>
```

**改进点**:
- 使用 Grid 布局替代 JSON 显示，采用"标签: 值"的表单样式
- 标签使用 `fontWeight={600}` 加粗
- 仅显示有值的字段（条件渲染）
- 支持响应式：移动端单列，桌面端双列
- 备注、审批说明等多行文本保留 `whiteSpace: 'pre-wrap'`
- 动态显示 `extra_fields` 自定义字段
