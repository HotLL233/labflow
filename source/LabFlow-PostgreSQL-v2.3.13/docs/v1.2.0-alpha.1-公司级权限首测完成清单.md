# v1.2.0-alpha.1 公司级权限首测完成清单

## 一、版本范围

本测试版基于公司级组织权限与数据治理实施方案，先落地“角色模板化创建”这一阶段能力，保持既有送样、分析检测、样品信息登记和数据范围逻辑不变。

## 二、已完成项

| 方案项 | 当前实现 | 使用方式 |
| --- | --- | --- |
| 角色模板数据结构 | 新增角色模板、模板权限和角色来源模板关联 | 系统启动迁移自动创建结构 |
| 内置角色模板 | 预置 8 个中文模板 | 管理员进入角色管理后选择模板 |
| 模板创建角色 | 支持从模板创建角色 | 选择模板，填写角色名称和说明后创建 |
| 空白角色 | 保留自定义空白角色创建 | 选择新增空白角色，再手工勾选权限 |
| 默认权限复制 | 模板权限复制到新角色自身 | 创建后可继续增减，不反向修改模板 |
| 角色来源展示 | 角色列表显示来源模板 | 便于识别角色是由哪个模板创建 |
| 功能权限调整 | 原有权限矩阵继续可用 | 创建后按部门实际需要增加或取消权限 |
| 数据范围复用 | 继续使用现有部门、工作部门和样品信息类型范围 | 在角色编辑页配置可见范围 |
| 旧角色兼容 | 旧角色模板来源为空但可正常运行 | 升级后无需重建旧角色 |
| 既有业务保护 | 未改变公共账号、取样、工作量归属及退回流程 | 按原流程继续使用 |

## 四、测试重点

1. 从每个内置模板创建角色，确认默认权限数量和中文模板名称正确。
2. 创建角色后增减权限，确认只影响角色自身，不影响模板和其他角色。
3. 创建空白角色，确认可以手工配置权限。
4. 编辑角色部门范围，确认原有部门数据范围逻辑不变。
5. 使用旧角色登录，确认旧角色无需绑定模板即可正常进入原有功能。
6. 使用分析公共账号、取样、工作量录入和样品信息登记退回流程回归验证。
