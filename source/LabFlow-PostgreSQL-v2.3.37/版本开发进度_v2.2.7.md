### ✅ Phase 1: 权限标签语义优化（已完成）

#### 后端改动
- **文件**: `src/models/role.rs`
- **改动内容**:
  - 扩展 `PermissionDef` 结构体，新增字段：
    - `full_label`: 完整标签（包含门户和操作范围）
    - `portal`: 所属门户（可选）
    - `actor`: 操作人员角色（可选）
  - 更新全部 80+ 权限定义，每个权限都添加了完整的双标签体系
  - 示例：
    ```rust

        key: "sample:collect",
        label: "取样（研发送样）",
        full_label: "分析检测-对研发送样取样",
        group: "门户入口",
        portal: Some("分析检测门户"),
        actor: Some("检测人员"),
    }
    ```

#### 前端改动
- **文件**: `frontend/src/constants/permissions.ts`
- **改动内容**:
  - 更新 TypeScript 接口 `PermissionDef`，匹配后端结构
  - 更新全部 80+ 权限常量定义，添加双标签和元数据
  - 保持向后兼容，现有使用 `label` 的代码不受影响

### ✅ Phase 2: 版本号统一管理（已完成）

#### 新增文件
1. **`VERSION`**: 单一版本号来源文件，内容为 `2.2.7`
2. **`scripts/set-version.sh`**: Linux/Mac 版本更新脚本
3. **`scripts/set-version.bat`**: Windows 版本更新脚本
4. **`scripts/check-version.sh`**: 版本一致性检查脚本

#### 自动化脚本功能
- `set-version.sh/bat`: 一键更新以下文件中的版本号：
  - `VERSION`
  - `Cargo.toml`
  - `frontend/package.json`
  - `build_server_installer.iss`
  - `build_hot_update_installer.iss`
- `check-version.sh`: CI/CD 集成验证，确保所有位置版本号一致

#### 使用方法
```bash
# Linux/Mac
./scripts/set-version.sh 2.2.8

# Windows
scripts\set-version.bat 2.2.8

# 检查版本一致性
./scripts/check-version.sh
```
