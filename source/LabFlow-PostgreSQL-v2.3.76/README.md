# LabFlow v2.3.76：辅助事项编号展示调整

本版隔离自已发布的 v2.3.75。辅助录入、事项选择、配置列表与编辑弹窗、主数据在线预览隐藏事项编号，页面保留名称、区域、分类、系数及原有操作和自定义配置。

程序稳定身份、API 和 Excel 模板／导出的识别字段继续保留，改名、修改配置和回导仍识别同一事项。隐藏编号不改变账号权限、人员归属、统计、历史快照或数据库结构。

历史辅助与独立事项的关联迁移、历史系数复核遗漏目前仅完成只读调查和设计，见 [历史辅助关联迁移与系数复核方案](docs/历史辅助关联迁移与系数复核方案.md)。本版不执行历史迁移、自动关联或重算。

验证及本地交付结果见本目录 `更新说明.md`、`安装包说明.md` 和仓库根 `PROJECT_MEMORY.md`。正式发布状态以根记忆与实际 GitHub 结果为准，不能把 v2.3.75 的发布证据作为本版证据。

开发、验证与安装包流程沿用仓库根 `README.md`、`PROJECT_MEMORY.md` 和 `docs/开发验证与交付自动化.md`；使用 PowerShell 7。运行库与缓存通过根 `scripts/prepare-local-build.ps1` 引用，不复制历史构建缓存。
