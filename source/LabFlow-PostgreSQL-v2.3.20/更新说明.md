# LabFlow v2.3.20 更新说明

发布日期：2026-09-23

## 一、本次主题：记录表列宽改版（一页显示全部列，内容尽量完整）

### 1. 问题

研发送样记录（16 个数据列 + 操作列）与样品信息登记 登记记录（13 个数据列 + 操作列）此前把
后台配置的 `width` 当作唯一真值，前端直接归一化成百分比，导致列宽与内容完全无关：

- 内容很短的列（部门 / 实验室 / 高项）拿到大量宽度；
- 长内容列装不下自身内容：样品信息登记记录的批号列只有 78px 却要显示 18 个字符，
  主要成分 / 注意事项被限制在 116px 且带「格内滚动条」；
- 样品信息登记记录的操作列按 6 个按钮宽度累加，独占表宽 29.9%（406px），
  比「主要成分 + 注意事项」两列之和还宽。

因为两张表都用 `tableLayout: fixed` + 百分比，桌面端**本来就没有横向滚动**；
真正没做到的是「内容尽量完整显示」。

### 2. 列宽改为四级模型

| 级别 | 来源 | 生效条件 |
| --- | --- | --- |
| ④ | 本机覆盖（localStorage） | 用户拖动表头分隔线后 |
| ③ | 管理员配置（`width` + `width_mode='custom'`） | 明确设为自定义时 |
| ② | 内容测量（`max(表头, 本页内容 P90) + 内边距`） | `width_mode='auto'`（默认） |
| ① | 系统默认区间（按输入方式） | 兜底 |

- 富余空间优先补给「可扩展列」（批号 / 主要成分 / 注意事项 / 方法），让长内容横向展开；
- 空间不足时先从「可折行列」按超出量扣减到下限，仍不足才整体等比压缩；
- `custom` 模式完全保留原行为，压缩时最后才动它，尊重既有配置。

### 3. 后端

- 新增迁移 `2.3.20-column-width-mode`：
  - `rd_record_columns` / `sample_info_columns` 各新增
    `width_mode`（默认 `auto`）、`min_width`、`max_width`（0 表示沿用默认区间）；
  - 新增系统设置 `record_table_action_mode`（默认 `auto`）与 `record_table_density`（默认 `auto`）。
- **老库升级默认走「自动」**：升级即按内容测量生效；原有 `width` 值保留在字段里不删除，
  管理员把某列切回「自定义」即可复用原值。
- 列配置的创建 / 更新接口同步支持三个新字段，并做服务端校验
  （模式仅 `auto`/`custom`；区间限 32~1200 或 0；下限不得大于上限）。

### 4. 前端

- 新增 `frontend/src/utils/recordTableLayout.ts`：列宽引擎（内容测量、上下限、富余分配、压缩、
  操作列三档）；
- 新增 `frontend/src/components/recordTable/columnLayoutHooks.tsx`：容器宽度测量、
  本机列宽覆盖、拖拽手柄、行操作收纳菜单；
- 研发送样记录：列宽切到新引擎（原先 `getRecordColumnBounds` 把配置值当 `fixed`，
  使内容测量成为死代码，该函数已删除）；长文本列改为最多两行展示；表头支持拖拽调宽；
- 样品信息登记 登记记录：`recordDisplayWidths` 改为调用新引擎并与当前页数据联动；
  `Wrap` / `valueBoxSx` 去掉 `maxHeight + overflow:auto`，改为两行展示（附件列除外）；
- 操作列收纳：样品信息登记记录改为「主操作 + 更多 ▾」，配合新系统开关
  `record_table_action_mode`（`auto` 自动收纳 / `full` 始终显示全部按钮，等同升级前）；
  研发送样记录的操作列本就是图标按钮，仅按容器宽度取档（160 / 132 / 108px）；
- 列设置菜单新增列宽来源提示与「恢复默认宽度」；表头分隔线支持拖动，
  双击恢复该列默认宽度；
- 表格配置三项接通记录表：`row_height` → 行高、`seq_column_width` → 序号列宽下限、
  `checkbox_column_width` → 选择列宽（样品信息登记记录无勾选列，不参与）。

### 5. 后台

- 研发送样字段列表、样品信息登记列列表的「宽度」列改为显示
  「自动（按内容）」或「自定义 Npx」，不再只显示一个裸数字。

### 6. 本次未包含

- 窄屏 L4「语义列合并」与 L6「隐藏最低优先级列」：需要额外的可合并列 / 列优先级配置，
  只在容器小于 1024px 时触发，留作后续迭代；
- 后台列编辑弹窗内的「宽度模式」单选区块与「全部列恢复自动宽度」按钮：本次先完成数据层与
  前台效果，后台可视化入口留作后续（数据库字段已具备，可直接切换）。
