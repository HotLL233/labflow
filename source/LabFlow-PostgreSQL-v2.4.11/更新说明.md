# labflow v2.4.11 更新说明

修复 v2.4.10 在未配置过管理导航时误报“导航配置读取失败”的问题。

- 系统设置读取接口在配置项尚不存在时返回成功的空结果，由现有页面使用默认值；读取不会创建设置记录，也不会覆盖已保存的自定义配置。
- 同步覆盖尚未配置的导航、页面布局、字段、导出模板及公告等默认读取场景。
- 原有登录与管理员权限检查保留；数据库失败、无权限、网络失败及损坏的已保存配置继续作为真实错误处理。导航告警补充具体原因和重试入口。
- 补充隔离 PostgreSQL 和真实本地 HTTP 回归，验证未配置、已保存、损坏原文、未登录、权限拒绝及数据库读取失败；前端补测默认配置与真实失败的区别。

不新增数据库迁移，不自动写入默认配置，不改业务记录、系数快照、统计口径或操作自定义。程序内品牌保留。安装包和发布事实见本目录《安装包说明.md》。
