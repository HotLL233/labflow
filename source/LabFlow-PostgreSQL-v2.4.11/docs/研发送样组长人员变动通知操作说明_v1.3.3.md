# 研发送样组长人员变动通知操作说明

适用版本：v1.3.3 及兼容的后续版本

## 1. 组长可以做什么

研发送样组长的主要职责是提交人员变动反馈，并查看本人负责实验室范围内的通知和项目人员汇总信息。

| 操作 | 研发送样组长权限 |
| --- | --- |
| 发起人员变动通知 | 可以 |
| 查看近 7 天通知记录 | 可以，仅限本人可见范围 |
| 查看项目及人员汇总表 | 可以，仅限本人关联实验室 |
| 导出汇总表 | 可以，仅限本人关联实验室 |
| 导入或更新汇总表 | 不可以 |
| 通过或驳回通知 | 不可以 |
| 编辑变动类型和反馈字段 | 不可以 |
| 配置钉钉机器人和通知规则 | 不可以 |

审批和汇总表维护由系统管理员或分析检测组长负责。组长提交通知后，不需要也不能自行审批。

## 2. 进入功能

1. 使用本人的系统账号登录。
2. 进入“人员变动通知”页面。
3. 页面顶部会显示“发起通知”、导出汇总表和刷新按钮。
4. 如果看不到某个实验室，先联系系统管理员检查用户账号的实验室关联。

研发送样组长只能看到用户数据库中与本人关联的有效实验室，不能查看其他实验室的数据。

## 3. 发起通知前先检查汇总表

发起通知前，请先查看页面下方“项目及人员汇总表”，确认：

- 实验室名称正确；
- 项目代号正确；
- 现有人员名单正确；
- 检测方法已完整列出。

组长只能查看和导出汇总表，不能在页面中直接修改。发现基线数据错误时，请将正确的 Excel 文件交给系统管理员或分析检测组长导入。

## 4. 发起通知的通用步骤

1. 在“发起通知”区域选择**实验室**。
2. 选择**变动类型**。
3. 按页面提示填写人员、项目、方法和生效日期。
4. 填写备注和当前变动类型显示的自定义字段。
5. 检查内容后点击“发起通知”。
6. 看到通知编号和“等待系统管理员或分析检测组长审批”的提示，表示提交成功。

提交后通知会立即进入通知处理流程，并出现在近 7 天记录中。实际汇总表不会立即改变，必须等管理员或分析检测组长审批通过。

## 5. 六类变动怎么填写

### 5.1 员工加入

1. 选择实验室和“员工加入”。
2. 填写人员姓名。
3. 选择该人员要加入的项目，可多选。
4. 填写生效日期和备注。

如果输入的是已有人员，系统会优先勾选该人员已关联的项目；如果没有匹配到人员，系统会显示本实验室全部项目，供组长选择。

取消某个项目的勾选，表示该项目不加入本次反馈。

### 5.2 员工离职

1. 选择实验室和“员工离职”。
2. 填写现有人员姓名。
3. 系统默认勾选该人员已关联的项目。
4. 取消不需要解除的项目，保留需要解除的项目。
5. 如需解除该人员在当前实验室的全部项目关联，可将项目全部留空。

请确认姓名与汇总表中的人员名称完全一致，避免解除错误人员的项目关联。

### 5.3 实验室内人员调动

1. 选择实验室和“实验室内人员调动”。
2. 填写人员姓名。
3. 项目下拉会显示该实验室的全部项目，不会只显示人员当前关联的项目。
4. 已关联项目默认勾选。
5. 勾选需要保留或新增的项目，取消不再关联的项目。

审批通过后，所勾选的项目会成为该人员在当前实验室的完整项目集合。取消勾选的项目会解除关联。

### 5.4 跨实验室人员调动

1. 选择当前实验室和“跨实验室人员调动”。
2. 填写当前实验室已有人员姓名。
3. 页面不填写目标实验室，也不填写目标项目。
4. 选择需要解除的当前实验室项目；如需解除全部项目，可将项目全部留空。

此类型只反馈“人员离开当前实验室的关联关系”。目标实验室的接收关系应由相关实验室组长另行发起“员工加入”或由管理员按实际情况调整。

### 5.5 实验室新增项目

1. 选择实验室和“实验室新增项目”。
2. 填写新增项目代号。
3. 点击“新增方法”，逐条填写该项目的检测方法。
4. 如为高新项目，勾选“高新项目”并填写高新项目名称。
5. 人员不是必填项；如项目已有确定人员，可填写人员姓名。
6. 填写生效日期和备注后提交。

注意：项目代号不能与该实验室现有项目重复；至少需要填写一个检测方法。

### 5.6 实验室新增方法

1. 选择实验室和“实验室新增方法”。
2. 选择要增加方法的项目，可多选。
3. 点击“新增方法”，逐条填写新增方法名称。
4. 填写生效日期和备注后提交。

至少要选择一个项目并填写一个方法。审批通过后，系统会将新方法合并到项目原有方法中，重复方法会自动去重。

## 6. 检测方法填写规则

每个输入框只填写一个方法名称，不能输入以下字符：

- 英文逗号 `,`
- 中文逗号 `，`
- 顿号 `、`
- 英文分号 `;`
- 中文分号 `；`
- 换行

有多个方法时，点击“新增方法”增加输入框，不要把多个方法写在同一个输入框中。

## 7. 自定义字段

管理员可能会根据单位要求增加字段，例如岗位、接收日期、调整原因或负责人确认情况。

- 带“必填”标记的字段必须填写。
- 只在当前变动类型适用的字段会显示。
- 日期字段按日期格式填写。
- 多行字段可填写详细说明。
- 不清楚字段含义时，请联系系统管理员确认，不要随意填写缩写。

组长不能新增、删除或修改字段配置。

## 8. 提交后查看状态

页面下方“近 7 天通知记录”显示组长可见范围内的记录。常见状态如下：

| 状态 | 说明 |
| --- | --- |
| 待审批 | 已提交，等待系统管理员或分析检测组长处理 |
| 已通过 | 审批已通过，独立汇总表已按通知更新 |
| 已驳回 | 审批未通过，汇总表没有变化；记录中会显示原因 |

点击“刷新”可以查看最新审批结果。记录默认只显示近 7 天，较早记录不在页面默认列表中。

## 9. 通知发送说明

提交成功后，系统会按通知中心的“人员变动反馈”规则发送程序内通知或钉钉通知。组长无需手动点击发送。

如果页面有通知记录但钉钉群没有收到消息：

1. 确认提交页面是否提示发起成功并生成通知编号。
2. 点击“刷新”查看记录状态。
3. 将通知编号、实验室和提交时间提供给系统管理员。
4. 请管理员在“通知中心 → 发送记录”检查规则、钉钉渠道和失败原因。

组长没有权限修改通知规则或重试发送。

## 10. 汇总表导出

1. 点击页面顶部“导出汇总表”。
2. 系统下载当前账号可见范围的 Excel 文件。
3. 导出内容只包含本人关联实验室，不包含其他实验室数据。

导出文件可以用于核对、沟通和留档。不要直接把修改后的文件当作已生效数据；需要更新系统基线时，应交由系统管理员或分析检测组长通过“更新汇总表”导入。

## 11. 常见问题

### 11.1 看不到“发起通知”

请确认登录账号具有“研发送样组长”角色。若角色正确仍看不到，请联系系统管理员检查权限和账号状态。

### 11.2 没有可选择的实验室

当前账号没有关联有效实验室，或独立汇总表中没有对应实验室。请联系系统管理员维护用户实验室关联并检查汇总表。

### 11.3 项目列表为空

请检查是否已导入项目及人员汇总表，以及所选实验室是否存在有效项目。该问题只能由系统管理员或分析检测组长处理。

### 11.4 提交时提示必须填写人员

员工加入、员工离职、实验室内人员调动、跨实验室人员调动必须填写人员。实验室新增项目和实验室新增方法可以不填写人员。

### 11.5 提交时提示项目或方法不完整

- 新增项目：必须填写项目代号和至少一个检测方法。
- 新增方法：必须选择项目并填写至少一个检测方法。
- 员工加入：必须至少选择一个关联项目。
- 实验室内调动：请确认保留或新增项目已勾选。

### 11.6 填错后怎么办

如果仍是“待审批”，请立即联系审批人说明通知编号和正确内容，由审批人驳回后重新发起。已通过的通知不能重复审批，后续修正应重新发起一条准确的通知，或联系管理员按汇总表流程处理。

## 12. 推荐操作习惯

- 提交前先对照页面下方汇总表核对人员和项目。
- 一条通知只描述一种明确变动，复杂调整拆成多条通知。
- 人员姓名使用汇总表中的正式姓名。
- 方法名称逐条填写，避免把多个方法写入一个输入框。
- 保存通知编号，后续查询或沟通时提供该编号。
- 不要直接修改程序数据库或绕过审批修改人员关系。
