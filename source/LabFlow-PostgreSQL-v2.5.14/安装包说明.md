# labflow v2.5.14 安装包说明

本版本尚未正式发布，正式下载继续使用根 README 列出的版本。

- 正式发布后，已有完整服务器安装使用 `labflow-v2.5.14-hotupdate.exe`，首次安装使用 `labflow-v2.5.14.exe`；Windows 数字版本为 `2.5.14.0`。
- 升级前备份数据库、附件和配置。应用启动会增加计费快照字段，并撤销已确认失效的多步骤费用。先在隔离备份副本运行，核对受影响月份的金额及作废原因 `incomplete_after_legacy_delete`、`record_deleted`。需要完全还原时，使用升级前备份，不能只替换可执行文件。

统一登录仅供受控试点。管理员预选人员时撤销其原本地密码会话；关闭试点开关不会恢复已预选人员的密码登录。需保留受控本地管理员，以便完成仍要求本地密码确认的管理操作。详见[统一登录试点](docs/统一登录试点.md)。
