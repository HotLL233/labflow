# labflow v2.5.14 更新说明

- 按人员或日期批量删除分析检测时，在同一事务内重核步骤和计费。删除使整单未完成时撤销正常费用；删除付费返工时撤销该笔费用。顺序检测校验整批删除后的状态，剩余步骤违反顺序时整批回滚。
- 研发送样和样品信息存在有效工作量时，不允许删除、撤回取样或退回来源。已删除的来源先恢复，再恢复关联工作量。历史已软删的研发来源若仍有有效步骤计费，研发与分析报表均保留该笔费用，不自动恢复来源。
- 研发工作量明细区分完成样品数和各步骤录入数量合计。检测数量按最后完成必要步骤的业务日期归属，返工不增加样品数；多步骤金额仍按计费生效日期筛选。
- 研发「检测类型汇总」与项目金额表共用计费数据，未完成的多步骤不提前计费，正常和付费返工按冻结单价与倍率计费。金额只归入一个检测类型，避免方法挂多个类型时重复计费。研发其他送样数量表仍是送样数量，不是完成检测量。
- 新普通分析记录保存单价快照；新研发送样记录保存单价和倍率快照。明确更换关联方法时按新方法取价。原无快照记录保留原计价回退，不拿当前价格回填历史。0 单价和 0 倍率仍是有效值。
- 升级迁移只将已删除返工或实际未完成检测的残留有效费用标记为作废，保留原账行及原因，不补发费用。工作量 API 合约、权限、统一登录开关和现有令牌不变。修改或删除后需要重新拉取受影响月份，已下载的 Excel 不会自动更新。
