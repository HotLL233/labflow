# labflow v2.5.12 安装包说明

- 已有完整服务器安装：使用 `labflow-v2.5.12-hotupdate.exe`。首次安装：使用 `labflow-v2.5.12.exe`。Windows 数字版本为 `2.5.12.0`，产品 `labflow`，发布者 `HotLL`。
- 正式资产以 [GitHub Release](https://github.com/HotLL233/labflow/releases/tag/v2.5.12) 的 `SHA256SUMS`、`manifest.json` 和 `DELIVERY-CHECKLIST.md` 为准。Docker 使用 `ghcr.io/hotll233/labflow:2.5.12`。本地验证产物不替代正式资产。
- 升级前备份数据库、附件和配置。统一登录默认关闭，升级不会迁移现网人员，也不会更改现有工作量 API 令牌。

统一登录仅供受控试点。管理员预选人员时撤销其原本地密码会话；关闭试点开关不会恢复已预选人员的密码登录。需保留受控本地管理员，以便完成仍要求本地密码确认的管理操作。新增迁移不回填人员、角色、部门、实验室或业务历史，详见[统一登录试点](docs/统一登录试点.md)。
