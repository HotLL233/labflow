# labflow v2.5.12 更新说明

- 默认关闭的 OIDC 试点：Keycloak 授权码 + PKCE 登录；预选现有个人账号，人工确认验证后的中心身份。新增迁移只增加绑定表、账号准入视图和会话截止字段。
- 保留非试点账号入口、原业务权限和历史归属。试点人员不再通过原密码入口登录；应用登出立即撤销会话，中心撤权或停用时旧会话绝对截止不超过 15 分钟。
- 延续 v2.5.11 的工作量 API 永久删除：系统管理员可删除指定接入（含已停用、已到期项），删除后原令牌失效，不影响其他接入或业务数据。
- 安装或升级不会自动开启统一登录，不迁移现网人员；须按[统一登录试点](docs/统一登录试点.md)配置并验证后再启用。
