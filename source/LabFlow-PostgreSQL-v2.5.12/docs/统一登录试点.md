# LabFlow 统一登录隔离试点

## 接入契约

默认关闭，不自动创建、合并或匹配人员。只核验一个固定 HTTPS issuer、一个 confidential client、精确 HTTPS 回调。授权码、`state`、`nonce` 和 `PKCE S256` 由服务端 OIDC 库校验；Keycloak 通过已签名的 ID Token 的 `labflow_roles` 数组声明本客户端的 `pilot-access`。不把中心角色当业务角色，不信任前端身份、邮箱、同名账号和反代头。试点使用 RS256。

| 进程环境 | 含义 |
| --- | --- |
| `LABFLOW_OIDC_ENABLED` | 仅 `1` 开启；未设置或配置不完整时不开放入口，不解除已预选人员的密码限制 |
| `LABFLOW_OIDC_ISSUER` | 完整发证方，如 `https://127.0.0.1:28443/realms/labflow-pilot` |
| `LABFLOW_OIDC_CLIENT_ID` | 此应用实例专用的 OIDC client ID |
| `LABFLOW_OIDC_CLIENT_SECRET` | 通过私有配置仅注入服务端，不进入前端、模板或安装包 |
| `LABFLOW_OIDC_REDIRECT_URI` | 固定 HTTPS URL，路径为 `/api/auth/oidc/callback`，禁止通配、查询串、片段；反代保留此 Host |
| `LABFLOW_OIDC_CA_FILE` | 可选 PEM 公共证书供隔离 CA 或测试自签名证书使用；不跳过 TLS 验证 |
| `LABFLOW_BIND_HOST` | 后端绑定的 IP；隔离、反代后端用 `127.0.0.1`，不设置则保持旧监听方式 |

网页发起和兑换均要求正确的 `Host` 和同源 `Origin`。回调 GET 验证本次 `Secure`、`HttpOnly`、`SameSite=Lax` 交易 Cookie 和一次性 `state`。交易有效期 5 分钟；回调后旋转 Cookie 为 60 秒一次性兑换凭证，只返回站内登录页，不支持外部 `return_to`。不把本地 Bearer 或中心 Token 放在 URL、日志或前端配置里；回调的反代日志也不得记录查询串、Cookie 和认证头。

## 绑定 API

使用现有系统管理员 Bearer。所有写操作只针对已有人员 ID，写入审计（预选、候选、确认、撤销、OIDC 登录）。24 小时邀请码只返回一次，数据库仅存摘要，不是业务凭证。管理员要独立核对人事名册、工号和中心客户端实际返回的身份标识。工号规范为大写字母、数字、短横线、下划线或点；重复工号、重复中心身份、候选不符、公共账号和停用或无角色的非管理员账号拒绝绑定。

| API | 请求/响应 |
| --- | --- |
| `GET /api/auth/oidc/bindings` | 返回 `user_id`、`username`、`employee_no`、`issuer`、`subject` 和 `status`；不返回邀请码或凭据 |
| `POST /api/auth/oidc/bindings/{id}/invite` | `{ "employee_no": "EMP-123", "reason": "已核对人员名册" }`；返回一次性邀请码。候选或已确认时先核对并撤销，不能直接覆盖 |
| `POST /api/auth/oidc/bindings/{id}/confirm` | `{ "issuer": "...", "subject": "...", "reason": "人工核对依据" }`；只可确认真实回调已提交的候选 |
| `POST /api/auth/oidc/bindings/{id}/revoke` | `{ "reason": "人员停用或核对异常" }`；清空映射和邀请，立即撤销 LabFlow 会话，保持原密码入口禁用 |

工号和姓名不是登录绑定键。角色、部门、实验室、历史外键和原工作量 API 接入不迁移、不重算、不改写。未入选人员及公共账号保留原入口；公共入口的替代流程后续另议。

## 会话与回滚

换码前设绝对截止，最多 900 秒。沿用两设备、同设备替换和应用退出；OIDC 会话不记住登录、不滑动续期。受保护 API 检查截止时间、绑定状态、账号与本地角色。延长会话要通过统一登录按钮重新授权、重新检查中心准入，不用旧 ID Token 或刷新令牌延长应用会话。中心中断时不能开始新统一登录；此前已签发会话仍受同一上限。

关闭开关并重启会撤销 OIDC 会话，但不恢复试点人员旧密码。应急管理员须保留受控内网入口；恢复某人旧入口须先复核中心停用名单并独立审批，不通过关闭开关、降级至不认识绑定策略的程序或恢复旧数据库绕过。当前交易存于单实例内存，重启作废。本试点不支持多实例切换、推送撤销或统一全局退出。
