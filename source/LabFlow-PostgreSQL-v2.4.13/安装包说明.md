# labflow v2.4.13 安装包说明

本版实现实际计量方法改选、公共账号实际送样人及兼容旧权限配置的优化。本地构建、隔离数据库、真实 HTTP 和浏览器验证已通过；正式 Windows 两包、GitHub Release 和 GHCR 均已发布，正式五资产已取回并核对摘要。未安装或升级现场服务。

完整包用于首次安装，已有完整服务器安装使用热更新包。数字版本 2.4.13.0，产品 labflow，发布者 HotLL。程序内“知微 / 样品管理系统”及自定义品牌保留。升级前备份数据库、附件和配置。

## 兼容范围

- 旧权限标识、角色和数据范围继续读取，不重置既有授权，不按角色模板重建用户配置。
- 角色功能权限与范围的新保存接口为原子事务；旧版分别保存的接口继续按部分更新契约处理。管理员专属及组长职责约束仍由服务端执行。
- 新计量字段为可选，旧工作量请求继续走原验证；新录入保留来源方法，历史快照不自动重算，不修改历史业务时间或人员。
- 新增 `2.4.13-manual-sample-submitter` 幂等迁移，为账号增加默认关闭的手填实际送样人设置。两类公共账号使用原稳定身份识别，不依据账号名称猜测。
- 新增 `2.4.13-persistent-role-permissions` 标记，只为全新安装初始化通知管理权限；升级保留已有授予与撤销，重启不再补授。原权限表不变。
- 公共账号旧客户端提交空白或占位送样人将明确拒绝，须升级页面并填写真实送样人；个人旧客户端留空仍按原逻辑使用本人。
- 新记录按所选实际方法的配置读取单价，字段为 `methods.amount`，并保存系数及倍率等已有计量快照。历史金额继续采用原有的当前方法单价口径，本轮没有新增历史单价快照或批量重算历史金额。
