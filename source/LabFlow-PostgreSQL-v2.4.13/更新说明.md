# labflow v2.4.13 更新说明

本版按已确认方案优化计量方法选择、公共账号实际送样人与角色权限管理，保留原送样流程和历史记录。

- 送样人仍提交原方法。检测人在常规工作量录入、研发送样及样品信息登记的录入窗口，可按关键词搜索并确认实际计量方法；原方法默认带入，不根据名称自动替换。特殊处理作为独立检测方法维护，不增加下级处理方式配置。
- 实际方法使用其工作量系数、仪器单价和默认金额倍率；手动修改的倍率予以保留，也可恢复方法默认值。保存前复核当前配置，配置已改变时要求重新核对。原提交方法保留为来源，分次采用不同实际方法仍共享同一份样品剩余数量。
- 历史系数快照不自动重算，原方法、来源、业务时间、检测人员和统计口径保留。新字段未传时继续支持旧请求；默认的原送样方法不因未显示在手动录入库而被误拦截。
- 两类公共账号新增样品登记时，实际送样人默认留空，逐行填写并校验；个人账号仍默认本人。旧草稿保留，疑似公共账号自动填名须重新确认。管理员可为其他账号独立开启“要求填写实际送样人”，该设置不改变账号角色或授权。
- 角色功能权限和数据范围改为一次事务保存，使用配置修订拒绝并发覆盖；旧版分别保存权限或范围的接口继续兼容。保存失败保留输入，不再出现只保存一半却统一提示失败的情况。
- 停止启动时重新授予已撤销的通知管理权限。原权限标识、角色配置、多角色数据范围配对、管理员与组长职责限制保留；系统必需内部项只读展示，历史兼容项明确说明。
- 用户列表增加实际权限查看；仪器管理、帮助维护和辅助工作入口按原服务端能力显示，避免只有入口却无法操作，也不以入口调整扩大权限。
- 网络中断或服务器异常导致提交结果未知时保留填写内容并提示先核对记录，避免直接重复提交；这不替代服务端业务容量校验。

新增幂等的账号手填设置字段迁移及通知权限初始化完成标记（不新增权限表）；不改已发布迁移标识，不回填业务记录，不新增依赖。既有自定义布局、按钮、品牌、账号归属及辅助工作独立配置继续保留。程序内“知微 / 样品管理系统”名称不变。

验证、安装包及各渠道发布事实以《安装包说明.md》为准；发布软件不自动更新现场服务。
