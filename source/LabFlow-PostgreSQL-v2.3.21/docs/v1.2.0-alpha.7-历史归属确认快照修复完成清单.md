## 本版本完成内容

### 1. 修复历史分析记录确认后的归属快照

管理员在“历史归属待确认”中确认分析检测记录后，现同步写入：

- 检测部门 ID 和名称快照：取确认的执行部门。
- 送样部门 ID 和名称快照：取确认的执行实验室所属部门。
- 送样实验室 ID 和名称快照：取确认的执行实验室。
- 执行部门、执行实验室名称快照同步补齐。
- 记录状态改为 `confirmed`。

因此确认后的记录会立即进入检测部门筛选、送样部门联动、统计预览和 Excel 导出，且组织主数据后续改名不会改变历史快照。

### 2. 修复跨部门历史归属确认

分析检测记录允许“检测部门”和“送样实验室所属部门”不同：

```text
检测部门：分析人员实际所属部门
送样部门：选定实验室所属部门
```

旧逻辑错误地要求执行实验室必须属于执行部门，alpha.7 改为：

- 分析检测历史记录：实验室只需存在且有效，送样部门由实验室归属确定。
- 研发送样、样品信息登记历史记录：继续保留原有执行部门与实验室一致性校验。
- 分析检测历史记录未指定实验室时拒绝确认，避免产生缺少送样部门的“已确认”数据。

### 3. 数据库迁移

新增迁移：`1.2.0-alpha.7-ownership-confirmation-snapshots`

- 为已规范的分析记录增加检测部门、送样部门和状态联合索引。
- 迁移可重复执行，不重复写入版本记录。
