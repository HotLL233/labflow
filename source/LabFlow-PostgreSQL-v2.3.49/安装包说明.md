# LabFlow v2.3.49 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.49.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和重新构建的前端资源。
- 热更新包：`installer/LabFlow-v2.3.49-HotUpdate.exe`，仅用于已有完整服务器安装的升级。
- Windows 产品和文件版本：`2.3.49.0`。本地产物校验文件位于版本 `installer/`；仓库根 `installers/` 由 CI 留存正式发布包。
- Docker 镜像：`ghcr.io/hotll233/labflow:2.3.49`；部署文件继续使用仓库根 `docker-compose.deploy.yml`。
- 默认端口8000；账号密码、数据位置按安装向导和现有配置，升级保留原密码与业务数据。

## 本次变化

本版增加记录操作按钮的管理员全局配色，覆盖研发送样、样品信息登记及分析检测录入页面的电脑和手机。管理员进入对应页面“表格样式 → 操作按钮配色”，选择按钮和状态，设置文字、背景及边框颜色，点击“发布为全局”；其他用户重新进入页面后生效。分析检测的配色入口位于工作量录入页面的“今日记录”区，无记录时也可配置。

操作前、提交中、部分录入、已完成及不可操作分别配置；留空沿用系统原色。颜色只对应真实业务状态，不改变权限和点击行为：样品“已录入”仍不可重复提交，研发“已录入”仍可查看原明细；取样后继续在取样人列显示姓名。默认完成态修复为绿色，避免禁用样式把已成功操作误显示为普通禁用灰色。

保留按钮尺寸、位置、顺序、列显隐及宽度、手机摘要、字号和内外边框配置。桌面保持一页显示全部列，手机沿用紧凑记录布局；已有取样、完成检测、编辑、退回、工作量录入及统计入口继续按原规则工作。

## 升级与验证

升级前按原流程备份数据库和附件，再运行完整包或热更新包。备份恢复的事务与待恢复任务规则不变。不得删除待恢复标记绕过失败；不包含生产配置、凭据或业务数据。

从正式v2.3.48隔离源码，不复制旧构建产物、依赖、运行库或安装包；前端、服务器、完整包和热更新包重新构建。本版无新数据库迁移，已有分类快照及工作量统计口径保留，不重算历史数据。

31项前端回归、9项实际React/MUI服务端渲染配色检查、Rust格式/编译/管理员配置权限单测及前端生产构建通过。隔离服务、安装包和CI发布的最终核对结果见仓库根PROJECT_MEMORY.md。本轮界面自动化不可用，未完成真实浏览器、生产覆盖安装或实际容器运行验收。

既有取样工作量弹窗方法系数预估与实际项目系数统计差异仍待统一，本版未修改统计规则或重算历史数据。
