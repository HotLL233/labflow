# LabFlow v2.3.43 安装包说明

- 完整服务器包：`installer/LabFlow-v2.3.43.exe`，用于首次安装或跨电脑部署，包含 PostgreSQL、VC++ 安装器、PDF 工具和前端资源。
- 热更新包：`installer/LabFlow-v2.3.43-HotUpdate.exe`，仅用于已安装完整服务器版的升级。
- Windows 产品和文件版本：`2.3.43.0`。本地产物 SHA-256 见同目录 `installer/checksums.sha256`。
- 默认程序端口为 8000；实际端口、数据位置与初始管理员密码以安装向导和已有配置为准。升级保留已有账号密码与业务数据。
- Docker 镜像由 GitHub 工作流发布 `ghcr.io/hotll233/labflow:2.3.43`，部署配置位于仓库根 `docker-compose.deploy.yml`。

## 本次变化

手机摘要采用字段网格和独立内框，外框与内框的颜色、粗细均在“表格样式 → 手机卡片”设置。取样及操作按钮统一40px最小高度、圆角和左对齐位置，样品自定义按钮宽度与排序保留。继续支持三/四组摘要、完整详情与管理员全局发布。

## 升级与恢复

升级前按既有流程保存数据库及附件备份，再运行完整包或热更新包。备份恢复的数据库清空、导入、关键表校验处于同一事务；附件保留暂存内容供重试。数据库和文件不是整体事务，恢复失败会停止启动，排除错误后重启完成同一恢复任务，不能删除待恢复标记强行继续业务。

## 验证范围

本版完成前端类型检查和生产构建、10项布局/摘要/工作量相关测试、Rust格式检查与编译。浏览器使用真实组件和模拟接口验证320/390/480/768像素手机及1280像素桌面、自定义列宽和操作列位置；未在生产数据库或现场覆盖安装测试。数据库业务逻辑及历史迁移沿用v2.3.42。

未在生产数据库上运行测试，未在真实业务服务器执行覆盖安装。现场升级仍需核对原角色配置、历史报表及附件。
