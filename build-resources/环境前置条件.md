# 重建环境前置条件

- Windows 10/11 x64。
- Rust stable MSVC：本次构建使用 `rustc 1.97.1`、`cargo 1.97.1`。
- Node.js：本次构建使用 Node.js `24.18.0`、npm `11.16.0`。
- Inno Setup 6：`C:\Program Files (x86)\Inno Setup 6\ISCC.exe`。
- 首次执行重建脚本需要网络访问 npm registry，以便 `npm ci` 按 `package-lock.json` 安装前端依赖。
- 完整安装包运行时不需要 Node.js、Rust、Inno Setup 或联网。

在交付包根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build-resources\build_full_installer.ps1
```

若重新执行，先检查并删除交付包根目录内的 `_build_v2.2.18` 临时构建目录。不要删除 `source`、`installers`、`build-resources`、`checksums`。
