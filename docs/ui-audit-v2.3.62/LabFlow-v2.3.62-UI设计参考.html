依据 v2.3.62 评审方案绘制：单一品牌绿、3 档圆角、6 档字号、语义色独立。表格沿用现有 38px 行高 / 36px 表头 / 1px 边框 的实测规格，不推翻可配置样式引擎。本稿仅用于视觉方向确认，不含业务改动。
