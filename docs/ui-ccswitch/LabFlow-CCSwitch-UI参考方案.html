LESS VISUAL NOISE · CLEARER WORKFLOW

把清晰的层级，
带进日常实验室工作。

参考 CC Switch 的导航、状态与设置布局，保留 LabFlow 的业务密度、已有主题和操作习惯。先统一视觉表达，再按需优化门户。

仅方案，不改程序代码本地对照：v2.3.40桌面 / 手机交互原型
建议采用：中性底色 + 明确状态 + 分组设置

卡片适合业务入口和实验室选择。多列记录继续使用表格；手机使用完整字段卡片。避免为了“像 CC Switch”而压缩业务信息或替换组件库。

01 / OBSERVATIONS

CC Switch 的长处与限制

以下观察来自官方截图与固定提交源码；不等同于对你本机安装版本的实测。

层级明确，扫描负担小

官方截图把名称、地址、当前状态放在固定区域，白底和边框形成稳定分组。当前源码又把背景、文字、业务模式色、状态色拆成统一变量。

  • 优点：颜色减少后，当前项和关键动作更容易识别。
  • 限制：供应商卡片字段少；搬到样品记录会明显降低一屏可见记录数。

主次动作与状态分开

按钮源码区分页级主操作、描边、弱按钮、危险操作。供应商卡片以文字徽标表示当前模式与健康状态，避免只靠颜色表达。

  • 优点：减少多个实心按钮互相争抢注意力。
  • 限制：桌面 28/32px 控件不能直接照搬到手机；关键行操作也不应全部藏入菜单。

设置像目录，而非大表单

当前设置布局采用“分节标题 → 边框卡片 → 设置行”，名称在左、控件在右。术语可放帮助提示，操作后果需直接可见。

  • 优点：配置范围、开关和编辑入口更容易区分。
  • 限制：过度隐藏说明或只靠悬停会增加新用户理解成本，手机尤其明显。
参考版本说明：README 截图是较早的卡片界面；本次固定提交的源码已有 v7 侧栏与设置系统。方案综合两类证据，未把截图当作 v7 实机画面。

优先级
中性背景与轻边框

首页三种大面积渐变、卡片阴影与主题色并存；入口醒目，但视觉强度较高。

入口用白底、业务色小标记与轻边框。保留三入口与权限过滤，不强制替换品牌或用户配置的主题色。

高 · 视觉
清楚的当前位置

管理区已具备分组侧栏、折叠与手机抽屉；顶部品牌、抽屉品牌呈现不同。

统一“品牌 / 模块 / 页标题”的层级。管理区侧栏保留；记录页不额外放宽侧栏占用列宽。手机业务页标题明确当前入口。

高 · 导航
单一页级主操作

不同页面按钮与颜色较分散；复杂记录本身包含多种必要动作。

页头主操作实心；筛选、导出、配置用描边或弱按钮。取样、录入工作量、编辑、退回仍保留在操作列，允许管理员配置顺序和大小。

高 · 交互
设置分节与作用范围

已有管理导航与 ResponsiveEditDrawer，可用于全局列配置。

配置列表精简为记录；编辑抽屉分成显示、列位置、宽度、按钮顺序等区。直接标明“仅管理员编辑 · 应用到所有用户”。

高 · 管理
状态优先，少靠颜色

记录有业务状态与工作量状态；两者不能互相代替。

“待取样 / 检测中 / 已完成 / 已退回”作为文字状态；工作量按钮独立呈现“已录入”。弹窗突出当前操作人、仪器、数量与倍率。

高 · 记录
紧凑入口卡片

公共账号人员选择页已是紧凑卡片，不必全部翻新。

统一门户和实验室卡片的标题、次级信息与进入位置。公共账号当前归属人员必须保留；增加任务摘要须先验证接口和权限范围。

中 · 门户
桌面与手机一致的语义

已有独立手机展示与桌面列配置；长期规则是一页显示全部列。

桌面按相对宽度分配全宽，单元格内换行/滚动；手机完整字段卡片复用列顺序、显示开关与按钮排序。配置有可见入口，不能只靠右键。

高 · 响应式
浅色 / 深色设计变量

已使用 MUI ThemeProvider 与服务端主题；部分页面仍硬编码颜色和圆角。

先收敛中性颜色、间距与控件层级，继续使用 MUI。深色模式后置，等表格、图表、弹窗、打印与预览能一起验证再引入。

03 / KEEP THE BUSINESS DENSITY

不宜照搬的部分

不把高密度记录变成桌面大卡片

研发送样、分析检测和样品信息登记需要横向比较多字段。保留全宽表格与字段边框，表头右键作为管理员快捷入口；另保留可见的“列设置”按钮。不能用整表横向滚动解决列宽问题，也不默认隐藏重要字段来制造整洁感。

不搬技术栈与桌面专用交互

无需引入 CC Switch 的 Radix、shadcn、Tauri 或拖拽库。复用本项目的 MUI、ManageNav、ResponsiveEditDrawer。手机点击区域建议至少 44px；排序同时提供上移/下移或位置选择，危险设置明确保存，不能无提示自动生效。

05 / ADOPTION PLAN

推荐分三步采纳

先统一已有界面，按需要增加新功能；不同时修改业务逻辑、接口与整套视觉体系。

第一步 · 推荐

统一基础视觉与记录状态

梳理 MUI 主题中的中性底色、文字层级、边框、控件尺寸。统一页标题、按钮主次、文字状态和错误提示，降低首页大面积渐变与重阴影。

投入：小至中。优先做样品信息登记和研发送样的页面样例，再迁移同类页面。视觉样例确认后才实施。

第二步 · 推荐

统一设置页与手机记录

后台按分节设置行呈现，编辑沿用已有抽屉。列配置的范围与保存时机明确，手机卡片使用同一配置数据，所有字段与操作可访问。

投入：中。涉及配置消费和响应式一致性，须核对旧列配置兼容与角色权限，不能仅更改 CSS。

第三步 · 按需

门户摘要与更多主题

实验室选择页采用统一紧凑卡片。任务摘要仅在已有接口能准确区分本人/部门/实验室时增加。深色模式与个性化密度按实际需求后置。

投入：中至较大。新增统计有接口与权限成本；不凭界面上的演示数据直接实施。

07 / PAGE COVERAGE

各页面如何落地

首页与实验室入口

三大入口不变，品牌区适度缩短。白底卡片、统一图标尺寸和进入位置；只显示当前用户有权访问的入口。公共账号选择人员页面保留当前工作量归属提示。

三类业务记录与工作量

统一筛选栏、字段边框和文字状态，按各业务保留原字段与流程。工作量弹窗明确当前录入账号；多个仪器提供选择。后端成功后刷新按钮，失败不显示已录入，也不替换取样人员信息。

公告与角色权限

公告管理采用记录列表，编辑打开侧栏；入口显示未读数量，用户明确确认后更新。权限矩阵继续适合表格，用分组标题、搜索、范围说明加强理解；不能用简洁开关替代权限含义。

备份、导入、导出与帮助

日常设置按行呈现，危险操作单独分节。恢复和清理直接显示影响范围、确认步骤与结果。导入保留校验摘要；导出模板保留列映射。帮助页分组目录、步骤示例，错误提示始终可见。

08 / ACCEPTANCE

将来实施时的验收条件

  • 桌面 1024 / 1280 / 1440px 均无整页横向滚动；全部启用列在内容区内显示，修改列宽会真实改变比例，长文本单元格支持独立滚动。
  • 手机 360 / 390 / 430px 字段完整，操作不被裁切；与桌面同步显示开关、字段顺序、操作列位置和按钮顺序，安全区不挡按钮。
  • 管理员保存列配置后，其他用户刷新或收到既有配置更新事件可见；普通用户无法发起全局编辑，后端拒绝越权请求。
  • 保存有处理中、成功和失败状态；失败保留当前输入与配置草稿。取消不改已保存配置，关闭有未保存更改时提醒。
  • 已录入工作量状态以后端成功响应为准，刷新页面仍正确；操作账号与取样账号明确区分，多仪器选择和数量倍率校验保留。
  • 公告确认记录与角标遵守现有用户维度规则；只关闭弹窗不擅自记为已确认。主题、打印、权限和原导出结果不因 UI 改造改变。
  • 键盘能进入单元格滚动区、打开配置、关闭弹层；手机不依赖右键；文字对比度与错误说明可读。
