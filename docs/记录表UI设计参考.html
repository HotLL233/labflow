适用范围：样品信息登记记录、研发送样记录、分析检测今日记录。v1/v2 关于「表头简称、选择列、操作列」的结论继续有效，本版把目标改写为「一页全显示」，并给出量化依据与降级阶梯。

2. 五种可选方案对比

方案做法优点代价
横向滚动（最终兜底）表格 minWidth 超容器即产生横向滚动条实现最简单，绝不截断 与「一页看全」目标直接冲突；当前两张表未使用（靠百分比压缩代替，代价是内容被挤）
智能列合并部门+实验室+项目竖排进一列列数减半，一定放得下 牺牲单列排序与筛选（需分级菜单补偿），信息架构变动大
列优先级自动隐藏按 P0/P1/P2 优先级，宽度不够时自动隐藏低优先级列始终一页，宽度自适应 「全部列」在窄屏必然看不到，与目标字面冲突
密度档切换紧凑（12px/32px 行高）/ 标准 / 舒适不改结构，用户自己选 只能省 8%~15%，单独用不够
内容自适应 + 阶梯降级 （推荐） 列宽按内容测量；空间不足时按固定顺序降级（简称表头→两行换行→次要信息竖排） 一页全显示、内容不截断、几乎不牺牲排序筛选 需要统一列宽算法（约 1 个模块 + 3 张表接入）
推荐组合：以「内容自适应 + 阶梯降级」为主体，「密度档」作为用户可选补充；「列优先级自动隐藏」只在极端列数（>14 列）时作为最后一级，且必须显式提示"N 列已隐藏，点此查看"。

3. 内容自适应：列宽怎么算

  1. 自然宽 w_i = max(表头宽度, 内容样本 P90 宽度) + 单元格内边距；表头宽度用「列表简称」，内容样本取当前页 + 最近一次全量统计的 P90（避免单条超长把列撑开）。
  2. 类型上下限：数字 [56, 96]、日期 [112, 150]、短文本 [64, 160]、长文本（备注/成分）[120, 360]、状态 [84, 110]。
  3. 固定列：选择列 44、序号列 64、操作列 [120, 160]（图标化或"主操作 + 更多"），三者不参与剩余空间分配。
  4. 富余分配：R = 容器宽 − Σw_i。若 R > 0，按「可扩展列」顺序吸收（备注/成分 → 项目名 → 批号），每列上限 2.2 × w_i；吸不完的余量再按比例均分给所有数据列，保证表格铺满、无右侧空白。
  5. 不足时：进入第 5 节阶梯降级，而不是压缩到不可读。

4. 一页全显示的四条规则

规则内容作用
R1 操作列封顶操作列固定 [120, 160]px，主操作 + 「更多 ▾」；图标化后单按钮 ≤ 32px样品信息登记表可直接回收 22% 表格宽度（628 → 160），是补上缺口的第一大来源
R2 内容定宽列宽由内容测量决定，后台配置值只作为「权重参考」与上下限约 1500px 的内容需求不再被 2034 / 2102 的权重稀释成平均 73~85px
R3 长文本吸收富余备注/主要成分/批号标记为可扩展列，优先吃富余空间，最多 2.2 倍自然宽「内容尽量全显示」的落点：批号 67 → 167px，备注 100 → 200px
R4 纵向换行替代横向挤压长文本列允许两行（line-clamp: 2），行高按需增长；短字段列保持单行纵向空间比横向便宜，且不牺牲列数；顺带去掉单元格内滚动条

5. 阶梯降级：放不下时按顺序启用（不牺牲可读性）

级手段省下触发条件与说明
L1表头改用「列表简称」表头 20~40px始终启用（未配简称自动回退全称并省略号）
L2单元格内边距 12px → 8px，字号 13px → 12.5px约 6%总需求 > 容器宽且处于「标准」密度档
L3长文本列两行换行（行高 +14px）长列 30%~45%备注/成分列内容超自然宽时
L4次要字段竖排进主列第二行（部门 / 实验室 / 项目 → 「组织」列三行）2~3 列宽仍不足时；仅限后台标记为「可合并」的字段，排序取主字段
L5数字/日期列切紧凑（数量 48px、时间两行显示）约 4%仍不足时
L6隐藏最低优先级列（P2），表尾提示「N 列未显示」按列计列数 > 14 或超宽容器仍不足；用户可在列设置中改优先级
关键约束：L1~L5 全程保持「所有列都在一页内」，不产生横向滚动；只有 L6 会隐藏列，且必须给出可点开的提示。横向滚动仅保留为 L6 之后的最终兜底。

7. 操作列：按按钮宽度自适应（沿用 v2 结论，补图标化档）

档位宽度触发条件与表现
文字档Σ按钮宽 + 间距 + 24，上限 160px容器 ≥ 1400px：主操作 + 次操作 + 「更多 ▾」
图标档88px（2 个图标 32px + 间距 + 内边距）容器 1024~1400px：主操作文字 + 图标按钮（悬停显示名称）
收纳档120px（主操作 + 更多）容器 < 1024px：仅主操作 + 「更多 ▾」菜单
三档都不参与剩余空间分配，宽度固定后交给数据列；按钮的权限与状态判断完全复用现有逻辑，仅改展示位置与形态。

9. 与后台配置的对应（已确认）

配置项现状本期
列宽模式 width_mode无此概念，配置的 px 即固定宽度新增（迁移 2.3.20-column-width-mode）：auto（默认，走内容测量）/ custom（固定）。老库升级默认 auto
自定义区间 min_width / max_width无，只有前端的隐式上下限新增：0 表示沿用系统默认区间（按输入方式给：数字 48~96、日期 104~150、长文本 120~360 等）
列宽 width单一 px，48~500，前端当固定宽度直接使用仅在 custom 模式下生效；升级时原值保留不删除，切回自定义即可复用
操作列收纳开关 record_table_action_mode无，操作列宽度＝Σ按钮宽 + 24（上限 1600）新增：auto（默认，按容器宽度三档收敛）/ full（始终全显示，等同升级前）。三档阈值亦为可配项
选择列 / 序号列 / 行高界面已有（ManageFormConfig.tsx），但两张记录表从未读取接通：row_height → 行高；seq_column_width → 序号列宽下限；checkbox_column_width → 选择列宽（仅研发送样记录有此列）
用户级列宽（本机）无新增：拖拽调整列宽 + 「恢复默认宽度」，存储键 labflow.record-col-widths，优先级最高
可扩展列无新增布尔配置：勾选后优先吸收富余空间（样品主要成分 / 注意事项 / 批号 默认勾选）
可合并列无新增布尔配置：允许 L4 降级时竖排进主列（所属部门 / 实验室·车间 / 所属项目 默认勾选）
列优先级无新增 P0/P1/P2：仅 L6 极端降级时用于决定隐藏顺序
列表表头简称 list_label无，表头只能用表单全称待定：表头先按库 label 原文两行折行，是否需要简称后续再评估
两项回退保障：① 任意列都可单独「恢复自动宽度」，保留自定义值不删；② 列管理页提供「全部列改为自定义」，一键整体回到升级前的固定宽度模式。

10. 落地清单

  1. 迁移 2.3.20-list-label：sample_info_columns、rd_record_columns 各加 list_label（可空）；同批加 is_expandable、is_mergeable、list_priority 三列（均有默认值，向后兼容）。
  2. 新增 frontend/src/utils/recordTableLayout.ts：内容测量 + 上下限 + 富余分配 + 阶梯降级，输出每列 px / lineClamp / hiddenLevel，替换现有 5 处各自实现。
  3. 新增 RecordTableHeadCell（单行标签 + 排序 + 筛选三态）与 ResponsiveRecordTable（列宽计算 + 密度档 + 选择列/操作列固定）。
  4. 三张记录表接入：样品信息登记记录（改动最大，需去掉旧权重模型）、研发送样记录、分析检测今日记录。
  5. 后台列编辑弹窗增加：表头简称、可扩展、可合并、优先级，以及「预估占用宽度」提示。
  6. 操作列三档（文字/图标/收纳）与密度档联动实现。
验收口径：① 10 列配置在 1024 / 1280 / 1440px 三档容器下均无横向滚动；② 备注/成分列内容可见 ≥ 2 行且悬停可看全文；③ 数字与日期列宽度不随容器抖动（有上下限）；④ 操作列在三档容器下分别呈现文字/图标/收纳形态；⑤ 表单、导出、通知文案不受 list_label 影响。
