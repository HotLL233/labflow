| 编号 | 实施内容 | 验证要点 |
| --- | --- | --- |
| F01 | 一览调用检查业务返回码；单字段更新；拒绝保留输入及原因 | HTTP成功但业务拒绝不提示成功；零系数、零倍率保留 |
| F02 | 布局编辑器手机对象选择器、桌面弹性分栏 | 360/390px可选择、编辑和保存 |
| F03 | 导出编辑器按容器排版；工作表/列可检索；隐藏列可恢复 | 手机属性和保存可达；公式和固定列序保留 |
| F04 | 用户手机摘要及完整归属展开 | 主归属、业务部门、实验室、角色及原编辑字段不合并 |
| F05 | 会话内草稿、刷新提醒、离开前保存/放弃/继续 | 拒绝仍停留；迟到响应不清新编辑；账号/权限范围隔离 |
| F06 | 列表与配置读取失败显示原因和重试 | 旧数据及条件保留；布局字段读取失败不伪装默认成功 |

v2.4.10已正式交付。277项前端测试、Windows静态258项浏览器检查、镜像静态另行同套258项检查及两类正式安装包核验完成；两个浏览器范围分别记录。准确源码、摘要、CI与未验收范围集中记入`source/LabFlow-PostgreSQL-v2.4.10/安装包说明.md`。

259份后端、API、类型和权限文件与v2.4.9逐字节一致，依赖锁除根应用版本外一致。业务记录、历史来源、统计口径、授权范围、记录全范围筛选及近30天加载策略不变。

草稿只保存在当前浏览器页面的会话内存；刷新或关闭由浏览器提示，确认离开后不会跨浏览器恢复。云端密码只留在正在编辑的窗口，不加入草稿存储。真实群/云盘、生产库、现场升级、手机实机和容器运行须分别验收。
