# B 方案实施说明

2026-11-06 用户选择 B 方案，实施版本v2.4.9，基线v2.4.8。此前三版HTML和评估文档保留为方案阶段记录。

## 本轮实施

- 管理桌面采用64px模块栏与168px当前模块菜单，不增加工作标签；保留原侧栏折叠键和四组权限过滤。
- 手机以顶部菜单按钮统一管理导航，抽屉同时保留主页、帮助和管理总览；页面不重复导航行。
- 外壳由顶栏和剩余内容区组成，取消固定104px补偿。长页面主要在内容区滚动，横向宽表仍可局部滚动。
- 方法管理把新增放到页头；仪器、类型、方法一览、主数据导入与刷新放到“更多”。关键词、类型和范围独立筛选，桌面按列排列数值，手机使用紧凑记录。
- 主数据对象用选择器；复用已有内容自适应列宽，取消固定620px内层纵向高度；预览、导入、导出与辅助配置入口不变。
- 通知中心默认展示事件。发送记录、规则与渠道、内容模板、身份绑定分别进入任务页签；事件发送详情自动定位对应事件筛选，模板关闭和任务切换保留当前页面草稿。
- 总览按分组横向列出入口；辅助事项压缩重复标题和说明，角色、字段、备份等继承同一外壳。

## 保留约束

继续使用当前React/MUI和原有API。菜单可见不等于授予业务权限；不变更后端授权、数据库、历史快照、稳定身份、统计口径及业务近30天加载策略。现有字号、主色、圆角、列、字段范围、辅助区域与按钮配置继续沿用。

## 验收和交付

前端测试、类型与生产构建；实际构建的六种视口浏览器检查，覆盖模块切换、折叠偏好、部分权限、方法稳定身份与零值、辅助区域草稿、主数据只读预览和筛选、通知模板草稿与补发确认。校验后端/API/类型/权限文件与v2.4.8的字节一致性。

正式发布使用现行门禁，安装包只进GitHub Release、镜像只进GHCR。具体结果和范围以v2.4.9安装包说明为准，不把离线夹具当真实数据库、现场安装或手机实机验收。
