修订方案与实施边界

按本次更正整理；旧 HTML 仅提供视觉参考，其“门户卡片加入口”的文字不再作为需求。

本文件只演示设计：所有记录、账号、操作和配置均在浏览器内存中，刷新恢复；不连接 LabFlow、数据库或外部服务。

1. 入口与复用

分析检测 → 点击实验室 → 默认工作量录入 → 点击“本实验室送样记录”。保留内部双页签，移除门户实验室卡片新增的记录按钮；辅助工作入口不显示实验室记录。

原研发记录页与实验室记录页共用记录组件；实验室参数固定在服务端授权范围内，不能通过清空筛选或更改 URL 扩大范围。保留切换时的表单草稿、筛选和原返回提示。

仅有记录查看权限、没有工作量入口权限时，继续保留当前只读入口逻辑；查看入口不授予取样、退回、编辑、工作量录入权限。

2. 表头筛选始终可用

列名与筛选分为上下两层；标题可换行，筛选按钮占独立一行，保持可见且可点击。窄列允许“筛选”文字换行，不与排序控件抢宽度。无结果仍保留筛选入口。

现状根因：表头横排标题、排序、图标按钮，外层裁切；宽度测算未计控件。操作表头单独返回文字，没有筛选值或筛选入口。方案需同时修复布局和筛选模型。

保留原列顺序、显示开关、相对宽度、右键管理员配置、排序与全局样式。桌面表格宽度始终适应页面；仅单元格内滚动，整页无横向滚动。手机用“按列筛选”打开同一条件。

3. 时间筛选与查询范围

在“送样时间”的筛选弹窗中提供本周、上周、全部时间，以及开始/结束的日期＋时刻输入；页面上方快捷按钮与列筛选共用同一时间状态，不叠两套时间条件。

日期范围含结束日全天，以次日 00:00 为排他上界。精确时刻范围包含起止时刻，按系统统一的北京时间解释；不能把明确的结束时刻扩成全天。校验起止倒置、允许只填一侧，并显示已生效范围。

当前列筛选只筛本页；拟改为服务端全量筛选。列表、总数、分页使用同一条件；可筛字段、匹配类型白名单验证并参数化查询。授权范围先于筛选，空范围返回空，不通过关键词获得其他实验室数据。

4. 操作列筛选语义

筛业务状态，不匹配按钮文案。条件建议：待取样、已取样未录入、部分录入、全部录入、退回待修改；同时可选择真实工作量录入人（含未记录人员）。实际状态按现有工作量进度与退回生命周期映射，不改变业务状态机。

同一条件多选为“或”，不同列以及操作状态/录入人之间为“且”。多次录入时，只要该人参与有效录入即匹配；已撤销的工作量不算有效录入。没有操作权限的用户仍能看到授权记录的业务状态，按钮按权限显示。

全量筛选选项也必须来自授权数据，不能加载全部用户目录生成候选；现有编辑、批量、退回、撤销、作废等操作按原权限和可操作条件保留，不因原型简化按钮而删除功能。表格上方常驻“按列筛选”，作为极窄列、隐藏列和手机的可靠入口。

5. 真实录入人及操作反馈

取样人和工作量录入人分别显示。已全部录入：已录入 · 林舟；分批多人：已录入 · 林舟等 2 人，点击看每批录入账号、数量、时间；部分录入：继续录入 · 2/5，附已有录入人。

关联非删除的 rd_sample / source_record_id 工作量，录入人取 created_by_user_id 与 created_by_username_snapshot；按当前页 RD ID 批量汇总，避免逐条查询或关联放大分页行数。稳定账号 ID 用于筛选与去重，明细保留每批姓名快照。缺失 ID 时不按姓名猜人数；已知和未知混合显示“已录入 · 林舟等 2 人 · 含历史身份未记录”。

公共账号操作人与业务归属人分开；原始录入账号与后来编辑后的工作量归属人也分开。提交时间取不可变的 created_at，可编辑的 recorded_at 标为“工作量日期”。最小录入人摘要随本条 RD 查看权限展示；完整工作量明细仍校验原工作量权限与人员/部门范围，不能因看得到 RD 就开放他人的全部工作量。用户更名、停用或删除后仍保留可解释的历史显示；旧记录无法可靠关联时显示“录入人未记录”，禁止猜成取样人。

点击后只在服务器提交成功后更新状态；失败保留输入并显示原因。提交中显示“录入中…”并禁止重复提交。多人同时提交由原事务/剩余数量校验兜底；已录入按钮只查看明细，不再次录入。

6. 文字按钮与自定义字体

取样/录入为蓝色主操作，编辑为描边，退回为暖色描边；录入中为不可重复提交状态，全部录入为浅绿，部分录入为浅橙。取样后不显示编辑或退回；撤回取样继续按原权限和条件展示。用文字说明状态，不只依赖颜色。业务操作移除重复图标；关闭、导航、排序等结构控件不在此范围。

记录正文默认 13px；表头、工具栏、说明、状态与按钮默认 12px，分别可调。复用现有正文/表头样式与 record_table_style_*；补齐目前硬编码的辅助文字/按钮字号和 RD 按钮尺寸配置，避免新建平行设置。

管理员发布到全部用户，原个人视觉设置与“跟随全局”行为保持兼容。样式持久化和权限验证仍由现有服务端设置完成；本原型的设置仅预览，不能代表当前程序已经支持全部新增项。

7. 手机同规则、紧凑四组

以原三/四组摘要为基础：①编号/状态，②项目/送样人/数量，③方法/仪器/工作量，④时间/取样人/实验室。字段有边框，空字段不占位，长文本换行；完整字段可展开。三组模式合并末两组，不丢字段。

主操作和次操作放卡片底部，宽度、顺序、显隐继续读取配置；文字大小可改，触控高度至少 40px。已录入人进入工作量摘要/状态按钮，完整分批明细可点开。手机筛选与桌面使用同一查询条件，条件可逐项移除。

内外边框颜色及粗细仍分开配置，摘要内容/行数/字段顺序、检测类型规则和操作列位置均保留。“水机页面”按上下文理解为手机页面。

8. 下一版验证清单

  • 管理员、普通人、部门范围、只读角色、公共账号；手工扩大实验室/人员参数不能绕过授权。
  • 取样人与录入人不同、分批多人、公共账号代录、历史无关联、删除/撤销后状态回退；成功后刷新和重新登录状态一致。
  • 窄列/隐藏列/右键配置/操作列排序；无数据时筛选仍能清除；全量计数与分页一致。
  • 周一/周日、起止相同、精确时刻、毫秒、结束日全天、无效输入及旧脏时间。
  • 320/390/768/1280 屏宽、手机三/四组摘要、自定义字体/按钮尺寸/边框；整页不横滚，已有功能和导出回归。

只读核查另发现：编辑工作量数量、直接恢复和回收站恢复尚未复用来源累计量校验，可能产生超量。应在下一版业务修复中评估并复用现有事务锁检查；展示仍保留现有“累计量 ≥ 来源量”完成口径，另标数量异常，不截断数量或修改统计结果。

正式实现时另建隔离版本、更新编号和唯一更新说明；验证完成后按惯例重新生成 Windows 完整/热更新包及 Docker 镜像。本次不创建正式版本、不构建、不提交或发布。
