# v2.4.13 实施与验证对照

日期：2026-11-12。基于正式版 v2.4.12，在新版本目录实现三份已确认方案。发布与安装包实际状态以本版安装包说明为准。

## 计量方法

- 复用现有独立检测方法 ID。特殊处理作为另一条方法维护，不新增处理方式子表，也不改变送样人的提交习惯。
- 手动录入保留原项目方法行，按需展开“更换计量方法”；研发和登记来源窗口可搜索实际方法。关键词只筛选排序，不创建方法或以名称猜 ID。
- 系数、方法配置单价（`methods.amount`）、默认倍率来自实际方法；手改倍率与恢复默认分开。方法或仪器配置变化时拒绝旧修订确认，刷新保留已填业务信息。
- 历史金额仍采用原有当前方法单价口径，本轮没有新增历史单价快照或批量改写历史金额；历史系数及已保存倍率继续保留。
- 源方法由服务端读取并保存来源快照，实际方法写入工作量记录。按同一来源锁定总容量，不因更换方法重复获得份数。
- 新路径仅放宽实际计量方法与项目的关联限制，原项目/实验室/部门/人员授权仍校验。普通直接请求不能伪造来源或服务端计量标记；新记录日常日期/备注编辑不被旧项目方法关联阻断。
- 旧请求未传新增字段时保留原契约，旧历史快照不重算。旧无方法的研发来源且未传任何新字段时保留项目系数回退；新页面无原方法时必须确认有效实际方法，不能自动选择唯一候选。

## 实际送样人

- 两类公共账号默认空白，个人账号默认本人；其他账号可由系统管理员独立开启手填要求，不自动赋予公共角色或其他权限。
- JSON 与带附件创建均在写记录、附件和通知之前校验空白及占位。显式填写的同名真实人员允许，不把公共账号名永久加入黑名单。
- 保留旧草稿及已填内容，疑似自动填入公共账号名时要求确认；后台隐藏送样人列时本页仍提供必填原生字段，不覆盖管理员保存的字段配置。
- 历史记录不批量改名；普通日期/备注编辑不会因旧送样人信息而重写或阻断。实际送样人自由文本不等于账号身份验证，不以姓名扩大本人范围。

## 角色与权限

- 新原子接口一起保存功能和三类范围，事务锁定角色并校验修订；三类范围必传，漏传直接拒绝，不默认为清空。
- 旧两个 PUT 接口保留各自部分更新契约。既有合法和历史兼容权限保留，不重命名 key，不由模板重置管理员配置。
- 全新安装初始化通知权限，升级及重启保留撤销。原公共账号系统必需项保留并只读可见；旧不生效标识明确标注。
- 多角色功能取并集；样品部门与类型仍按同角色配对后合并，禁止跨角色交叉扩大。
- 用户列表“查看实际权限”由服务端解释关键能力、来源与范围；明确管理员、组长、门户、人员关系和状态等附加条件，不声称拥有功能就能维护任意记录。
- 仪器独立入口可达、方法页仪器按权限只读；帮助后台保持管理员维护，普通阅读按原权限；只有辅助记录维护能力时给出入口依赖说明，不自动补授录入权限。

## 数据与交付边界

新增账号手填字段迁移及通知权限初始化标记；不更改旧迁移标识，不回填或重算业务记录，不新增依赖。原布局、配色、内部品牌、人员归属及辅助工作的独立配置继续保留。

原型和合成接口浏览器检查不能替代真实数据库/API，CI Build 不宣称运行了数据库业务测试。私有日志保留在实际工作区，不上传数据库、凭据、截图或原始会话。
