可采纳的四处变化

① 搜索常驻，条件进底部面板

保留状态快捷选择；部门、实验室、时间和工作量状态集中设置，首屏不堆多行输入框。

② 每条只保留核心信息

列表展示编号、批号、状态、实验室、数量、时间和项目；其他字段点开详情查看，避免把整张表搬到列表里。

③ 一个主操作，其余进“更多”

取样或工作量录入保持直接可点；编辑、退回、完成检测等按管理员顺序放入操作面板。已录入独立提示，按钮触控高度至少约 44px。

④ 取消逐字段按钮常驻

管理员从页头统一进入列设置，字段筛选进入筛选面板。减少每张卡片重复的齿轮、漏斗和图标。

如何体验

第一条可录入工作量，第二条可取样。点击任意记录标题查看全部字段；第三条可查看退回原因。“更多”保留完整操作集合。

针对当前手机页的修改方案

对照用户打开的 v2.3.40 静态源码。现有手机卡片已经具备完整字段、全局配置和操作排序；这次建议优化呈现方式。

现有设计值得保留

  • 手机已有双列字段卡片，长字段跨列并可独立滚动。
  • 样品登记操作由状态、角色权限和全局配置共同决定，不是固定按钮集合。
  • 管理员已能设置字段；桌面与手机使用同一份顺序与按钮配置。
  • 已有分页、排序、编辑表单和统一编辑抽屉，避免再建一套。

当前可改进的地方

  • 卡片内反复出现字段配置、筛选图标，手机视觉负担与误点机会较多。
  • 排序、筛选与操作工具占据记录顶部，首屏用于内容的空间偏少。
  • 每个字段同等突出，批号、状态与普通辅助信息不易快速区分。
  • 部分操作最小高度仍为 32px；虽有宽度配置，手机触控区域可再优化。

兼容约束
记录页顶栏

标题 + 身份 / 范围说明；一行搜索与筛选；状态快捷按钮换行显示。排序从一个按钮打开。

不重做全站导航。标题、搜索和状态工具共享一个吸顶区域，横向溢出禁止。不要给每组控件单独吸顶。

记录卡片

列表只保留识别信息和业务摘要；完整短字段双列、长字段全宽放到详情面板中。

紧凑浏览为默认，完整字段保留在详情。标题只能使用当前有权且启用的字段；管理员隐藏字段不得在摘要里重新出现。其余字段继续按全局配置顺序排列。

长文本

正常长度自然换行，一次显示；超长原因/备注用一个独立滚动框，并有“展开全文”。

保留原字段显示模式；单行内容可在框内横向滚动，不让整页横向滚动。稳定记录键与滚动容器，操作反馈不让阅读位置跳回顶部。

操作区

紧凑列表显示一个主要操作与“更多”；操作面板保留全部允许按钮。完整字段模式维持原操作区，已录入单独提示。

按钮顺序与大小仍读取全局配置，完整详情保留操作区位置；紧凑列表只折叠呈现，不删按钮或改变权限。尺寸过大允许换行，触控区域至少约 44px。

筛选与检索

常用状态在顶部；部门、实验室、日期、工作量状态进底部面板，应用后显示条件摘要。

原有字段筛选仍保留，面板支持扩展已有自定义列。明确当前页/服务器全部记录的范围；没有后端全量检索支持时不伪装为全量搜索。

配置入口

普通用户不显示管理员编辑按钮；管理员从页头进入字段和操作设置，避免每个字段常驻多个图标。

复用现有管理配置与跳转，不设仅本机个人覆盖。配置范围“所有用户”，需明确保存。原型只演示部分设置，不替代后台全部选项。

手机弹层

短筛选与仪器选择底部打开；工作量显示当前操作人、数量、倍率。复杂编辑继续全宽抽屉。

遮罩关闭有草稿时提醒；安全区、软键盘、背景滚动与焦点复原一起验证。仅在后端成功后显示“已录入”。

列表状态与分页

加载用保留尺寸的骨架；为空显示原因和重置入口；失败显示重试。保留有明确范围的分页。

新增数据或操作后保留位置。暂不引入无限滚动、滑动删除、滑动退回、重复固定底栏或整个卡片手势操作。

第二阶段 · 少量交互调整

再整合筛选与移动弹层

复用现有筛选参数、分页、状态回写和编辑抽屉。短筛选使用 bottom Drawer；工作量面板需要核对仪器匹配、归属人员和异常反馈。紧凑浏览为默认，完整字段模式仍可切换。

分析检测入口与研发送样记录的关系：当前 App.tsx 路由将 /sample-records 交给 RdRecordsPage。本原型“分析检测”选择项明确示范这类共享记录，不代表本次已核对其他分析工作量页面的所有字段。

将来实施的验收

  • 360 / 390 / 430px 和横屏均无整页横向滚动；系统大字体不裁切字段、按钮与状态。
  • 列表默认紧凑，一屏应能浏览多条；所有启用字段在详情中可看，长文本可独立滚动，管理员排序与操作配置保持。
  • 普通人员只执行获授权且状态允许的操作；前后端同时校验，不能只靠按钮隐藏。
  • 取样后、已检测但未录入时仍可按现有规则补录；录入成功后按钮为已录入，刷新后与后端一致。
  • 仪器多选一时需确认具体仪器，数量默认本次取样数量，倍率读取既有默认值；当前录入人显示并按既有归属规则保存。
  • 失败留草稿、取消不应用、危险动作有明确原因与确认；弹层关闭还原焦点，底部安全区与键盘不挡按钮。
  • 筛选条件和分页范围明确，返回列表保留页码及阅读位置。退回原因滚动不因附件或状态更新而重置。
  • 桌面页面、导出结果、公告、权限、管理员配置和现有后端行为不随本次手机 UI 改造改变。
