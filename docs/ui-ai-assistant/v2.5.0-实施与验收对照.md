# v2.5.0 AI 助手实施与验收对照

日期：2026-11-13。对应[批准方案](AI-Agent配置与语音业务助手方案.md)和[交互参考](LabFlow-AI-Agent与语音助手参考.html)，实现位于 `source/LabFlow-PostgreSQL-v2.5.0/`。本文区分源码实现、集成验证和真实供应商验收；源码存在不代表安装包已经发布或现场设备已经验收。

## 本次交付范围

本次按 **A：接入和知识 + B：语音与填报** 实施。助手可以解释本版本操作、查询授权记录、整理工作量总结、生成四类原表单草稿和转写短音频。**C：在助手内直接提交业务**不在本次范围；没有新增 AI 取样、驳回、删除、改权限、恢复备份或历史重算工具。

默认关闭助手。管理员配置并测试模型后，另在角色权限中授予“使用 AI 助手”；已有角色的业务资格、数据范围和公共账号用途继续由原逻辑决定。

## 私密配置、外发和失败边界

AI 私密配置位于实际 `data_dir` 下的 `ai-assistant/settings.json`，与通用 `system_settings` 返回分离。浏览器只接收已配置状态，密钥留空保留原值，替换和清除独立操作；修改接口地址或协议时不能悄悄沿用旧密钥。服务端限制目的地址形式、禁止自动重定向，模型不能改 URL、执行 SQL 或命令。

**标准业务数据库备份和全量备份均不包含该私密配置目录。**依据为 [backup_service.rs](../../source/LabFlow-PostgreSQL-v2.5.0/src/service/backup_service.rs) 的 `backup_sources` 白名单；原始录音与 AI 会话也没有新增持久保存。换主机恢复业务备份后，需要管理员重新配置 AI 服务和密钥并重新测试；不能将“业务备份恢复完整”解释成 AI 凭据也会恢复。

单账号同一时刻一个 AI 请求，服务最多八个活动请求；每分钟次数和超时由管理员在限定范围内设置。上游响应最大 4MiB，工具结果另限制大小，工具调用轮数与次数受限。停止或关闭助手取消后续生成；取消不代表撤销业务事务，本次 AI 原本就不创建业务事务。

对话开始/结束记录请求 ID、账号、供应商/模型、结果和耗时；工具调用记录账号、工具、结果及耗时；配置和转写有独立审计。审计不默认保存密钥、原始音频、完整提示词或业务工具正文；真正提交业务仍由原页面和原业务审计记录。

| 核验项 | 状态 |
| --- | --- |
| 未确认日期的查询拒绝、确认范围外的工具日期拒绝；精确记录查询按原权限复核 | 待 root 汇总 |
| 普通设置 GET、AI 返回、浏览器存储与审计不含密钥；换地址不沿用凭据 | 待 root 汇总 |
| 权限撤销、账号停用、多角色范围、跨范围 ID、公共实际人员切换 | 待 root 汇总 |
| 错密钥、错误格式、200 空响应、未完成流、截断模型列表、取消与重试 | 待 root 汇总 |
| 提示注入、未授权工具、非法参数、来源/快照及已有输入保护 | 待 root 汇总 |
