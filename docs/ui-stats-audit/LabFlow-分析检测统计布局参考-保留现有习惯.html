入口、图表和查看顺序保持现有方式

首页仍是六张指标卡和原有16个报表卡片，名称、顺序及点击进入方式保留；顶部保留“我的工作量 / 授权范围汇总”。

进入报表后仍按“筛选 → 图表 → 表格”查看。折线、柱状、饼图以及数量、记录数、管理分值、金额等原有适用指标继续提供；顶部迷你折线、柱图、环形图保留。

手机的日期和常用筛选保持展开；不要求用户换到新的侧边导航或收起筛选。仅整理间距、对齐、控件尺寸和记录卡片。

工作量汇总继续顺序展示分类、人员汇总、人员类型矩阵、检测 / 辅助 / 总工作量三线趋势以及来源明细，不改成互相隐藏的内容标签。

专业统计默认今天（示例基准日2026-11-09）；工作量汇总首次进入默认本月截至示例日。可选“本月”查看更多虚构数据。

日期、系数快照、账号归属、辅助独立配置、不分摊实验室和不计金额规则均保留。专业报表的分组与金额只作布局示例，不作为实际公式验收。

显示设置可预览统计卡标题／配色、字号、边框、密度和手机摘要。正式实现仍沿用完整自定义功能。
