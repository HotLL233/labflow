配置更改预览

仅本页内存模拟。正式实现应原子保存权限与范围，并记录前后差异，防止出现半成功。
    方案原型不调用真实权限接口、不执行迁移、不修改角色成员。有效权限解释应由服务端统一计算，前端仅展示；原权限码、角色ID、历史配置与授权范围保留。
