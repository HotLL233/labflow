LabFlow 记录表改版 · 全部变动界面清单

按「列宽默认值 + 可覆盖 + 可恢复」方案，逐界面给出改后参考。本文件覆盖后台与交互界面；两张记录表主视图见 docs/记录表改版预览.html。

已确认的四项决策（2026-09-23）
决策落地方式
① 用户自己拖列宽 + 恢复默认宽度 要。启用列宽四级模型的第 ④ 级（本机 localStorage 覆盖）；列设置菜单提供「恢复默认宽度」，双击列分隔线恢复单列。详见第 8 节。
② 操作列收纳为「主操作 + 更多 ▾」 可接受，但必须带开关。新增系统设置 record_table_action_mode：auto（按容器宽度三档自动收敛，默认）／ full（始终显示全部按钮，等同升级前）。详见第 9 节。
③ 老库升级后的默认宽度模式 默认「自动」（width_mode DEFAULT 'auto'）。升级即按内容测量生效；原 width 值保留不删，切回「自定义」即可复用；另设「全部列改为自定义」作为整体回退。
④ 表格配置三项接通记录表 一并接通。row_height → 两张记录表行高；seq_column_width → 序号列宽；checkbox_column_width → 选择列宽（仅研发送样记录有选择列）。详见第 7 节。
