## 兼容与保护规则

- 保留旧角色 ID、权限 key、模板引用、人员角色关联及三类范围配对；未知历史权限不会因搜索、分组或默认隐藏而从保存内容中删除。
- 旧固定公共角色用途锁定。自定义角色明确选择个人后，新用途优先于旧公共 key；未配置时才回退旧 key。多角色账号分别保留公共送样、公共检测事实；仅无多角色关联时回退旧 `users.role_id`。
- 管理身份使用真实管理员或稳定组长身份；`*` 不生成管理员身份。新增管理身份与公共用途组合被拒绝；历史已有混合组合保留，基础资料编辑不清理角色或归属，并提示复核。
- 模板改名、停用不撤销已关联身份或重置已有权限。旧创建请求的空权限数组继续表示使用模板默认；明确空权限使用新增覆盖字段。停用用于阻止后续创建，不提供永久删除入口。
- 配置预检不写审计、不撤销成员会话；实际保存采用修订校验与事务。用途或授权不完整时拒绝整次变更，不通过清空部门、实验室或角色使保存通过；实际授权变化按影响范围撤销会话。
- `/users/role-options` 按用户管理授权返回八项必要字段。非管理员仅获原可分配的个人用途分析员、研发送样员与研发组长选项；实际提交仍由服务端校验。角色查看权不扩大为用户管理权。
- 不重算历史工作量、金额或来源快照。工作量继续为数量乘系数，金额继续为数量乘单价乘倍率；手工倍率 0 合法，切方法保留手改值，明确恢复后才采用方法默认。
- 原方法默认、关键词明确选择稳定 ID、配置修订、业务日期、剩余容量、草稿隔离及未知提交结果保护继续保留。辅助事项独立配置，不增加实验室或金额分摊；自定义配色、字号、品牌不因本轮布局调整而重置。
